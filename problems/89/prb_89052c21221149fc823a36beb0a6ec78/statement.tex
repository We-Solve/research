\subsection{Definitions and mathematical statement}
This record combines two historical conjectures. The supplied source does not explicitly state their integer ranges or graph conventions. The formulations below use finite simple undirected graphs for the first claim, and tournaments and orientations of finite simple trees for the second. For an integer \(n\geq 3\), let \(V\) be a fixed set of \(n\) vertices and let \(\binom{V}{2}\) be its set of unordered vertex pairs. Identify a graph on \(V\) with its edge set \(E\subseteq\binom{V}{2}\). A family \(\mathcal{F}\subseteq\mathcal{P}(\binom{V}{2})\) is \emph{triangle-intersecting} if, for every \(E_1,E_2\in\mathcal{F}\), there is a three-element set \(S\subseteq V\) such that
\[
\binom{S}{2}\subseteq E_1\cap E_2.
\]
For each such \(S\), define
\[
\mathcal{F}_S=\left\{E\subseteq\binom{V}{2}:\binom{S}{2}\subseteq E\right\}.
\]
The historical \emph{Simonovits--S\'os conjecture}, as supplied, asserts that every triangle-intersecting family satisfies
\[
|\mathcal{F}|\leq 2^{\binom{n}{2}-3},
\]
with equality if and only if \(\mathcal{F}=\mathcal{F}_S\) for some three-element set \(S\subseteq V\). Here ``largest'' means maximum cardinality, including the asserted characterization of every equality case. The range \(n\geq3\) makes the fixed-triangle formulation meaningful; smaller values are not addressed by the supplied wording.

A \emph{tournament} \(T\) is a finite directed graph without loops in which, for each pair of distinct vertices \(u,v\), exactly one of \((u,v)\) and \((v,u)\) belongs to its arc set \(A(T)\). Interpret a \emph{directed tree} \(D\) as an arbitrary orientation of a finite simple undirected tree, with exactly one direction assigned to each edge. Containment means containment as a directed subgraph, without an induced-subgraph requirement: there is an injective map \(f:V(D)\to V(T)\) such that
\[
(u,v)\in A(D)\ \Longrightarrow\ (f(u),f(v))\in A(T).
\]
Under these conventions, the historical \emph{Sumner Universal Tournament Conjecture} asserts that, for every integer \(n\geq2\), every tournament \(T\) with \(|V(T)|=2n-2\) contains every directed tree \(D\) with \(|V(D)|=n\). The source omits the lower bound on \(n\); the value \(n=1\) would demand containment of a one-vertex tree in a zero-vertex tournament and therefore cannot be included in this literal formula.

The first claim characterizes the largest families of graphs whose pairwise intersections contain a triangle: all graphs containing one fixed triangle. The second claims that every tournament on \(2n-2\) vertices contains every orientation of every \(n\)-vertex tree.
