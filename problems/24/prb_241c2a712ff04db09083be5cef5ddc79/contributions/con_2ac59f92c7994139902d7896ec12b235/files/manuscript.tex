\section{Research attempt: A fixed-alphabet predictor pays repeatedly for an enormous alphabet}
Let a known alphabet have size $K$ and let a sequential predictor assign probability $(n_a+1)/(t+K)$ to symbol $a$ after $t$ previous symbols, where $n_a$ is its previous count. These probabilities sum to one because $\sum_a n_a=t$. On a constant sequence of length $N$, its assigned probability is
\[
Q(a^N)=\prod_{t=0}^{N-1}\frac{t+1}{K+t}
=\frac{N!}{K(K+1)\cdots(K+N-1)}.
\]
Since $N!\le N^N$ and every denominator factor is at least $K$, its ideal log loss obeys $-\log_2 Q(a^N)\ge N\log_2(K/N)$. For $K$ much larger than $N$, this predictor keeps paying a large cost even after repeatedly observing the same symbol. The formula is an exact likelihood calculation; no unproved coding-regret theorem is used.

For example $K=2^{20}$ and $N=16$ give log loss at least 256 bits. When $K$ and $N$ are known, there is a simple binary prefix code for all length-$N$ sequences that encodes every constant sequence in 21 bits: write a leading 0 followed by the 20-bit symbol index for a constant sequence; otherwise write a leading 1 followed by all $N$ symbol indices. All codewords in each branch have the same length, and the two branches have different first bits, so the code is prefix-free and decodes uniquely. This does not make it universal-optimal; it is a concrete witness that the predictor's repeated alphabet cost is avoidable on this family.

There is still an unavoidable first-symbol cost. The $K$ possible constant sequences must receive distinct prefix codewords. At least one has length at least $\log_2 K$: if all had shorter length than an integer $L=\lceil\log_2 K\rceil$ when applicable, their disjoint binary-tree capacities could not accommodate $K$ words; equivalently prefix-freeness gives $\sum2^{-\ell}\le1$ by the same extension counting at the maximum code length. If every $\ell<\log_2K$, the sum would exceed one. Thus a universal code cannot uniformly attain zero length just because each point-mass source has entropy zero.

For a $k\times k$ binary block the unrestricted block alphabet can have $2^{k^2}$ symbols. The preceding predictor calculation explains a specific large-alphabet obstruction, but the report's graph blocks have dependence and model restrictions. Proving universality for that class requires exploiting their structure or controlling an appropriate redundancy; the constant-sequence example does not establish an impossibility result for the original graph compressor.
