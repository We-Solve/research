\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(\N_{>0}=\{1,2,\ldots\}\). For a group \(G\), use the commutator convention
\[
[x,y]=x^{-1}y^{-1}xy,\qquad [x,{}_0y]=x,\qquad [x,{}_{k+1}y]=[[x,{}_ky],y]\quad(k\geq0).
\]
An element \(a\in G\) is \emph{left \(n\)-Engel} in \(G\) if \([x,{}_na]=1\) for every \(x\in G\), and is \emph{right \(n\)-Engel} in \(G\) if \([a,{}_nx]=1\) for every \(x\in G\).

Define the lower central series by \(\gamma_1(G)=G\) and
\[
\gamma_{k+1}(G)=\langle [u,v]:u\in\gamma_k(G),\ v\in G\rangle.
\]
The group \(G\) is nilpotent if \(\gamma_{c+1}(G)=\{1\}\) for some integer \(c\geq0\); its nilpotency class is the least such \(c\).

\begin{enumerate}
\item[(a)] Does there exist a function \(f:\N_{>0}\times\N_{>0}\to\N_{>0}\) such that, for every \(n,d\in\N_{>0}\), every nilpotent group \(G\) admitting a generating tuple \(a_1,\ldots,a_d\) of left \(n\)-Engel elements in \(G\) satisfies
\[
\gamma_{f(n,d)+1}(G)=\{1\}?
\]
\item[(b)] Does there exist a function \(g:\N_{>0}\times\N_{>0}\to\N_{>0}\) such that, for every \(n,d\in\N_{>0}\), every nilpotent group \(G\) admitting a generating tuple \(a_1,\ldots,a_d\) of right \(n\)-Engel elements in \(G\) satisfies
\[
\gamma_{g(n,d)+1}(G)=\{1\}?
\]
\end{enumerate}
No finiteness assumption on \(G\) is imposed. The generating tuple need not be a minimal generating set. The supplied source writes \(\N\) without specifying whether it contains zero; the formulation above explicitly uses positive Engel lengths and positive numbers of generators. Any intended zero-index cases require clarification.
\subsection{Short English statement}
Proposed by A. Abdollahi, these two questions ask whether the nilpotency class of a nilpotent group has a uniform bound depending only on the number of generators and their common Engel length, separately for left Engel generators and right Engel generators. The supplied registry labels the problem open; that label is not an independently verified assessment.
