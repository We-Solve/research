\subsection{Definitions and mathematical statement}
Let \(k\geq 1\) be a fixed integer, rather than part of the variable input. Let \(\mathcal C\) be a class of finite digraphs. An instance consists of a digraph \(G=(V,A)\in\mathcal C\) and an ordered list of terminal pairs \((s_1,t_1),\ldots,(s_k,t_k)\in V\times V\). Here \(A\) denotes the set of directed edges (arcs). A directed path from \(s_i\) to \(t_i\) follows arcs in their prescribed directions. Write \(A(P)\) for the arcs used by a path \(P\). The required feasibility condition is
\[
\exists P_1,\ldots,P_k\quad
\left[\text{each }P_i\text{ is a directed }s_i\text{--}t_i\text{ path}\right]
\quad\text{and}\quad
A(P_i)\cap A(P_j)=\varnothing\quad(1\leq i<j\leq k).
