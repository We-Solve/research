\subsection{Definitions and mathematical statement}
A group is locally finite if every subgroup generated by finitely many elements is finite. Let \(G\) be a simple locally finite group. A permutation representation of \(G\) on a set \(\Omega\) is a homomorphism
\[
\rho:G\longrightarrow\operatorname{Sym}(\Omega).
\]
Here a nontrivial permutation representation is interpreted as one for which \(\rho(G)\ne\{\operatorname{id}_{\Omega}\}\). For a finite subgroup \(H\le G\) and a point \(\omega\in\Omega\), define
\[
H_{\omega}=\{h\in H:\rho(h)(\omega)=\omega\}.
\]
The orbit \(H\omega\) is regular if \(H_{\omega}=\{1\}\), equivalently if \(|H\omega|=|H|\).

Following the supplied source, \(G\) is a \emph{group of finite type} if there exist a set \(\Omega\), a nontrivial permutation representation \(\rho:G\to\operatorname{Sym}(\Omega)\), and a finite subgroup \(H\le G\) such that
\[
\forall\omega\in\Omega,\qquad H_{\omega}\ne\{1\}.
\]
Thus the restriction of the action to \(H\) has no regular orbit.

\textbf{Problem (Kourovka Notebook 12.27).} Investigate and, if possible, classify the simple locally finite groups of finite type.

The source states an investigation and possible classification problem, rather than a specific conjectured classification. It imposes neither transitivity of the permutation action nor an explicit infinitude condition on \(G\).
