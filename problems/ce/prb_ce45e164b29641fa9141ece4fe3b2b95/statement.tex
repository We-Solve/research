\subsection{Definitions and mathematical statement}
Let \(V\) denote the ambient universe of sets satisfying ZFC, and let \(V_\alpha\) denote its cumulative hierarchy. All unqualified cardinals, cofinalities, power sets, and stationary sets are computed in \(V\). Let \(\mathrm{HOD}\) be the class of hereditarily ordinal-definable sets: those sets whose transitive closures consist of sets definable in \(V\) from ordinal parameters.

For an uncountable regular cardinal \(\delta\), put
\[
S^\delta_\omega=\{\xi<\delta:\operatorname{cf}^{V}(\xi)=\omega\}.
\]
A subset of \(\delta\) is stationary if it meets every closed unbounded subset of \(\delta\) in \(V\). Use the following standard formulation: \(\delta\) is \emph{\(\omega\)-strongly measurable in \(\mathrm{HOD}\)} if there is an ordinal \(\eta<\delta\) such that \((2^\eta)^{\mathrm{HOD}}<\delta\) and there is no sequence belonging to \(\mathrm{HOD}\) that partitions \(S^\delta_\omega\) into \(\eta\) sets, each stationary in \(V\). Here the power-set cardinality is computed inside \(\mathrm{HOD}\). The \emph{HOD hypothesis} says that there is a proper class of uncountable regular cardinals that are not \(\omega\)-strongly measurable in \(\mathrm{HOD}\).

Use the following convention for \emph{\(<\lambda\)-extendibility}: for every ordinal \(\alpha\) with \(\kappa<\alpha<\lambda\), there are an ordinal \(\beta\) and an elementary embedding
\[
j:(V_\alpha,\in)\longrightarrow(V_\beta,\in)
\]
with critical point \(\kappa\) and \(j(\kappa)>\alpha\). No requirement \(\beta<\lambda\) is imposed in this convention. The supplied record does not specify the definition of this term, so agreement with the source's intended convention requires review.

A cardinal \(\lambda\) is a \emph{strong limit} if \(2^\mu<\lambda\) for every cardinal \(\mu<\lambda\). Write \(\lambda^+\) for the least cardinal of \(V\) strictly above \(\lambda\), and write \((\lambda^+)^{\mathrm{HOD}}\) for the least cardinal strictly above the ordinal \(\lambda\) as computed in \(\mathrm{HOD}\).
