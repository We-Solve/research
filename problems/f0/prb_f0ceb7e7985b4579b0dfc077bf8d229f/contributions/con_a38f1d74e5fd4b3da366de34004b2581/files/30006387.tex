\section{New Quantum LDPC Codes with Good Parameters}\label{30006387}
{\small UnsolvedMath ID 30006387 · Mathematical Physics}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$; the standard number fields have their usual meanings. All additional conventions are stated locally.


A family of quantum codes has parameters $[[n,k,d]]$: number of physical qubits, number of encoded qubits and minimum weight of a nontrivial logical operation. Low-density parity-check means a bounded check weight and bounded number of checks incident on each qubit. Asymptotically good means both $k/n$ and $d/n$ stay bounded away from zero along a growing family.

\paragraph{Catalogue wording retained for traceability.}
Construct new families of quantum low-density parity-check codes with asymptotically good parameters.

\paragraph{Scope and source qualification.}Asymptotically good quantum LDPC families already exist. The source asks for new families or constructions, rather than the historical existence question.

\paragraph{Testing direct sums as a way to obtain a new family.} Let a stabilizer code \(C\) have parameters \([[n_0,k_0,d_0]]\), with \(k_0\geq1\), and fixed bounded-weight bounded-incidence checks. Take \(r\) disjoint copies, so the stabilizer matrix is block diagonal. The resulting code has \(n=rn_0\), \(k=rk_0\) and the same check bounds. Its distance is exactly \(d_0\): a smallest logical operator on one block gives the upper bound; for the lower bound, a nontrivial global logical must be nontrivial on at least one block and has weight at least \(d_0\) there. Hence
\[
 \frac{k}{n}=\frac{k_0}{n_0},\qquad
 \frac{d}{n}=\frac{d_0}{rn_0}\longrightarrow0.
\]
Bounded check locality and positive rate therefore survive replication, while relative distance does not.
\paragraph{Why classical sparsity alone is also insufficient.} For a CSS code with binary check matrices \(H_X,H_Z\), commutation requires \(H_XH_Z^T=0\): two Pauli checks anticommute exactly when the overlap has odd cardinality. Independently selecting sparse good classical checks need not satisfy this equation. Even after enforcing it, quantum distance minimizes over \(\ker H_Z\setminus\operatorname{row}H_X\) and the corresponding exchanged expression; classical kernel distance and the quotient logical distance are different objects.
\paragraph{First construction gap.} The source explicitly acknowledges that asymptotically good quantum LDPC families already exist. This attempt produces no additional family and makes no novelty claim. A new construction must couple blocks or chain-complex data while proving both sparse commutation and a linear lower bound on nontrivial logical weight. That simultaneous distance-and-sparsity control is the first missing step; merely relabeling or replicating an existing code does not meet the target.
