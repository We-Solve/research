For a codimension-one face \(\tau\), set
\[
N_\tau=N\cap\operatorname{span}_{\R}(\tau-\tau).
\]

\[
\sum_{\substack{\sigma\supset\tau\\ \dim\sigma=d}}
 m_\sigma u_{\sigma/\tau}=0
\quad\text{in }(N/N_\tau)\otimes_{\Z}\R.
