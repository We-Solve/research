\section{Strongly Polynomial Algorithms for Linear Programming}\label{statement}

\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.


A strongly polynomial algorithm uses a number of arithmetic operations polynomial in the numbers of variables and constraints, independent of input coefficient bit lengths, while the bit lengths of intermediate values remain polynomially bounded in the input length.
