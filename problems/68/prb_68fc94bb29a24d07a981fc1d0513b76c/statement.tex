\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


Mixed-integer convex optimization minimizes a convex function over a convex feasible set intersected with $\mathbb Z^n\times\mathbb R^d$. In an oracle model, information complexity counts oracle answers needed to obtain the specified additive accuracy, while running time includes the work between queries. The source uses bounded feasible regions, Lipschitz objective control, and a strict-feasibility parameter to state its bounds, with first-order and separation access.
\paragraph{Statement recorded in the supplied source.}
Can mixed-integer convex optimization be solved with running time matching its information-complexity bound up to lower-order factors? \sref{30004902}{2}
\paragraph{Scope qualification.}
This is the comparison in the source's parameterized oracle setting; it is not a claim about arbitrary unencoded convex functions. The radius, Lipschitz constant, feasibility margin, accuracy, and oracle costs must remain specified when giving a quantitative running-time bound.
