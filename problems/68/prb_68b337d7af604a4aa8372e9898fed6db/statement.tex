For a nonempty simple undirected graph $G=(V,E)$, put
\[
d_G(x,y)=\begin{cases}0&x=y,\\ \tfrac12&\{x,y\}\in E,\\1&x\ne y\text{ and }\{x,y\}\notin E.\end{cases}
\]
Then $(V,d_G)$ is a complete metric structure of diameter at most $1$ in the pure metric language. The predicate
\[
A(x,y)=2\left|d_G(x,y)-\tfrac12\right|
\]
is $0$ precisely on adjacent pairs and $1$ on other pairs, including the diagonal; this uses the continuous-logic convention that truth has value $0$. Equality is represented by $\min(1,2d_G(x,y))$. With these atomic predicates, Boolean connectives and quantifiers translate by $\neg\mapsto1-\varphi$, $\wedge\mapsto\max$, $\vee\mapsto\min$, $\forall\mapsto\sup$, and $\exists\mapsto\inf$. Thus first-order graph formulas have exact $\{0,1\}$-valued continuous-metric translations on these codes. The displayed scalar function of distance is $2$-Lipschitz; coordinatewise uniform continuity follows from the metric triangle inequality. Induced graph embeddings are exactly isometric embeddings between codes, and graph isomorphisms are exactly their surjective isometries.

For a metric $\widetilde d$ on the same carrier $V$, if
\[
\sup_{x,y\in V}|\widetilde d(x,y)-d_G(x,y)|<\tfrac14,
\]
then, for distinct $x,y$,
\[
\{x,y\}\in E\quad\Longleftrightarrow\quad\widetilde d(x,y)<\tfrac34.
\]
For bounded nonempty metric spaces $X,Y$, define the correspondence pseudodistance by
\[
\delta(X,Y)=\tfrac12\inf_R\operatorname{dis}(R),\qquad
\operatorname{dis}(R)=\sup_{(x,y),(x',y')\in R}|d_X(x,x')-d_Y(y,y')|,
\]
where $R\subseteq X\times Y$ projects onto each factor. The aid asserts that nonisomorphic graph codes satisfy $\delta\geq\tfrac14$. The strict noise bound and the separation constant are sharp: the edge and nonedge graphs on two vertices have code distances $\tfrac12$ and $1$ respectively, share the midpoint metric with off-diagonal distance $\tfrac34$ at uniform error $\tfrac14$, and have correspondence pseudodistance $\tfrac14$.
