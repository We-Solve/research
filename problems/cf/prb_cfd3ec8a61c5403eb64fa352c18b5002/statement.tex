\section*{UnsolvedMath ID: 5300091}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let $F:S^2\to S^2$ be a smooth orientation-preserving diffeomorphism. For a compatible metric $d$, put $d_n(x,y)=\max_{0\leq j<n}d(F^jx,F^jy)$ and let $s_F(n,\varepsilon)$ be the largest size of a set whose distinct points have $d_n$-distance greater than $\varepsilon$. Its topological entropy is
\[
h_{\mathrm{top}}(F)=\lim_{\varepsilon\downarrow0}\limsup_{n\to\infty}\frac1n\log s_F(n,\varepsilon).
\]
The computability question asks whether an effective specification of $F$ permits an algorithm that, given any integer $m\geq1$, outputs a rational $q_m$ with
\[
|q_m-h_{\mathrm{top}}(F)|\leq2^{-m}.
\]
The source also asks whether such computation can take useful time, without specifying a complexity bound or input-size model.

When $F$ preserves a specified probability measure $\mu$, the analogous target is Kolmogorov--Sinai entropy
\[
h_\mu(F)=\sup_{\mathcal Q}\lim_{n\to\infty}\frac1n
H_\mu\left(\bigvee_{j=0}^{n-1}F^{-j}\mathcal Q\right),
\]
where the supremum is over finite measurable partitions and $H_\mu$ is Shannon entropy with the same logarithm convention. In the sphere area-preserving case one can take normalized Riemannian area, provided that is the intended invariant area. The question is to approximate this value with arbitrary prescribed error as well.

The source requests H\'enon and standard-map families in particular, but these usually act on a plane and a torus/cylinder, respectively, rather than on $S^2$. Their parameterization, phase space, any compact invariant restriction, and invariant probability measure must be specified separately. No smooth sphere extension or finite invariant area measure on a noncompact phase space is assumed.

An ``explicit'' smooth map need not specify an effective representation. A uniform algorithm on a class of encoded maps differs from computability of the entropy of one fixed map. The record supplies neither representation, parameter restrictions, uniformity requirement, nor time bound, so these are essential unresolved parts of the algorithmic statement.
\subsection{Short English statement}
Can the entropy of an explicitly given smooth surface diffeomorphism be approximated to any error by a Turing algorithm, and efficiently? Specify the computational input, and separately formulate the H\'enon, standard-map, and invariant-area entropy cases.
