\subsection{Definitions and mathematical statement}
For an integer \(n\geq 1\), write \([n]=\{1,\ldots,n\}\). A graph here is a finite simple undirected graph. For \(p\in[0,1]\), the Erd\H{o}s--R\'enyi random graph \(G(n,p)\) has vertex set \([n]\), and each unordered pair of distinct vertices is an edge independently with probability \(p\).

For a graph \(H=([n],E(H))\), define its Lov\'asz number by
\[
\vartheta(H)=\max\left\{\sum_{i,j=1}^{n}X_{ij}: X\in\R^{n\times n},\ X=X^{\mathsf T},\ X\succeq0,\ \operatorname{tr}(X)=1,\ X_{ij}=0\ \text{whenever }\{i,j\}\in E(H)\right\},
\]
where \(X\succeq0\) means that \(X\) is positive semidefinite.

\textbf{Conjecture 1 (Bandeira et al., as attributed in the supplied record).} For each \(n\geq1\), let \(G_n\) have distribution \(G(n,1/2)\). Then
\[
\lim_{n\to\infty}\frac{\mathbb E[\vartheta(G_n)]}{\sqrt n}=1,
\]
or equivalently,
\[
\mathbb E[\vartheta(G_n)]=(1+o(1))\sqrt n\qquad(n\to\infty).
\]
The expectation is over the random graph. \subsection{Short English statement}
The conjecture states that the expected Lov\'asz number of a random graph on \(n\) vertices, with each possible edge present independently with probability \(1/2\), is asymptotic to \(\sqrt n\) as \(n\to\infty\). This is a statement-only draft requiring human mathematical review.
