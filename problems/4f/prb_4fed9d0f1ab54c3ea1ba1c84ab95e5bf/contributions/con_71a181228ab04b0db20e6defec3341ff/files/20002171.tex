\section{Research attempt: A terminating macro subset can still have exponential output}
Consider a restricted import language containing literals, concatenation, and references to finitely many acyclic macro definitions. A converter can reject unresolved names and dependency cycles, expand definitions in topological order, and translate the resulting literal tree. This is a genuinely decidable subset: graph traversal is finite, a cycle can be exhibited if present, and an acyclic graph admits a topological order by repeatedly removing a vertex with no remaining dependencies. Such a vertex always exists in a nonempty finite acyclic graph; otherwise repeatedly following a dependency would revisit a vertex and produce a cycle.

Expansion preserves meaning in this language. A dependency-free definition consists of literal concatenation and has the stated value. Inductively every dependency has already been expanded to the same string, so substituting these strings preserves its user's value. The final body is covered by the same induction. This proves termination and semantic preservation under the declared literal semantics, without claiming to parse all LaTeX.

But termination does not imply polynomial-size flat output. Set $a_0$ to the one-character string x and $a_i=a_{i-1}a_{i-1}$ for $1\le i\le n$. There are $n+1$ short definitions apart from identifier encoding. If $L_i$ is the fully expanded length, then $L_0=1$ and $L_i=2L_{i-1}$, so $L_i=2^i$ by induction. Any converter printing the entire expansion must write at least $2^n$ characters. With binary-encoded indices the input length is $O(n\log n)$, so this output is not polynomially bounded in that input length.

A shared expression graph preserves the compact form, but a target requiring fully expanded text cannot avoid the output cost merely by using a faster parser. Alternatively a conversion profile may impose an explicit expansion-size budget and reject this family above the budget. The chosen subset therefore needs both syntactic closure and an output-size policy; calling it acyclic is insufficient for an efficiency guarantee.
