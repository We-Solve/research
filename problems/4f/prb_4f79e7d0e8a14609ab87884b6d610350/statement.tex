\subsection{Definitions and mathematical statement}
Let \(f\colon\C\to\C\) be a transcendental entire function, meaning an entire function that is not a polynomial. Write \(f^0=\operatorname{id}_{\C}\) and \(f^{n+1}=f\circ f^n\) for \(n\geq 0\). Let \(S(f)\) be the closure in \(\C\) of the set of critical values and finite asymptotic values of \(f\). A critical value is a value \(f(c)\) with \(f'(c)=0\); a finite asymptotic value is a number \(a\in\C\) for which there is a continuous curve \(\gamma\colon[0,\infty)\to\C\) such that \(|\gamma(t)|\to\infty\) and \(f(\gamma(t))\to a\) as \(t\to\infty\). Define the postsingular set by
\[
P(f)=\overline{\bigcup_{n=0}^{\infty}f^n(S(f))},
\]
where the closure is taken in \(\C\). Let \(F(f)\) be the set of points having a neighbourhood on which the family \(\{f^n:n\geq0\}\) is normal with respect to the spherical metric, and let \(J(f)=\C\setminus F(f)\) be the Julia set. Define the escaping set by
\[
I(f)=\{z\in\C:|f^n(z)|\longrightarrow\infty\text{ as }n\to\infty\}.
\]
Assume that
\[
\#P(f)<\infty\qquad\text{and}\qquad P(f)\subseteq J(f).
\]
\textbf{Question.} Under which additional hypotheses on such a function \(f\), if any, is \(I(f)\) connected in the topology inherited from \(\C\)? Here connectedness means that \(I(f)\) cannot be expressed as the union of two disjoint nonempty relatively open subsets.
