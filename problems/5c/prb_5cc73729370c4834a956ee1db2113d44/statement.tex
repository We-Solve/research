\subsection{Definitions and mathematical statement}
Let \(D=(V,A)\) be a finite simple loopless digraph, allowing two opposite arcs between a pair of vertices but no repeated arc. Call it Eulerian here when \(d_D^+(v)=d_D^-(v)\) for every vertex; the source does not specify an additional connectivity convention. Set
\[
 d=|A|/|V|,
 \qquad \ell(D)=\max\{\text{number of arcs in a vertex-simple directed path in }D\}.
\]
Thus \(d\) is average outdegree; if ``average degree'' instead means average total degree, it is \(2d\), which changes only the absolute constant in the source's asymptotic question. Nonempty vertex sets are understood. The question, attributed to Jacques Verstraete, is whether there is an absolute \(c>0\) such that every Eulerian digraph in the intended class satisfies
\[
 \ell(D)\ge cd.
\]
The source describes this as a special case of a Bollob\'as--Scott conjecture on weighted directed paths and says an \(\Omega(\sqrt d)\) bound is not difficult. No weighted formulation is supplied. The simple-loopless convention matters: unrestricted parallel arcs can raise average degree without increasing vertex-simple path length.

The supplied aid's structural bound does not require the Eulerian condition. Let \(b(D)\) be the number of unordered pairs supporting both opposite arcs. If \(|A|>0\), put
\[
 \rho(D)=2b(D)/|A|\in[0,1].
\]
It reports
\[
 \ell(D)\ge\frac{2b(D)}{|V|}=\rho(D)d.
\]
The stated input is the Erd\H{o}s--Gallai undirected path theorem applied to the reciprocal graph, whose edges are those unordered pairs; any undirected path in that graph can be directed in either direction in \(D\). For \(|A|=0\), \(\ell(D)=d=0\), and no division defining \(\rho\) is needed.

Consequently an Eulerian family with \(\rho(D)\ge\rho_0>0\) satisfies the desired bound with \(c=\rho_0\), and every bidirected case satisfies \(\ell(D)\ge d\). Any asymptotic counterexample sequence with \(d\to\infty\) and \(\ell(D)/d\to0\) must have \(\rho(D)\to0\), so only \(o(|A|)\) arcs lie in directed two-cycles. This is an asymptotic reciprocal-density restriction; deleting those arcs need not preserve the Eulerian condition and does not itself construct an oriented Eulerian counterexample.

The aid reports that the general linear question remains open and that the best general bound it located is of order \(d/(\log d+1)\), in the relevant large-degree regime. It provides no full citation or logarithm convention for that assessment. These are dated research-aid claims, not an independently checked current literature conclusion.
\subsection{Short English statement}
The source asks for a directed simple path whose length is a fixed fraction of average degree in every Eulerian digraph. The supplied aid proves a reported bound in terms of reciprocal arcs, showing that a possible asymptotic obstruction must have a vanishing fraction of arcs in directed two-cycles.
