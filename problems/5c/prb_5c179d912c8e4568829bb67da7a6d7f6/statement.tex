\subsection{Definitions and mathematical statement}
Use the positive affine group as a coordinate convention:
\[
\mathcal A=(0,\infty)\times\R,\qquad
(a,b)(a',b')=(aa',b+ab'),\qquad
(\pi(a,b)\psi)(x)=a^{-1/2}\psi((x-b)/a).
\]
For a countable affine parameter set \(\Gamma\subset\mathcal A\), let
\(W(\psi,\Gamma)=(\pi(\gamma)\psi)_{\gamma\in\Gamma}\).
It is a wavelet frame for \(L^2(\R)\) if there are constants \(0<A\leq B<\infty\) such that
\[
A\|f\|_2^2\leq\sum_{\gamma\in\Gamma}|\langle f,\pi(\gamma)\psi\rangle|^2
\leq B\|f\|_2^2\qquad(f\in L^2(\R)).
\]
The source asks whether one generator works for every sufficiently dense affine set. Denoting the intended lower and upper affine densities by \(D^-_{\mathrm{aff}}\) and \(D^+_{\mathrm{aff}}\), its quantifier structure is

\forall\Gamma\quad
\bigl(D^-_{\mathrm{aff}}(\Gamma)>1,\ D^+_{\mathrm{aff}}(\Gamma)<\infty\bigr)
