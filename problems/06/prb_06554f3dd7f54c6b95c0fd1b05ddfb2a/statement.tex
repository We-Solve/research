\section*{UnsolvedMath ID: 701512}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(G\) be a group with identity \(1_G\). A generating set is a subset \(X\subseteq G\) such that \(\langle X\rangle=G\). Put \(X^{-1}=\{x^{-1}:x\in X\}\), and, for each integer \(n\geq 0\), define
\[
B_X(n)=\bigcup_{k=0}^{n}\{x_1\cdots x_k:x_i\in X\cup X^{-1}\text{ for }1\leq i\leq k\},
\]
where the product with \(k=0\) is \(1_G\). The generating set \(X\) is \emph{fast} if \(B_X(n)=G\) for some integer \(n\geq 0\). It is \emph{slow} otherwise; equivalently,
\[
\forall n\in\Z_{\geq 0}\ \exists g\in G\quad g\notin B_X(n).
\]
\textbf{Problem (B. Poizat).} Does there exist a countably infinite group having no infinite slow generating set? Explicitly, is there a group \(G\) such that
\[
|G|=\aleph_0
\quad\text{and}\quad
\forall X\subseteq G,\quad
\bigl(|X|\text{ is infinite and }\langle X\rangle=G\bigr)
\Longrightarrow
\bigl(\exists n\in\Z_{\geq 0}\quad B_X(n)=G\bigr)?
\]
The bound \(n\) may depend on \(X\); no common bound for all generating sets is required. The condition concerns infinite generating sets only.

As background, the supplied source describes the squares in \((\Z,+)\) as fast and the powers of \(2\) as slow. It also states that uncountable groups having no infinite slow generating set do exist. These are supplied source assertions, not independently verified here.
\subsection{Short English statement}
Does some countably infinite group have the property that every infinite generating set expresses all group elements using a bounded number of generators and their inverses, with the bound allowed to depend on the generating set? The supplied record labels the problem open and states that uncountable examples exist; neither assessment is independently verified here.
