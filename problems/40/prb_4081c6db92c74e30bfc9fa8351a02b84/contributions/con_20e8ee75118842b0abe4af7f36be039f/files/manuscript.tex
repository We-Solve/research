\subsection{A level-set cell can hide a component}
The source distinguishes adaptivity of the level-set field from that of the physical state field. We analyze the former in a specified piecewise-linear model; it is not an analysis of the entire B-spline optimization algorithm. On a cell $[0,h]$, with $h>0$, put
\[
\phi(x)=4|x-h/2|/h-1.
\]
Both endpoint values are $1$, while the midpoint value is $-1$. The zero set consists of $h/4$ and $3h/4$, and the negative region is a nonempty internal interval. Linear interpolation from the endpoints is identically $1$ and misses that region entirely. Thus a rule that accepts a cell solely because all its vertex values have one sign can lose a component.
\begin{proposition}
Let $K$ be a simplex of diameter at most $h$, and suppose $\phi$ is $L$-Lipschitz on $K$. Its barycentric linear interpolant $I_K\phi$ satisfies $|\phi(x)-I_K\phi(x)|\le Lh$ for every $x\in K$. In particular, if every vertex value is greater than $Lh$, then $\phi$ is positive throughout $K$; the corresponding negative certificate also holds.
\end{proposition}
\begin{proof}
For vertices $v_i$ and barycentric coefficients $\lambda_i(x)\ge0$ summing to one,
\[
|\phi(x)-I_K\phi(x)|
\le\sum_i\lambda_i(x)|\phi(x)-\phi(v_i)|
\le L\sum_i\lambda_i(x)\|x-v_i\|\le Lh.
\]
If all vertex values exceed $Lh$, their convex combination does too, and subtracting the error bound proves positivity. Apply the same argument to $-\phi$ for negativity.
\end{proof}
This gives a valid local certificate if a rigorous Lipschitz bound is available; cells lacking the margin cannot be certified by this argument. The hidden-component example has $L=4/h$ and vertex value $1<Lh=4$, so the test correctly declines certification.
A second failed inference is that small field error always implies a proportional zero-set displacement. On $[-1,1]$, take $f(x)=x^2$ and $g(x)=x^2-\varepsilon$ with $0<\varepsilon<1$. Their uniform difference is $\varepsilon$, whereas the Hausdorff distance between their zero sets $\{0\}$ and $\{-\sqrt\varepsilon,\sqrt\varepsilon\}$ is $\sqrt\varepsilon$. No fixed constant times $\varepsilon$ can bound it for all small $\varepsilon$. The critical zero also splits into two, so topology itself is unstable under these perturbations.
