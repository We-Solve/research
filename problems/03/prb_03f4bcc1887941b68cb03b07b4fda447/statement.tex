The number of colors and forbidden configuration defining a loss are not supplied, so no particular Ramsey-avoidance game is silently chosen.

The proposed implication is: for every $\alpha\in[0,1/6]$, if

For a fixed $\alpha$, the first condition means there are $c>0$ and $n_0$ such that $p(n)\ge c n^{-1/2-\alpha}$ for all $n\ge n_0$; the second means $N(n)/n^{8\alpha}\to\infty$.
