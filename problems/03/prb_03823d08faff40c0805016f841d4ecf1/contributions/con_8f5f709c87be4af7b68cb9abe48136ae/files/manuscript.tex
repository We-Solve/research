\subsection{Attempt: retaining diagnostic information while changing feedback}
The source's word all is a normative recommendation, not a quantified efficacy claim. I tested one possible failure in implementing supportive feedback: replacing distinct performance messages by the same message. Let $H\in\{0,1\}$ be a declared state to diagnose and let a finite feedback message $M$ have joint masses $a_m=P(H=0,M=m)$ and $b_m=P(H=1,M=m)$. Loss is binary misclassification of $H$.
\begin{proposition}
The smallest possible diagnostic error using $M$ is $\sum_m\min(a_m,b_m)$. Deterministically coarsening messages cannot reduce this optimal error, and it can increase it from zero to $1/2$.
\end{proposition}
\begin{proof}
At message $m$, choosing state zero makes joint error mass $b_m$, and choosing state one makes error mass $a_m$. A randomized choice gives a convex combination and cannot beat their minimum. Choices can be made separately for each message, proving the formula. If a coarsened message combines a set $B$ of original messages, its optimal error contribution is $\min(\sum_{m\in B}a_m,\sum_{m\in B}b_m)$. Since $\sum_{m\in B}\min(a_m,b_m)$ is at most each of those two sums, coarsening cannot lower total error.

For the extreme example, take balanced $H$ and initially let $M=H$. The two messages reveal the state exactly, giving zero error. Replace both by one constant encouraging message. The joint masses of its two states are both $1/2$, so the best remaining diagnostic error is $1/2$.
\end{proof}
\subsection{Verification and remaining gaps}
The two-message and one-message probability tables directly verify the error change. The failed inference is that all informational distinctions can be removed without affecting diagnosis. Supportive wording can retain accurate distinctions, so the result does not say praise is harmful or establish any motivational effect. Diagnosis, encouragement and subsequent learning are different objectives. The original universal recommendation is neither proved nor refuted as a complete pedagogical proposition by this limited information calculation.
