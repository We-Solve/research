\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


A hidden-shift instance consists of functions $f_0,f_1$ on a group $G$ related by $f_1(x)=f_0(xs)$ for an unknown shift $s$, with the additive version $f_1(x)=f_0(x+s)$ for abelian groups. The task is to recover a compatible shift from the stipulated function access. For $G=\mathbb Z^d$, periodicity under a sublattice means $f(x+\lambda)=f(x)$ for every period $\lambda$. Shifts differing by a period are indistinguishable. Unary query cost counts the size of an integer argument in unary, rather than only its binary length.

\section{Research attempt: Exact rectangular quotients and the cost of unary representatives}
Assume known positive integers $N_1,\ldots,N_d$, and that $f_0,f_1$ are periodic under $N_i e_i$ for every coordinate. Put $G=\prod_i\mathbb Z/N_i\mathbb Z$, and define $F_b(\bar x)=f_b(x)$ for any integer representative $x$. This is well defined: two representatives differ by a sum of the stated periods. If $f_1(x)=f_0(x+s)$ then $F_1(\bar x)=F_0(\bar x+\bar s)$, with exactly the same oracle outputs. A quotient query can therefore be implemented by lifting each coordinate to $0,\ldots,N_i-1$ and making one original query.

If $f_0$ has exactly the stated period lattice $\Lambda=\prod_iN_i\mathbb Z$, the quotient shift is unique. Indeed, if both $s,t$ work then $f_0(x+s)=f_0(x+t)$ for all $x$, so $t-s$ is a period, hence lies in $\Lambda$. Injectivity of $F_0$ is a stronger sufficient promise. Merely knowing that the displayed vectors are periods does not imply either property: $f_0(x)=x\bmod2$ with a supplied even period $N>2$ also has period two, and shifts differing by two are indistinguishable in $\mathbb Z/N\mathbb Z$.

Now specify a literal unary encoding whose length for one integer $z$ is $1+|z|$, with a separate sign convention. A quotient representative set for $\mathbb Z/N\mathbb Z$ must contain $N$ distinct integers. If all have absolute value at most $B$, then $N\leq2B+1$, so $B\geq(N-1)/2$. Thus even the best choice of representatives has a worst-case unary length linear in $N$. Moreover, at most $2B+1$ residue representatives can have absolute value at most $B$. With $N\geq8$ and $B=\lfloor N/8\rfloor$, at least half have absolute value greater than $B$, proving an average unary cost at least $N/32$ for a uniform quotient query. The crude constant follows from $B\geq N/16$ for $N\geq8$.

The standard nonnegative lifts have total unary length at most $d+\sum_i(N_i-1)$, whereas their binary lengths are $O(\sum_i\log(2N_i))$. A coherent query using fixed-size literal unary registers must accommodate the largest representative in its support. Consequently a finite-group routine polynomial in the logarithms of the periods does not acquire the same unary cost by this simulation. For $d=1$, $N=2^k$, merely holding a supported unary representative can require order $2^k$ positions while its binary description uses order $k$ bits.

These are lower bounds for the explicit quotient-lift representation, not lower bounds against every possible hidden-shift algorithm. An algorithm that avoids large integer arguments or uses a different oracle interface would need its own analysis. When the period lattice is not given or does not have full rank, this finite quotient construction is not automatically available at all.
