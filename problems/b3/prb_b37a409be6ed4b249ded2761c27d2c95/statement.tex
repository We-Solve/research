\subsection{Definitions and mathematical statement}
For an integer \(n\geq 0\), write \(n=\sum_{r\geq 0}\varepsilon_r2^r\), where \(\varepsilon_r\in\{0,1\}\) and only finitely many digits are nonzero. Define its binary digit sum by \(s_2(n)=\sum_{r\geq 0}\varepsilon_r\), so that \(s_2(0)=0\). For integers \(t\geq 1\) and \(m\geq 0\), put
\[
p_m(t)=2^{-m}\#\bigl\{n\in\Z:0\leq n<2^m,\ s_2(n+t)\geq s_2(n)\bigr\}.
\]
The source uses the limiting density
\[
\gamma_\infty(t)=\lim_{m\to\infty}p_m(t).
\]
Existence of this limit for each positive integer \(t\) is implicit in the source formulation; the supplied record does not provide a justification.

The digit-sum questions are:
\begin{enumerate}
\item Is it true that \(\gamma_\infty(t)>\tfrac12\) for every integer \(t\geq 1\)?
\item What is the value of \(\displaystyle\liminf_{\substack{t\to\infty\\t\in\Z_{\geq 1}}}\gamma_\infty(t)\)?
\end{enumerate}

For a sequence \(a=(a_j)_{j\geq 0}\) of integers, define its shifted Hankel determinants by
\[
H_{n,k}(a)=\det\bigl(a_{k+i+j}\bigr)_{0\leq i,j<n},
\qquad n\in\Z_{\geq 1},\quad k\in\Z_{\geq 0}.
\]
The further existence question is whether there are a finite nonempty set \(A\subseteq\Z\) and an infinite sequence \(a\in A^{\Z_{\geq 0}}\) such that
\[
\forall n\in\Z_{\geq 1}\ \forall k\in\Z_{\geq 0},\qquad H_{n,k}(a)\neq 0.
\]

\subsection{Short English statement}
For each positive shift, compare the binary digit sums of an integer and its translate using densities on intervals \([0,2^m)\). Ask whether every limiting density exceeds \(1/2\), and determine their limit inferior as the shift tends to infinity through positive integers. Also ask whether an infinite sequence taking only finitely many integer values can have every shifted Hankel determinant nonzero. The supplied dated assessment labels the first question solved and the other two open; this draft does not verify that assessment.
