\subsection{Definitions and mathematical statement}
Use the usual simple, undirected graph convention. Let \(G=(V,E)\) be a countably infinite graph with finite maximum degree \(\Delta\ge 3\), and let \(w=(w_x)_{x\in V}\) be nonnegative real vertex activities. A hard-core configuration is a function \(\sigma\in\{0,1\}^{V}\) satisfying \(\sigma_x\sigma_y=0\) whenever \(\{x,y\}\in E\). Thus the occupied vertices form an independent set.

For a finite set \(\Lambda\subset V\) and a hard-core configuration \(\eta\) on \(V\setminus\Lambda\), let \(\mathcal A_\Lambda(\eta)\) consist of the configurations \(\xi\in\{0,1\}^{\Lambda}\) whose union with \(\eta\) is a hard-core configuration on \(G\). Define
\[
 Z_\Lambda^\eta(w)=\sum_{\xi\in\mathcal A_\Lambda(\eta)}\prod_{\substack{x\in\Lambda\\\xi_x=1}}w_x,
 \qquad
 \gamma_\Lambda^\eta(\xi)=\frac{\mathbf 1_{\{\xi\in\mathcal A_\Lambda(\eta)\}}}{Z_\Lambda^\eta(w)}\prod_{\substack{x\in\Lambda\\\xi_x=1}}w_x.
\]
The empty product is \(1\); in particular, \(Z_\Lambda^\eta(w)>0\), including when some activities vanish. A Gibbs measure is a probability measure \(\mu\) on hard-core configurations, with the sigma-algebra generated by the coordinate maps, such that for every finite \(\Lambda\subset V\), its conditional distribution on \(\Lambda\), given the configuration \(\eta\) outside \(\Lambda\), equals \(\gamma_\Lambda^\eta\) for \(\mu\)-almost every outside configuration.

\textbf{Conjecture 1 (Sokal, 2000; supplied formulation for \(\Delta\ge3\)).} For every such graph \(G\) and every activity assignment \(w\), if there exists a single \(\epsilon>0\) such that
\[
 0\le w_x\le (1-\epsilon)\lambda_c(\Delta)
 \quad\text{for every }x\in V,
 \qquad
 \lambda_c(\Delta)=\frac{(\Delta-1)^{\Delta-1}}{(\Delta-2)^\Delta},
\]
then the hard-core lattice gas on \(G\) has exactly one Gibbs measure. The source also records the asymptotic relation \(\lambda_c(\Delta)\sim e/\Delta\) as \(\Delta\to\infty\).

The source tentatively asks whether the same uniqueness conclusion holds under the inclusive bound \(0\le w_x\le\lambda_c(\Delta)\) for every vertex, corresponding to \(\epsilon=0\). This is an additional tentative assertion, not a hypothesis of the main conjecture.

Sokal's supplied conjecture predicts a unique hard-core Gibbs measure on every countably infinite graph when all vertex activities stay uniformly below the stated degree-dependent threshold.
