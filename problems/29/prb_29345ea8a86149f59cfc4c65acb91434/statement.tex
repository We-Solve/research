\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Use the finite-resolution convention: a group $H$ is of type $\mathrm{FP}$ over $\Z$ if its trivial module $\Z$ has a finite-length resolution by finitely generated projective $\Z H$-modules. A group $\Gamma$ is virtually of this type if it has such a subgroup of finite index. This convention distinguishes $\mathrm{FP}$ from $\mathrm{FP}_\infty$, which permits an infinite resolution with finitely generated terms.

Let $\Z\Gamma$ have its left regular $\Gamma$-action and set
\[
H^i(\Gamma;\Z\Gamma)=\operatorname{Ext}^i_{\Z\Gamma}(\Z,\Z\Gamma).
\]
Right multiplication on the coefficient group ring commutes with the left action, giving each cohomology group a right $\Z\Gamma$-module structure. Equivalently one can use the left action $\gamma\cdot v=v\gamma^{-1}$. Finite generation is over the group ring, not merely over $\Z$.

The question asks whether, for every virtually type-$\mathrm{FP}$ group $\Gamma$, its group-ring cohomology is finitely generated as a $\Gamma$-module. Reading $H^*$ as the total graded module gives the assertion
\[
\bigoplus_{i\geq0}H^i(\Gamma;\Z\Gamma)
=\sum_{k=1}^{N}c_k\,\Z\Gamma
\quad\text{for some finite set of homogeneous classes }c_1,\ldots,c_N.
\]
A degreewise reading asks instead for each $H^i(\Gamma;\Z\Gamma)$ to be finitely generated. The extract does not explicitly distinguish these readings; they agree when cohomology is concentrated in finitely many degrees. If the intended hypothesis uses $\mathrm{FP}_\infty$ rather than the finite-resolution convention, that change must also be specified. The supplied Coxeter-group result is a special-family qualification, not a replacement of the general virtual-$\mathrm{FP}$ question.
