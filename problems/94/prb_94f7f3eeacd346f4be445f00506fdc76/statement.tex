A finite asymptotic value of a function defined near infinity is a number $a\in\C$ for which there is a curve $\gamma:[0,\infty)\to\C$ with $|\gamma(t)|\to\infty$ and $f(\gamma(t))\to a$; the curve is taken in the function's domain. The first question is whether the inherited conditions together with
\[

force $f$ to have no finite asymptotic value. The source attributes to Kövari a result under the stronger condition $\rho\Delta<1/\pi^2$.

The second question uses the minimum and maximum moduli
\[

\[
