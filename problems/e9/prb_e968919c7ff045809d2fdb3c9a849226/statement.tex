\subsection{Definitions and mathematical statement}
For each integer \(n\geq 0\), let \(S_n\) be the set of permutations of \(\{1,\ldots,n\}\), with \(S_0\) consisting of the empty permutation. A permutation \(\sigma\in S_k\) is a pattern of \(\pi\in S_n\) if there exist indices \(1\leq i_1<\cdots<i_k\leq n\) such that \(\pi(i_a)<\pi(i_b)\) if and only if \(\sigma(a)<\sigma(b)\) for all \(a,b\). A permutation avoids \(\sigma\) if it does not contain this pattern. For a set \(B\) of permutations, write \(\operatorname{Av}(B)\) for the set of finite permutations avoiding every member of \(B\).

A permutation class is a set of finite permutations closed under taking patterns. Define the class of separable permutations by
\[
\operatorname{Sep}=\operatorname{Av}(2413,3142).
\]
A proper subclass means a permutation class \(\mathcal C\subsetneq\operatorname{Sep}\). Its ordinary generating function, counted by permutation length, is
\[
F_{\mathcal C}(z)=\sum_{n\geq0}|\mathcal C\cap S_n|z^n\in\Q[[z]].
\]

u^2=1-4z,\qquad v^2=1-6z+5z^2,\qquad u(0)=v(0)=1,
