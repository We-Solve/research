\section{Exact Higher-Order Matrix Decomposability}\label{30004154}
{\small UnsolvedMath ID 30004154 · Computer Science}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


For $S\subseteq\{1,\ldots,n\}$ with $|S|=k$, let $E_S$ be the $n\times k$ matrix selecting the standard coordinate vectors indexed by $S$. An exact positive-semidefinite principal-block decomposition is an identity $Q=\sum_{|S|=k}E_S\Pi_SE_S^{\mathsf T}$ with real symmetric $\Pi_S\succeq0$. Exact means there is no remaining positive-semidefinite residual. The identity necessarily makes $Q$ real symmetric and positive semidefinite.

\subsection{An exact threshold on a symmetric matrix family}
The source already formulates decomposition as an SDP and asks for structural conditions beyond its two-by-two characterization. The following calculation supplies a complete restricted family, not a general characterization. Let $2\le k<n$ be integers, $\lambda\ge0$, $J_n$ the all-ones matrix, and $Q=I_n+\lambda J_n$. A $k$-principal PSD decomposition means a sum of PSD matrices, each supported on a set of at most $k$ coordinates; smaller supports can be padded to size $k$.
\begin{proposition}
The matrix $Q$ has such a decomposition if and only if
\[
\lambda\le\frac{k-1}{n-k}.
\]
\end{proposition}
\begin{proof}
Write $a=\binom{n-1}{k-1}$ and $b=\binom{n-2}{k-2}$. For each $k$-subset $S$, embed in those coordinates the block $cI_k+dJ_k$, where
\[
d=\lambda/b,\qquad c=(1+\lambda)/a-\lambda/b.
\]
Each coordinate occurs in $a$ subsets and each distinct pair in $b$, so the sum of these blocks has diagonal $a(c+d)=1+\lambda$ and off-diagonal $bd=\lambda$. It is exactly $Q$. Because $d\ge0$, a block is PSD if $c\ge0$. Using $a/b=(n-1)/(k-1)$, that condition is precisely $\lambda(n-k)\le k-1$.
For necessity take $Z=I_n-J_n/k$. On a coordinate set $S$ of size at most $k$, Cauchy--Schwarz gives
\[
x^TZ_{SS}x=\|x\|^2-k^{-1}(\mathbf1^Tx)^2\ge(1-|S|/k)\|x\|^2\ge0.
\]
Hence $\operatorname{tr}(ZR)\ge0$ for every PSD summand $R$ on such a support: diagonalize $R$ as a sum of nonnegative multiples of $vv^T$ to see each trace term is nonnegative. Any proposed decomposition therefore requires
\[
0\le\operatorname{tr}(ZQ)=\frac{n(k-1)}k-\frac{\lambda n(n-k)}k,
\]
which is the same threshold.
\end{proof}
For $k=n$, one block suffices for every PSD $Q$, and the displayed threshold with denominator $n-k$ is not used. For $k<n$, even the positive definiteness of $I+\lambda J$ does not guarantee a decomposition: every $\lambda$ above the threshold is a counterexample. The attempted route ``positive definite, therefore split into small PSD blocks'' thus fails on a fully explicit family.
