An additive randomized encoding represents $f(x_1,\ldots,x_n)$ through $\sum_i g_i(x_i)$ in a finite Abelian group. Correctness recovers $f$ from the sum; information-theoretic privacy requires a simulator using only the intended output, under the stated randomness convention.

In the LOCAL model vertices communicate synchronously along graph edges; messages and local computation are unrestricted and complexity is the number of rounds. After $t$ rounds a vertex can depend only on its radius-$t$ neighborhood and any supplied identifiers or randomness.

A code $C\subseteq\Sigma^N$ is a set of permitted length-$N$ words. Its Hamming minimum distance is the minimum number of unequal coordinates of two distinct words. For a linear $[N,K,D]_q$ code, rate is $K/N$ and relative distance is $D/N$; decoding recovers a codeword from corrupted observations.

A cryptographic security requirement compares an efficient adversary\textquotesingle s advantage with a negligible function of the security parameter. A negligible function is smaller than every inverse polynomial eventually; computational and information-theoretic security are different requirements.

\subsection{A perfect-privacy obstruction for AND with independent coins}
Let the two parties have bits $x,y$ and independently output group-valued random variables with laws $\mu_x,\nu_y$ on a finite Abelian group $G$. The aggregate has law $\mu_x*\nu_y$. Perfect privacy for AND requires
\[
 D_0=\mu_0*\nu_0=\mu_0*\nu_1=\mu_1*\nu_0,\qquad D_1=\mu_1*\nu_1.
\]
\begin{proposition}
These conditions imply $\sum_{g\in G}D_0(g)D_1(g)=\sum_{g\in G}D_0(g)^2>0$. Hence no decoder of the aggregate can recover AND with zero error.
\end{proposition}
\begin{proof}
For a character $\chi$ of $G$, put $\widehat\mu(\chi)=\sum_g\mu(g)\chi(g)$. Expanding the convolution sum shows $\widehat{\mu*\nu}=\widehat\mu\widehat\nu$. Write $a_x=\widehat\mu_x(\chi)$, $b_y=\widehat\nu_y(\chi)$ and $c_i=\widehat D_i(\chi)$. Then
\[
 a_0b_0=a_0b_1=a_1b_0=c_0.
\]
If $c_0\ne0$, both $a_0,b_0$ are nonzero, so division gives $a_1=a_0,b_1=b_0$ and $c_1=c_0$. If $c_0=0$, the product $c_0\overline{c_1}$ is zero. Thus in all cases $c_0\overline{c_1}=|c_0|^2$.

For completeness, character orthogonality gives
\[
 \sum_g U(g)\overline{V(g)}=|G|^{-1}\sum_\chi\widehat U(\chi)\overline{\widehat V(\chi)}.
\]
One can verify it by writing a finite Abelian group as a product of cyclic groups and using the characters $\exp(2\pi i\sum_j r_j g_j/q_j)$. The finite geometric sum over each $r_j$ is $q_j$ when the corresponding coordinates agree and zero otherwise. Expanding the right side therefore leaves exactly the left side. Apply this identity to $(U,V)=(D_0,D_1)$ and $(D_0,D_0)$ and use the previous characterwise equality. The squared norm is positive because $D_0$ is a probability distribution.

Hence some aggregate value has positive probability under both output cases. A zero-error decoder would have to output both zero and one on that same value, which is impossible, even for a randomized decoder required to be always correct.
\end{proof}
\subsection{The precise limitation of the masking route}
For functions of the form $f(x_1,\ldots,x_k)=\sum_i\phi_i(x_i)$ valued in $G$, deterministic local outputs $\phi_i(x_i)$ already have aggregate exactly $f$, and so satisfy aggregate-only privacy. This observation does not extend to AND; the proved overlap is the obstruction. Shared correlated randomness invalidates the product-convolution premise, while statistical rather than perfect privacy invalidates the exact equalities. Neither change is ruled out by this proof.
