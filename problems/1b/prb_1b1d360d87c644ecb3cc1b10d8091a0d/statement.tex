\section*{UnsolvedMath ID: 701189}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
A group is \emph{periodic} if every element has finite order, and is \emph{locally finite} if every finitely generated subgroup is finite. An \emph{involution} is an element of order exactly \(2\). For \(t\in G\), its centralizer is
\[
C_G(t)=\{g\in G:gt=tg\}.
\]
A \(2\)-subgroup is a subgroup whose elements all have finite order a power of \(2\); a Sylow \(2\)-subgroup means a \(2\)-subgroup maximal under inclusion.

Is the following assertion true? For every periodic group \(G\), if there exists an involution \(t\in G\) such that \(C_G(t)\) is locally finite and has a Sylow \(2\)-subgroup of order \(2\), then \(G\) is locally finite.
\subsection{Short English statement}
Must a periodic group be locally finite if some involution has a locally finite centralizer possessing a Sylow \(2\)-subgroup of order \(2\)?
