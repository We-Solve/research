# Hamiltonian paths in every finite connected abelian Cayley graph

Problem: TOP-1329

Claim type: Partial result.

Exact scope: Every finite connected undirected Cayley graph of an abelian group has a Hamiltonian path; a subgroup-and-coset induction supplies the path without requiring a cyclic group.

## Statement and construction

Write the finite abelian group additively as A, and let S=-S be the allowed nonzero steps. Connectivity means that S generates A. We prove the assertion by induction on |A|. The one-element group has its singleton path. Redundant generators can be discarded: a Hamiltonian path in a spanning Cayley subgraph is still a path in the original graph.

Choose an inclusion-minimal set of generators T contained in S. If |T|=1, repeated addition of its generator lists the cyclic group and gives a Hamiltonian path. Otherwise choose s in T and put H=<T\{s}>. Minimality makes H a proper subgroup. The quotient A/H is cyclic, generated by s+H; let its order be q. Thus the cosets H,H+s,...,H+(q-1)s are distinct and exhaust A.

The induction hypothesis supplies a Hamiltonian path p_1,...,p_h of Cay(H,S∩H), since T\{s} generates H and h<|A|. Translate this path to the first coset. Suppose a translated path through the j-th coset ends at x. In the next coset begin at x+s, and use the translate of p_1,...,p_h whose first vertex is x+s. Its translation parameter belongs to the required coset because p_1∈H. Consecutive blocks join by the permitted step s; inside a block all steps belong to S∩H. Repeating gives a path with qh=|A| distinct vertices. Distinctness follows inside each translated path and between distinct cosets. This proves the induction.

Abelianness is used in translating a Cayley path without changing its allowed steps and in identifying the quotient by H. No assertion about all nonabelian Cayley graphs is inferred. Nor is an arbitrary vertex-transitive graph assumed to be a Cayley graph.

## Relation to the prompt

Left translation acts transitively on every Cayley graph, so this is an infinite positive class within the literal Hamiltonian-path question. The proof produces a path and does not require its endpoints to be adjacent. For S empty, connectivity forces |A|=1, already handled. The selected prompt lists no previous attempt.
