\section{Research attempt: Hiding instructor text is weaker than excluding it from public output}
Choose a byte-observation model for private instructor material. A document has public part $p$ and secret part $s$; public publication produces a byte string $R(p,s)$. Hiding a secret answer with a visual style does not ensure confidentiality in this model. For example the public bytes containing a hidden answer 2 differ from those containing a hidden answer 3, even if the displayed page looks identical. An observer reading the delivered bytes distinguishes the secrets.

The exact noninterference condition for this model is
\[
R(p,s_1)=R(p,s_2)\quad\text{for all }p,s_1,s_2.
\]
On a nonempty product domain this is equivalent to the existence of a function $G$ of public input alone with $R(p,s)=G(p)$. One direction follows by substitution. For the other, fix any secret $s_0$ and define $G(p)=R(p,s_0)$; the displayed equality makes this independent of which secret is actually supplied. This is a proved factorization property, not a security audit of any renderer.

A cache can invalidate an otherwise separated pipeline. Suppose the same cache key $k$ is used for an instructor rendition and a public rendition, and lookup returns the first stored bytes. If instructor output is stored first, a later public request can receive it unchanged. Including audience and relevant source revision in the cache identity prevents this particular alias, provided distinct keys really address distinct entries. The result says nothing about access-control enforcement, logs, network metadata, or deployment behavior. Those are outside the byte-string model and must not be inferred from the factorization lemma.
