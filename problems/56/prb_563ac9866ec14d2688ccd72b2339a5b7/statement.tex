\subsection{Definitions and mathematical statement}
For a pseudo-Anosov map \(f\), its dilatation \(\lambda(f)>1\) is the factor by which it expands one of its invariant transverse measured singular foliations; it contracts the other by \(\lambda(f)^{-1}\). Write \(L(f)=\log\lambda(f)\).

The supplied problem does not define the class of surfaces or maps under consideration, or the length \(\ell_g\). In particular, it does not specify whether surfaces are closed, punctured, or have boundary, whether maps preserve orientation, or whether maps are considered up to isotopy or conjugacy. For each admissible genus \(g\), let \(\mathcal P_g\) denote the intended class of pseudo-Anosov maps. For every \(g\) for which this class is nonempty, define
\[
 m_g=\inf_{f\in\mathcal P_g}\log\lambda(f),
 \qquad
 \mathcal M_g=\{f\in\mathcal P_g:\log\lambda(f)=m_g\}.
\]

Under this interpretation, the problem asks for the exact values of \(m_g\) and a description of the qualitative properties of the maps in \(\mathcal M_g\). This definition of the infimum does not itself assert that \(\mathcal M_g\) is nonempty.

\subsection{Short English statement}
Determine the minimum logarithmic pseudo-Anosov dilatation in each genus and describe the maps attaining it; more broadly, describe families whose logarithmic dilatation is comparable to \(1/g\).
