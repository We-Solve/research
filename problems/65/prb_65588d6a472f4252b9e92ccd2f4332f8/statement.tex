\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
For a group \(G\), let \(\ell^\infty(G;\R)\) denote the real vector space of bounded functions on \(G\). Say that \(G\) is amenable if there exists a linear functional \(m:\ell^\infty(G;\R)\to\R\) such that \(m(\mathbf{1})=1\), \(m(f)\geq 0\) whenever \(f\geq 0\) pointwise, and
\[
 m(L_hf)=m(f)\qquad(h\in G,\ f\in\ell^\infty(G;\R)),
 \qquad (L_hf)(x)=f(h^{-1}x).
\]
This uses amenability of an abstract group, equivalently its discrete topology; the supplied statement specifies no other topology. A group has bounded exponent if there exists an integer \(n\geq 1\) such that \(g^n=1_G\) for every \(g\in G\).

Does there exist an amenable group \(G\), a finite subset \(S\subseteq G\), and an integer \(n\geq 1\) such that
\[
 |G|=\infty,\qquad G=\langle S\rangle,\qquad
 \forall g\in G,\quad g^n=1_G?
\]
The exponent bound must be uniform over all elements of \(G\), but its value and the number of generators are not prescribed. The supplied registry labels the problem open; this status has not been independently verified. Its statement names A. M. St\"epin, while its proposer metadata names R. I. Grigorchuk; the relationship between these attributions is not explained.
\subsection{Short English statement}
Does an infinite finitely generated amenable group exist in which every element has order dividing one fixed positive integer? The supplied record labels this question open.
