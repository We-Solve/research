\subsection{Fixed-input success and adaptive-input failure of the same protocol}
Fix integers $1\le t<n$. Let $R$ be a uniform binary $t\times n$ matrix, shared publicly. Alice sends the $t$-bit vector $Rx$; Bob accepts equality with his $y$ precisely when $Rx=Ry$, with all arithmetic over $\mathbb F_2$.
\begin{proposition}
For each fixed pair $x\ne y$ independent of $R$, the false-accept probability is $2^{-t}$; equal inputs are always accepted. If the unequal pair may be chosen after seeing $R$, an efficient chooser forces acceptance for every $R$.
\end{proposition}
\begin{proof}
For fixed nonzero $d=x-y$, the dot product of a uniform row with $d$ is a fair bit: select a coordinate with $d_j=1$ and pair each row with the row differing in that coordinate. Different rows are independent, so $Rd=0$ has probability $2^{-t}$. Equality plainly gives identical fingerprints.

After seeing $R$, its kernel has dimension at least $n-t>0$ by row reduction. Gaussian elimination finds a nonzero $d\in\ker R$ using polynomially many binary operations. Choosing $x=0,y=d$ yields unequal inputs with identical fingerprints deterministically. Thus the adaptive failure probability is one, not $2^{-t}$.
\end{proof}
\subsection{The failed inference and its computational limit}
The statement $\Pr_R[R(x-y)=0]=2^{-t}$ for every fixed nonzero difference does not imply the same bound for a difference selected as a function of $R$. Fresh independent randomness sampled after inputs are fixed restores the first proof. More generally any map from $n$ bits to $t<n$ bits has a collision by counting, but that existence argument does not give an efficient collision finder for an arbitrary map. Our efficient attack relies on linear algebra and therefore cannot be transferred without proof to collision-resistant hash families or all shared-randomness protocols.
