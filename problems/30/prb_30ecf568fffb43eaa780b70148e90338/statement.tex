\subsection{Definitions and mathematical statement}
Let \(\mathcal F\) be a foliation of a compact manifold \(M\). Its codimension is \(q\) if every leaf has dimension \(\dim M-q\). A subset of \(M\) is saturated if it is a union of leaves. A minimal set is a nonempty closed saturated subset \(K\subseteq M\) having no proper nonempty closed saturated subset. For precision, a candidate convention for an exceptional minimal set is a minimal set that is neither a compact leaf nor an entire connected component of \(M\). The supplied record does not define ``exceptional,'' so this convention requires confirmation from the source.

Here \(r\) is provisionally interpreted as specifying a \(C^r\) foliation; this interpretation is not explicit in the supplied statement.

A fully specified classification problem additionally requires a choice of equivalence relation on minimal sets or on the triples \((M,\mathcal F,K)\).
