\subsection{Definitions and mathematical statement}
\textbf{Requested bound, in the curated statement.} Prove for shifted lattice point sets \(M_n\subset[0,1)^d\) a star-discrepancy bound \(\operatorname{disc}_\infty(M_n)\le C\sqrt{d/n}\), or a comparably sharp bound of the same order as the probabilistic bound for unrestricted \(n\)-point sets. For an \(n\)-point set \(M\), define its normalized anchored discrepancy by\[D_M(t)=\frac1n\#(M\cap[0,t_1)\times\cdots\times[0,t_d))-\prod_{j=1}^dt_j,\qquad \operatorname{disc}_\infty(M)=\sup_{t\in[0,1]^d}|D_M(t)|.\] The substantive existence interpretation of the displayed target is: there is an absolute constant \(C>0\) such that, for every positive integer \(d\) and \(n\), an admissible shifted lattice point set \(M_n\) of size \(n\) can be selected with this bound. It is not a bound for every lattice and every shift; independence of \(C\) from \(d,n\) is essential to the proposed dimension dependence.\par One conventional lattice model is \(M_n=(H+\Delta)\bmod\Z^d\), represented in \([0,1)^d\), where \(H\le\R^d/\Z^d\) is a finite subgroup of order \(n\) and \(\Delta\in\R^d/\Z^d\). Rank-one rules are the special case \(M_n=\{\{kz/n+\Delta\}:0\le k<n\}\), with \(z\in\Z^d\) of order \(n\) modulo \(n\); braces denote componentwise fractional parts. The source does not state whether all lattice rules, only rank-one rules, or a narrower class such as Korobov rules is intended, nor the quantifier or distribution on shifts. These are conditional models, not silently selected hypotheses.\par \textbf{Formulation discrepancy.} The original prose instead asks for an upper bound for \(n\)-point lattice sets of the same order as the known expected \(L^p\) discrepancy bound for random point sets. For finite \(p\), \(\|D_M\|_{L^p([0,1]^d)}\) differs from the star discrepancy \(\|D_M\|_\infty\).
