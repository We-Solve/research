\subsection{Definitions and mathematical statement}
Let \(f:\PP^N\to\PP^N\) be a morphism of degree \(d\) defined over \(\Q\). The supplied record does not specify lower bounds on \(N\) or \(d\); any intended restrictions on these parameters require clarification. For a field extension \(K/\Q\), write \(f^0=\operatorname{id}\) and let \(f^r\) denote the \(r\)-fold iterate for \(r\geq 1\). A point \(P\in\PP^N(K)\) has exact period \(n\geq 1\) if
\[
f^n(P)=P\quad\text{and}\quad f^j(P)\neq P\quad(1\leq j<n).
\]
Define
\[
\operatorname{Per}_n(f,K)=\{P\in\PP^N(K):P\text{ has exact period }n\}.
\]
For a prime \(p\), let \(\Q_p\) be the field of \(p\)-adic numbers.

\begin{enumerate}
\item[(a)] For which integers \(n\geq 1\) does the following equivalence hold?
\[
\operatorname{Per}_n(f,\Q)\neq\varnothing
\quad\Longleftrightarrow\quad
\left(
\operatorname{Per}_n(f,\R)\neq\varnothing
\ \text{and}\ 
\operatorname{Per}_n(f,\Q_p)\neq\varnothing
\text{ for every prime }p
\right).
\]
The local points may be chosen separately at each place.
\item[(b)] For which integers \(n\geq 1\) is the set
\[
\{p:p\text{ is prime and }\operatorname{Per}_n(f,\Q_p)=\varnothing\}
\]
infinite? Does this hold for every \(n\geq n_0(N,d)\), with a threshold depending only on \(N\) and \(d\)? Such a dependence asks for a threshold uniform in \(f\), within the intended class of morphisms. The record supplies no additional restrictions on that class.
\end{enumerate}

More generally, for integers \(m\geq 0\) and \(n\geq 1\), a point \(P\in\PP^N(K)\) is preperiodic of exact type \((m,n)\) if \(m\) is the least nonnegative integer for which \(f^m(P)\) is periodic, and \(f^m(P)\) has exact period \(n\). Write \(\operatorname{PrePer}_{m,n}(f,K)\) for the set of such points. Ask the analogues of (a) and (b) with \(\operatorname{Per}_n(f,K)\) replaced throughout by \(\operatorname{PrePer}_{m,n}(f,K)\). The source does not specify how the proposed eventual threshold should depend on the two parameters \(m\) and \(n\), or which parameter is to become large.
\subsection{Short English statement}
For a projective morphism defined over \(\Q\), determine which exact periods satisfy a local-to-global existence principle, and which exact periods are absent over \(\Q_p\) for infinitely many primes \(p\). Ask whether the latter property holds beyond a bound depending only on dimension and degree. Ask analogous questions for points with a prescribed exact tail length and eventual period. Parameter restrictions and the threshold formulation for preperiodic types require clarification.
