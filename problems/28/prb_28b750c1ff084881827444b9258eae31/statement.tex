\section*{UnsolvedMath ID: 800264}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
A domain in \(\C^2\) is a nonempty connected open subset. A Fatou--Bieberbach domain is a domain \(\Omega\subsetneq\C^2\) for which there exists a biholomorphic map \(\Phi:\C^2\to\Omega\); that is, \(\Phi\) is bijective and both \(\Phi\) and \(\Phi^{-1}\) are holomorphic.

Write \(\mathcal O(\Omega)\) for the holomorphic functions on \(\Omega\). A domain \(\Omega\subset\C^2\) is Runge in \(\C^2\) if, for every \(f\in\mathcal O(\Omega)\), every nonempty compact set \(K\subset\Omega\), and every \(\varepsilon>0\), there exists a polynomial \(p\in\C[z_1,z_2]\) such that
\[
\sup_{z\in K}|f(z)-p(z)|<\varepsilon.
\]

\textbf{Question (source Problem 63).} Does there exist a Fatou--Bieberbach domain \(\Omega\subsetneq\C^2\) that is not Runge in the ambient space \(\C^2\)? Equivalently, does there exist such a domain together with \(f\in\mathcal O(\Omega)\), a nonempty compact set \(K\subset\Omega\), and \(\varepsilon>0\) such that
\[
\forall p\in\C[z_1,z_2],\qquad
\sup_{z\in K}|f(z)-p(z)|\geq\varepsilon?
\]
The supplied registry labels the problem open; this label is supplied source metadata, not an independently verified assessment of its current status.
\subsection{Short English statement}
Does a proper domain in \(\C^2\), biholomorphic to all of \(\C^2\), exist on which polynomial approximation of holomorphic functions fails on some compact subset? The question concerns the domain's inclusion in the ambient \(\C^2\).
