\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(G\) be a finite group with \(|G|>1\), and let \(X\subseteq G\) satisfy \(\langle X\rangle=G\). A computation using \(m\) multiplications starts with \(A_0=X\) and, for each \(i=1,\ldots,m\), chooses \(u_i,v_i\in A_{i-1}\) and sets
\[
y_i=u_iv_i,\qquad A_i=A_{i-1}\cup\{y_i\}.
\]
The two factors may coincide, and previously obtained elements remain available for reuse. An element \(g\) is obtained by this computation if \(g\in A_m\); in particular, elements of \(X\) require zero multiplications.

\textbf{Question (C. R. Leedham-Green, Kourovka Notebook Problem 15.48).} Is it true that for every such \(G\), every such \(X\), and every \(g\in G\), there exist an integer \(m\geq 0\) and a computation as above such that
\[
g\in A_m\qquad\text{and}\qquad m<2\log_2|G|?
\]
The computation may depend on \(g\); the proposed bound concerns obtaining each individual element, including the identity.

\textit{Convention requiring review.} This formulation reads ``using multiplications'' literally: initially only the elements of \(X\) are available. Neither inversion nor adjoining the identity is a free operation. The supplied wording does not explicitly settle whether either additional convention was intended.
\subsection{Short English statement}
Must every element of every nontrivial finite group \(G\) be obtainable from any generating set using strictly fewer than \(2\log_2|G|\) multiplications, with all previously obtained elements available for reuse? The draft uses a multiplication-only convention; the initial availability of inverses or the identity requires review.
