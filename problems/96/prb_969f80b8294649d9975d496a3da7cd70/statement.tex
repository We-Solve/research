For a precise conventional formulation, interpret graphs as finite, simple, and undirected, and take integers \(k\geq 3\) and \(n\geq 1\). These conventions and parameter ranges are not explicitly stated in the supplied record; any intended restriction such as \(n\geq k\) requires confirmation.

Let \(C_k\) be the cycle with vertex set \(\{1,\ldots,k\}\) and edge set
\[
\bigl\{\{i,i+1\}:1\leq i<k\bigr\}\cup\bigl\{\{k,1\}\bigr\}.
\]
A graph \(G\) is \(C_k\)-free if it contains no subgraph isomorphic to \(C_k\); the subgraph need not be induced. For distinct nonadjacent vertices \(u,v\), write \(G+uv\) for the graph obtained by adding the edge \(\{u,v\}\). A graph \(G\) is \(C_k\)-saturated if it is \(C_k\)-free and
\[
\text{for every }\{u,v\}\in\binom{V(G)}{2}\setminus E(G),
\qquad G+uv\text{ contains a subgraph isomorphic to }C_k.
\]
The universal condition includes every missing edge and is vacuous when there are no missing edges. Define
\[
\operatorname{sat}(n,C_k)
=
\min\Bigl\{|E(G)|:\ V(G)=\{1,\ldots,n\},\ G\text{ is }C_k\text{-saturated}\Bigr\}.
\]

Determine the smallest number of edges in an \(n\)-vertex graph that contains no cycle of length \(k\), but acquires such a cycle whenever any missing edge is added.
