\subsection{Definitions and mathematical statement}
Let \(\operatorname{Homeo}_{+}(\R)\) denote the group of orientation-preserving homeomorphisms of the real line. An action of a group \(G\) by such homeomorphisms is a homomorphism \(\rho\colon G\to\operatorname{Homeo}_{+}(\R)\). Its set of global fixed points is
\[
\operatorname{Fix}(\rho)=\{x\in\R:\rho(g)(x)=x\text{ for every }g\in G\}.
\]
Thus the action has no global fixed point precisely when \(\operatorname{Fix}(\rho)=\varnothing\); this does not require each nonidentity element to act without fixed points.

The supplied question asks whether there exists an infinite, finitely generated group \(G\) that acts on \(\R\) and whose every orientation-preserving action on \(\R\) without global fixed points is of type (iii). The universal requirement has the form
\[
\forall\rho\in\operatorname{Hom}\bigl(G,\operatorname{Homeo}_{+}(\R)\bigr),\qquad
\operatorname{Fix}(\rho)=\varnothing

\mathsf{Type}_{(iii)}(\rho).
\]
