\section{Approximating Submodular Functions by Matroid Rank Functions}\label{30004909}
{\small\sffamily UnsolvedMath ID 30004909 · Computer Science}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.


A matroid rank function assigns each subset the maximum size of an independent subset within it. A normalized monotone submodular function has zero empty-set value, increases with inclusion, and satisfies $f(A)+f(B)\geq f(A\cup B)+f(A\cap B)$.

\paragraph{Statement recorded in the supplied source.}
Is there a universal constant $\alpha$ such that every normalized nonnegative monotone submodular function $f:2^V\to\mathbb R_{\geq0}$ with $f(\{i\})=1$ for all $i\in V$ admits a matroid rank function $r$ satisfying $r(S)\leq f(S)\leq\alpha r(S)$ for every $S\subseteq V$? \sref{30004909}{2}
