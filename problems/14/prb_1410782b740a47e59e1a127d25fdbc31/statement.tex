\subsection{Definitions and mathematical statement}
Let \(F\colon\C^2\to\C^2\) be a polynomial H\'enon map in the class intended by the cited source. A Fatou component \(U\) is a connected component of the open set on which the forward iterates \(\{F^n:n\geq0\}\) form a normal family. Recurrence means that there exist \(z\in U\), integers \(n_j\to\infty\), and \(w\in U\) such that \(F^{n_j}(z)\to w\).

For parameters \(0\leq r<R\leq\infty\), write
\[
A(r,R)=\{\zeta\in\C:r<|\zeta|<R\}.
\]
An irrational rotation on this domain is the map \(\zeta\mapsto e^{2\pi i\alpha}\zeta\), where \(\alpha\in\R\setminus\Q\). A finite-modulus annulus has \(0<r<R<\infty\). The supplied record does not specify whether its use of ``annulus'' also permits punctured or infinite-modulus conformal types.

Writing \(S\) for that associated one-dimensional domain, the annular rotation condition means that, for an appropriate return iterate \(F^k\), there are a biholomorphism \(\phi\colon S\to A(r,R)\) and \(\alpha\in\R\setminus\Q\) such that
