\section{Research Problems in Function Theory — Problem 2.69}\label{statement}

\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


For an entire function $f$, put $M(r,f)=\max_{|z|=r}|f(z)|$, $T(r,f)=(2\pi)^{-1}\int_0^{2\pi}\log^+|f(re^{i\theta})|\,d\theta$, and $\rho(f)=\limsup_{r\to\infty}\log\log M(r,f)/\log r$, where $\log^+t=\max(0,\log t)$. A transcendental entire function is an entire function that is not a polynomial.
\paragraph{Statement recorded in the supplied source.}
Is there an absolute constant $d>0$ such that every transcendental entire function $f$ with $\rho(f)<d$ satisfies
\[\liminf_{r\to\infty}\frac{T(r,f)}{T(r,f')}\leq1?\] \sref{statement}{2}
\subsection{Short English statement}
Does a universal positive upper bound on the order force the characteristic of an entire function to be asymptotically no larger than that of its derivative along some radii?
