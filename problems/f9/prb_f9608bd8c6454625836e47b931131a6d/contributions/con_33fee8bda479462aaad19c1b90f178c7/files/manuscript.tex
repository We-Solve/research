\subsection{Attempt: using development feedback to select and evaluate features}
I tested the common inference that the best observed pilot result estimates the quality of the feature selected during development. The model has $m$ candidate versions of equal true success probability $1/2$, each receiving one independent Bernoulli pilot observation $X_j$. It isolates selection bias; it is not a complete study design.
\begin{proposition}
The selected pilot maximum has expectation $1-2^{-m}$ although every candidate has true success probability $1/2$. An independent fresh outcome for the selected candidate has expectation $1/2$.
\end{proposition}
\begin{proof}
The maximum is zero exactly when all $m$ independent observations are zero, an event of probability $2^{-m}$. Since it is binary, its expectation is $1-2^{-m}$. Choose an index $J$ attaining the maximum by any fixed tie rule based only on pilot data. Conditional on the complete pilot data, $J$ is fixed and a fresh outcome $Y_J$, independent of those data, has mean $1/2$. Taking expectations gives $E(Y_J)=1/2$. More generally, if candidate means are $p_j$, the fresh selected outcome is conditionally unbiased for $p_J$; the pilot maximum need not be.
\end{proof}
