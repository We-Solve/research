\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(G\) be a finite group, with identity element \(1\). For \(A\leq G\) and \(g\in G\), write \(A^g=g^{-1}Ag\). Using the standard meaning of \(TI\), call \(A\) a \(TI\)-subgroup if
\[
\forall g\in G,\qquad A^g\neq A\ \Longrightarrow\ A\cap A^g=\{1\}.
\]
For subgroups \(A,B\leq G\), define
\[
N_A(B)=\{a\in A:a^{-1}Ba=B\},\qquad
[A,B]=\langle a^{-1}b^{-1}ab:a\in A,\ b\in B\rangle.
\]
A \(TI\)-subgroup \(A\) is a \emph{subgroup of root type} if
\[
\forall g\in G,\qquad N_A(A^g)\neq\{1\}\ \Longrightarrow\ [A,A^g]=\{1\}.
\]
Describe, up to isomorphism, all finite groups \(G\) containing a subgroup \(A\cong\Z/4\Z\) that is a subgroup of root type. The source does not expand the abbreviation \(TI\); the conventional definition used above is explicit. No additional requirement that \(A\) be proper or nonnormal is stated in the supplied record.
\subsection{Short English statement}
Classify the finite groups containing a cyclic subgroup of order \(4\) whose distinct conjugates intersect trivially and which commutes elementwise with every conjugate having a nontrivial normalizer inside that subgroup.
