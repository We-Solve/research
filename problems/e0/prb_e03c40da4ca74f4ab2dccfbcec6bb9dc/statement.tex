\section*{UnsolvedMath ID: 700905}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
A group \(G\) is \emph{periodic} if every element has finite order, that is,
\[
\forall g\in G\;\exists n\in\Z_{\geq 1}\quad g^n=1_G.
\]
For a finite generating set \(X\subseteq G\setminus\{1_G\}\) satisfying \(X=X^{-1}\), define the undirected Cayley graph \(\operatorname{Cay}(G,X)\) to have vertex set \(G\), with \(g\) and \(g'\) adjacent exactly when \(g^{-1}g'\in X\). This is a connected, locally finite, simple graph.

Do there exist finitely generated groups \(G,H\), finite generating sets \(X\subseteq G\setminus\{1_G\}\) and \(Y\subseteq H\setminus\{1_H\}\) with \(X=X^{-1}\) and \(Y=Y^{-1}\), and a bijection \(\varphi:G\to H\), such that
\[
\forall g,g'\in G,\qquad
 g^{-1}g'\in X\ \Longleftrightarrow\ \varphi(g)^{-1}\varphi(g')\in Y,
\]
while
\[
\bigl(\forall g\in G\;\exists n\in\Z_{\geq1}\quad g^n=1_G\bigr)
\quad\text{and}\quad
\bigl(\exists h\in H\;\forall n\in\Z_{\geq1}\quad h^n\ne1_H\bigr)?
\]
Here having the same Cayley graph means isomorphism as abstract undirected graphs; the bijection is not required to preserve group multiplication or generator labels.
\subsection{Short English statement}
Can a periodic finitely generated group and a finitely generated group containing an element of infinite order have isomorphic locally finite undirected Cayley graphs, for suitable finite symmetric generating sets that exclude the identity?
