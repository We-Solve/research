\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
A $(\lambda,\varepsilon)$-quasigeodesic in a metric space $X$ is a map $\gamma:I\to X$ satisfying
\[
 \lambda^{-1}|s-t|-\varepsilon\leq d(\gamma(s),\gamma(t))
             \leq\lambda|s-t|+\varepsilon
\]
for $\lambda\geq1$, $\varepsilon\geq0$. A CAT(0) space is geodesic with triangles no thicker than Euclidean comparison triangles. Its visual boundary $\partial_\infty X$ consists of asymptotic geodesic rays with the visual topology; a basepoint identifies these with rays beginning there.

\textbf{Topology/measure program (Danny Calegari).} Define a topology on the intended set of quasigeodesics in a CAT(0) space, in the source's alternatives of proper geodesic, coarsely homogeneous, or cocompact settings, such that:
\begin{enumerate}
\item it is an increasing union of compact metrizable spaces;
\item it includes $\partial_\infty X$;
\item it is quasi-isometry invariant;
\item it has reasonable measure classes which are quasipreserved.
\end{enumerate}
The first condition can be written $B(X)=\bigcup_{m\geq1}K_m$ with $K_m\subseteq K_{m+1}$ compact metrizable. The source does not explicitly require the final/direct-limit topology. A usual precise measure-class interpretation would ask that an induced quasi-isometry homeomorphism $F_\partial:B(X)\to B(Y)$ send a chosen measure class to the chosen class, with representatives satisfying $(F_\partial)_*\mu_X\sim\mu_Y$. This is conditional terminology: ``reasonable'' and ``quasipreserved'' are undefined.

The intended underlying set is also unresolved: finite paths, rays or lines; parameterized paths or asymptotic/bounded-distance classes; and any basepoint convention are not stated. The strength of boundary inclusion (set inclusion or topological embedding), naturality under quasi-isometries, and admissible measures must be specified. The program is not silently replaced by a topology only on Morse rays, which could omit visual directions.

As context, the source reports Bowditch--Swarup [13, 56]: a one-ended hyperbolic group has a boundary with no cut points. It also reports Swenson: if a visual-boundary point of a CAT(0) group is a cut point, an infinite torsion subgroup fixes it. These are supplied contextual claims, not extra requirements of the topology. The summary additionally mentions Croke--Kleiner and says the full program is not worked out, without precise references or a modern resolution check.
