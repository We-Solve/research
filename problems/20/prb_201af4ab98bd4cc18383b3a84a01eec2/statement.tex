\subsection{Definitions and mathematical statement}
For a semigroup \(S\), multiplication is associative: \((xy)z=x(yz)\) for all \(x,y,z\in S\). An endomorphism of \(S\) is a map \(f:S\to S\) satisfying \(f(xy)=f(x)f(y)\) for all \(x,y\in S\); write \(\operatorname{End}(S)\) for the set of such maps.
