\subsection{Definitions and mathematical statement}
The supplied record concerns the comparison of a Hilbert-transform norm and a martingale unconditionality constant. The definitions below use the standard real-line normalization and the usual range \(1<p<\infty\); these conventions are not explicitly specified in the supplied statement.

Let \(X\) be a Banach space and \(1<p<\infty\). Write \(L^p(\R;X)\) for the Bochner space with respect to Lebesgue measure. On smooth, compactly supported functions taking values in a finite-dimensional subspace of \(X\), define
\[
Hf(t)=\frac{1}{\pi}\operatorname{p.v.}\int_{\R}\frac{f(s)}{t-s}\,\dd s,
\qquad
h_p(X)=\|H\|_{L^p(\R;X)\to L^p(\R;X)},
\]
where the norm refers to the bounded extension when it exists.

Define \(m_p(X)\) to be the least \(M\geq 1\) such that
\[
\left\|\sum_{k=1}^{n}\varepsilon_k d_k\right\|_{L^p(\Omega;X)}
\leq M\left\|\sum_{k=1}^{n}d_k\right\|_{L^p(\Omega;X)}
\]
for every positive integer \(n\), every filtered probability space \((\Omega,\mathcal F,\mathbb P,(\mathcal F_k)_{k=0}^{n})\), every sequence \(d_k\in L^p(\Omega;X)\) with \(d_k\) measurable with respect to \(\mathcal F_k\) and \(\mathbb E[d_k\mid\mathcal F_{k-1}]=0\), and every deterministic choice \(\varepsilon_k\in\{-1,1\}\). Set \(m_p(X)=\infty\) if no finite \(M\) exists. A Banach space has the unconditional martingale differences property, abbreviated UMD, if \(m_p(X)<\infty\) for every \(1<p<\infty\).
