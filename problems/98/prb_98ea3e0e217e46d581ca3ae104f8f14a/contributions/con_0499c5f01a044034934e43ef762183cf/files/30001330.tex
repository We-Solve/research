\section{Sigma Models with Noncommutative Target Spaces}\label{30001330}
{\small UnsolvedMath ID 30001330 · Mathematical Physics}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$; the standard number fields have their usual meanings. All additional conventions are stated locally.


\paragraph{Definitions and conventions.} In a classical sigma model, a field $g:\Sigma\to X$ maps a closed two-dimensional worldsheet into a target with a metric, and the leading action is $\int_\Sigma\|\nabla g\|^2\,d\sigma$. A noncommutative target is specified by an algebra in place of its coordinate functions. The irrational rotation algebra $A_\theta$, $\theta\notin\mathbb Q$, is generated by unitaries $U,V$ with $VU=e^{2\pi i\theta}UV$. A possible noncommutative map is expressed contravariantly by a suitable algebra homomorphism, with source and target algebras and regularity specified; the report develops this approach in examples.

\paragraph{Source scope and qualifications.} The report presents noncommutative replacements and example classification results. It does not make one proposed homomorphism framework a universal answer for all noncommutative targets, or identify every possible physical field with a classical map.

\paragraph{Catalogue wording retained for traceability.}

\paragraph{Classical maps fail already algebraically.} Put $q=e^{2\pi i\theta}\ne1$. A unital $*$-homomorphism from $A_\theta$ to a commutative unital algebra would send $U,V$ to commuting unitaries $u,v$. The defining relation then gives $vu=quv$ and hence $(1-q)uv=0$, impossible because $uv$ is invertible. Thus the naive contravariant map $A_\theta\to C(\Sigma)$ has no such fields for a classical worldsheet; some part of the field framework must change.

\paragraph{A noncommutative-domain test family.} On the smooth rotation algebra define derivations by $\delta_1(U)=2\pi iU,\delta_1(V)=0$, $\delta_2(U)=0,\delta_2(V)=2\pi iV$. For integers $a,b,c,d$, the assignments $U\mapsto U^aV^b$, $V\mapsto U^cV^d$ preserve the target relation precisely when $ad-bc=1$, because the commutation phase is $q^{ad-bc}$ and irrationality excludes other integer exponents. They therefore define algebraic $*$-homomorphisms of the polynomial rotation algebra.

Using its normalized trace $\tau(U^mV^n)=0$ unless $(m,n)=(0,0)$, the candidate Dirichlet expression
\[
 E(\phi)=\sum_{j=1}^2\tau\bigl((\delta_j\phi(U))^*\delta_j\phi(U)+(\delta_j\phi(V))^*\delta_j\phi(V)\bigr)
\]
equals $4\pi^2(a^2+b^2+c^2+d^2)\geq0$.

\paragraph{Gap.} This explicit algebraic family changes the domain to a noncommutative torus and reconstructs a possible energy, not a universal replacement for fields on the original classical worldsheet. A justified physical field category, completion/regularity and action for general noncommutative targets remain missing.
