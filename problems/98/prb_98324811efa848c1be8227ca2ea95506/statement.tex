\subsection{Definitions and mathematical statement}
Identify \(\C^n\) with \(\R_x^n\times\R_y^n\), write \(z_j=x_j+iy_j\), and put
\[
\omega=\sum_{j=1}^n\dd x_j\wedge\dd y_j,
\qquad \Omega=\dd z_1\wedge\cdots\wedge\dd z_n.
\]
A smooth oriented real \(n\)-dimensional submanifold \(M\subset\C^n\) is special Lagrangian of phase \(\theta\in\R\) if
\[
\omega|_M=0,\qquad
\operatorname{Im}(e^{-i\theta}\Omega)|_M=0,\qquad
\operatorname{Re}(e^{-i\theta}\Omega)|_M=\operatorname{vol}_M.
\]
A set \(L\subset\C^n\) is conical if \(tL=L\) for every real \(t>0\). For a special Lagrangian cone, the special Lagrangian conditions hold on its smooth locus with one constant phase. Here nonflat means that \(L\) is not contained in a real \(n\)-dimensional linear subspace of \(\C^n\).

A graphical description relative to the displayed splitting has the form

\{x+iF(x):x\in D\},
