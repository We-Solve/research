\subsection{Definitions and mathematical statement}
A Kähler manifold is a complex manifold $(M,J)$ with a Riemannian metric $g_0$ satisfying $g_0(JX,JY)=g_0(X,Y)$ whose associated two-form $\omega_0(X,Y)=g_0(JX,Y)$ is closed. A Riemannian metric $g$ is Einstein if its Ricci tensor satisfies $\operatorname{Ric}_g=\lambda g$ for an Einstein constant $\lambda\in\R$. On a disconnected manifold, whether one requires a common constant or allows a separate constant on each connected component is not specified in the supplied source.

The classification problem is to determine all Kähler manifolds $(M,J,g_0)$ for which there exist a globally defined function $\sigma\in C^\infty(M,\R)$ and an Einstein Riemannian metric $g$ on $M$ such that
\[
 g=e^{\sigma}g_0.
\]
Thus the conformal factor must be smooth and strictly positive everywhere on $M$; a factor defined only locally, or vanishing somewhere, does not satisfy this formulation. On a connected $M$, the condition can equivalently be written
\[
 \exists\,\sigma\in C^\infty(M,\R)\;\exists\,\lambda\in\R
 \quad \operatorname{Ric}_{e^{\sigma}g_0}=\lambda e^{\sigma}g_0.
\]
No sign restriction on $\lambda$ or nonconstancy requirement on $\sigma$ is supplied.
