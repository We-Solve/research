Let \(x(t)\in\R^n\) be its reference state and \(x^{\mathrm f}(t)\in\R^n\) its forecast, and define the forecast error by \(e(t)=x^{\mathrm f}(t)-x(t)\). If these errors are random vectors with finite second moments, write \(m(t)=\E[e(t)]\) and define the temporal forecast-error covariance by
