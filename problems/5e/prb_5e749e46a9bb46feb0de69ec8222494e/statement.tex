\subsection{Definitions and mathematical statement}
A skew lattice is a set \(S\) equipped with two associative, idempotent binary operations \(\wedge\) and \(\vee\) satisfying, for every \(x,y\in S\),
\[
x\wedge(x\vee y)=x=(y\vee x)\wedge x,
\qquad
x\vee(x\wedge y)=x=(y\wedge x)\vee x.
\]
Neither operation is required to be commutative.

For a set \(X\), use the braid convention for a set-theoretic Yang--Baxter solution: a map \(r\colon X\times X\to X\times X\) satisfies
\[
(r\times\mathrm{id}_X)\circ(\mathrm{id}_X\times r)\circ(r\times\mathrm{id}_X)
=
(\mathrm{id}_X\times r)\circ(r\times\mathrm{id}_X)\circ(\mathrm{id}_X\times r)
\]
as maps \(X^3\to X^3\). This definition alone imposes no bijectivity requirement; the supplied question does not specify whether bijectivity or other additional properties are intended.
