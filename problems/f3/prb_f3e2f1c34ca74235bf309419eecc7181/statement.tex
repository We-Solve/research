\subsection{Definitions and mathematical statement}
Let \(J=[0,1)\). An interval-exchange transformation on \(J\) is a bijection \(T:J\to J\) for which there is a finite partition
\[
0=a_0<a_1<\cdots<a_m=1
\]
such that \(T\) restricts to a translation on each half-open interval \([a_{i-1},a_i)\). Call \(T\) minimal if \(\{T^n(x):n\geq 0\}\) is dense in \(J\) for every \(x\in J\). Here \(T^n\) denotes the \(n\)-fold iterate. For \(x,y\in J\), define
\[
\phi_1(x,y)=\liminf_{\substack{n\to\infty\\ n\in\N,\ n\geq1}} n\lvert T^n(x)-y\rvert\in[0,+\infty].
\]
The distance is ordinary absolute-value distance in \(\R\).

\textbf{Question.} Does there exist a minimal interval-exchange transformation \(T:J\to J\) such that
\[
\forall x\in J\;\forall y\in J,\qquad \phi_1(x,y)=0?
\]
Equivalently, does such a transformation exist for which
\[
\forall x,y\in J\;\forall\varepsilon>0\;\forall N\in\N\;\exists n\in\N,
\qquad n\geq\max\{1,N\},\qquad n\lvert T^n(x)-y\rvert<\varepsilon?
\]
The universal quantifiers include partition endpoints belonging to \(J\); the endpoint \(1\) is excluded. No uniform choice of \(n\) over \(x,y\) is required.

The supplied wording contrasts this property with an almost-everywhere property, conventionally understood using product Lebesgue measure on \(J\times J\). It does not supply the precise hypotheses of the referenced almost-everywhere results. The supplied dated assessment labels the question open and reports that the property is ruled out for interval exchanges on at most three intervals. These are supplied literature qualifications, not independently verified assertions here.
\subsection{Short English statement}
Does some minimal interval-exchange transformation of \([0,1)\) satisfy the following property: for every starting point \(x\), every target \(y\), and every \(\varepsilon>0\), there are arbitrarily large positive integers \(n\) with \(\lvert T^n(x)-y\rvert<\varepsilon/n\)? The supplied source asks for every pair, including interval endpoints, rather than merely almost every pair.
