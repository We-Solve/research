\subsection{Definitions and mathematical statement}
For a compact nonempty set \(K\subseteq\C^n\), its polynomial hull is
\[
\widehat K=\left\{z\in\C^n: |p(z)|\leq\sup_{w\in K}|p(w)|\ \text{for every }p\in\C[z_1,\ldots,z_n]\right\}.
\]
The set \(K\) is polynomially convex if \(\widehat K=K\); the empty set is also taken to be polynomially convex. A smooth embedding \(f:M\to\C^n\), with \(\C^n\) viewed as a real smooth manifold, is a smooth injective immersion that is a homeomorphism onto its image. It is polynomially convex when \(f(M)\) is polynomially convex.

The supplied problem asks for the least ambient complex dimension that works for every compact smooth real manifold of a given dimension. Its boundary convention is unspecified. To display this qualification explicitly, for an integer \(m\geq0\), let \(\mathcal M_m^{(0)}\) be the class of compact smooth real \(m\)-manifolds without boundary, and let \(\mathcal M_m^{(1)}\) be the class of compact smooth real \(m\)-manifolds with possibly nonempty boundary. No connectedness or orientability restriction is stated.

n_{b,D}(m)=\min\left\{n\in D:\ \forall M\in\mathcal M_m^{(b)}\ \exists\text{ a smooth embedding }f:M\to\C^n\text{ with }\widehat{f(M)}=f(M)\right\},

whenever this minimum exists. The embedding may depend on \(M\). If \(0\in D\), use \(\C^0=\{0\}\). \subsection{Short English statement}
Determine, as a function of the real dimension \(m\), the smallest complex dimension \(n\) such that every compact smooth real \(m\)-manifold has a smooth embedding into \(\C^n\) whose image equals its polynomial hull.
