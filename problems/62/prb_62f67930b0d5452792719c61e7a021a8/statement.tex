\subsection{Definitions and mathematical statement}
Let \(\omega=\{0,1,2,\ldots\}\) and let \([\omega]^\omega\) denote the set of infinite subsets of \(\omega\). An infinite family \(\mathcal A\subseteq[\omega]^\omega\) is almost disjoint if \(a\cap b\) is finite whenever \(a,b\in\mathcal A\) are distinct. Such a family is maximal almost disjoint, or mad, if it is maximal under inclusion among almost disjoint families. Equivalently, it satisfies
\[
\forall b\in[\omega]^\omega\;\exists a\in\mathcal A\quad |a\cap b|=\infty.
\]
The requirement that \(\mathcal A\) be infinite excludes finite maximal almost disjoint families. Write \(\mathsf{NMAD}\) for the assertion that no infinite mad family exists.

A set \(X\subseteq[\omega]^\omega\) has the Ramsey property if
\[
\exists H\in[\omega]^\omega\quad
\bigl([H]^\omega\subseteq X\ \lor\ [H]^\omega\cap X=\varnothing\bigr).
\]
Write \(\mathsf{RP}\) for the assertion that every \(X\subseteq[\omega]^\omega\) has this property. This gives a standard interpretation of the source's phrase ``every set of reals has the Ramsey property,'' using infinite subsets of \(\omega\) as a space of reals.

A related convention is complete Ramsey regularity. For finite \(s\subseteq\omega\) and infinite \(A\subseteq\omega\) with every element of \(s\) less than every element of \(A\), put
\[
[s,A]=\{s\cup B:B\in[A]^\omega\}.
\]
A set \(X\subseteq[\omega]^\omega\) is completely Ramsey if, for every such \(s,A\), there is \(H\in[A]^\omega\) such that \([s,H]\subseteq X\) or \([s,H]\cap X=\varnothing\). The supplied record does not explicitly distinguish these conventions.
