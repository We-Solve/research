Establish in ZFC, without adding the generalized continuum hypothesis, the negative partition relation
\[
\aleph_{\omega+1}\nrightarrow(\aleph_{\omega+1},3,3,\ldots)_{\aleph_0}^{2}.
\]
Equivalently, seek a countable coloring of pairs from a set of size $\aleph_{\omega+1}$ with no color-zero homogeneous set of that size and no monochromatic triangle in any other color.
