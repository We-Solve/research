\textbf{Erd\H{o}s \#515; one path for all positive exponents, 2026-09-24.}
Given a transcendental entire function $f$, construct one locally rectifiable path $\Gamma$ tending to infinity such that, for every $\lambda>0$,
\[
 \int_\Gamma |f(z)|^{-\lambda}\,|dz|<\infty.
\]
The integral is with respect to arclength, and the path must be independent of $\lambda$.
