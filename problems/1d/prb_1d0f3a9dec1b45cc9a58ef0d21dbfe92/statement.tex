\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(N:\R^2\to[0,\infty)\) be a possibly asymmetric Minkowski norm: \(N(v)=0\) if and only if \(v=0\), \(N(tv)=tN(v)\) for \(t\geq0\), and \(N(u+v)\leq N(u)+N(v)\). The identity \(N(-v)=N(v)\) is not assumed. Set
\[
B_N=\{v\in\R^2:N(v)\leq1\}.
\]
Consider the billiard table whose boundary is \(\partial B_N\), in the setting of the source's smooth convex boundary construction. Parametrize this boundary by a periodic map \(\gamma\) with \(N(\dot\gamma(s))=1\). The Minkowski billiard associated with \(N\) has generating function
\[
L(s_0,s_1)=N\bigl(\gamma(s_1)-\gamma(s_0)\bigr).
\]
Its trajectories satisfy the variational principle associated with
\[
\mathcal L\{s_n\}=\sum_n L(s_n,s_{n+1}).
\]
Here stationarity can be expressed using finite segments with fixed endpoints; the displayed sum need not be interpreted as a convergent infinite series. The source describes the resulting billiard as a twist map. For a Euclidean norm, this construction specializes to the Birkhoff billiard.

\textbf{Question (communicated by Yaron Ostrover).} For every possibly asymmetric Minkowski norm \(N\) for which this billiard construction applies, does total integrability of the Minkowski billiard in \(B_N\), using the same norm \(N\) in the generating function, imply that \(N\) is Euclidean? With the usual meaning of a Euclidean norm, the proposed conclusion is
\[
\exists\,Q\in\R^{2\times2}\quad
Q^{\mathsf T}=Q,\qquad
v^{\mathsf T}Qv>0\ \text{for every }v\ne0,\qquad
N(v)=\sqrt{v^{\mathsf T}Qv}\ \text{for every }v\in\R^2.
\]

\subsection{Short English statement}
If the Minkowski billiard inside the unit ball of its own possibly asymmetric norm is totally integrable, must that norm come from an inner product? The source reports an affirmative answer for tables with a finite symmetry group. The exact integrability, regularity, and symmetry hypotheses remain to be checked.
