\section{Research attempt: Countable CSP compactness and the failure of a fixed local test}

\paragraph{A complete countable finite-domain compactness argument.}
Let variables be $v_1,v_2,\ldots$, with a fixed nonempty finite domain $D$,
and let constraints $C_1,C_2,\ldots$ each involve finitely many variables.
Assume every finite set of constraints is satisfiable. For each $n$, let $T_n$
be the set of assignments to $v_1,\ldots,v_n$ that extend to an assignment
satisfying $C_1,\ldots,C_n$; this extension may freely assign all other
variables. Each $T_n$ is nonempty and finite. Restricting a member of
$T_{n+1}$ to its first $n$ entries gives a member of $T_n$.
These levels form a finitely branching tree with a node at every depth.
Starting at its root, select a child having descendants at arbitrarily large
depths. Such a child exists because there are finitely many children: if each
had a finite depth bound, their maximum would bound the parent's descendants.
Fix an ordering of $D$ and choose the first qualifying child at each step.
This constructs an infinite branch and a full assignment $a$.
For a particular $C_i$, choose $n$ at least $i$ and at least all variable
indices occurring in $C_i$. The first $n$ branch entries lie in $T_n$, so
extend to a solution of $C_i$; since its variables are already fixed, $a$
itself satisfies $C_i$. Hence all constraints are simultaneously satisfied.

The branch rule requires determining whether a node has arbitrarily deep
extensions. That is an infinitary property, not an algorithm of bounded local
radius and not a continuity or Borel-selection proof on an uncountable space
of instances. Compactness alone has not supplied any of the adjectives in the
table caption.

\paragraph{A fixed-radius satisfiability test cannot replace compactness.}
Take proper two-coloring constraints on an odd cycle of length $L>2r+1$,
where $r\geq1$. Every radius-$r$ induced neighborhood is a path and has a
proper two-coloring, obtained by alternating colors along its vertices.
The entire cycle is not two-colorable: following its $L$ edges flips a color
an odd number of times and returns the opposite color to the starting vertex.
Thus passing all radius-$r$ neighborhood satisfiability checks does not imply
a global solution. This does not contradict the compactness theorem, whose
hypothesis quantifies over \emph{every finite set of constraints}, including
all constraints of this finite cycle.
The discrepancy is exactly between independently chosen local witnesses and
one compatible assignment on their overlaps.
