\paragraph{Testing the density-one route.} A common attempted upgrade starts from an averaged variance estimate for a fixed observable. Abstractly, let \(a_j\ge0\) be its squared equidistribution error and suppose \(N^{-1}\sum_{j\le N}a_j\to0\). For every \(\delta>0\), the number of \(j\le N\) with \(a_j\ge\delta\) is at most \(\delta^{-1}\sum_{j\le N}a_j=o(N)\). This establishes a zero-density exceptional set for each fixed threshold, but not its absence.
\paragraph{An exact obstruction to the upgrade.} Set \(a_j=1\) when \(j\) is a perfect square and zero otherwise. Then
\[
 \frac1N\sum_{j\le N}a_j=\frac{\lfloor\sqrt N\rfloor}{N}\longrightarrow0,
 \qquad a_{n^2}=1.
\]
The same issue can be expressed by probability measures: take normalized volume measure except at square indices, where take a fixed point mass. For a continuous observable separating that point from its volume average, its errors behave exactly in this sparse way.
