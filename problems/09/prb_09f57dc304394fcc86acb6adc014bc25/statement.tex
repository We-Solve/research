A finite set $D=\{1<n_1<\cdots<n_k\}$ is a covering set if residues $a_i\pmod{n_i}$ can be chosen to cover $\mathbb Z$. Call $D$ irreducible if no proper subset admits any such covering choice. Determine the number of irreducible covering sets with $k$ elements, the smallest and largest possible $n_k$, and
\[\max_D\sum_{i=1}^k\frac1{n_i}.\]
Also, do infinitely many integers $m$ have the property that all their divisors greater than $1$ form an irreducible covering set?
