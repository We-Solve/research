\section*{UnsolvedMath ID: 701709}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
For a finite group \(G\) and \(g\in G\), define the conjugacy class of \(g\) and the number of conjugacy classes of \(G\) by
\[
[g]_G=\{xgx^{-1}:x\in G\},\qquad k(G)=\bigl|\{[g]_G:g\in G\}\bigr|.
\]
The group \(G\) is non-abelian if there exist \(a,b\in G\) such that \(ab\ne ba\), and it has odd order if \(|G|\) is an odd integer.

The question proposed by D. MacHale is whether, for every odd integer \(t>3\), there exists a finite non-abelian group \(G\) of odd order such that
\[
k(G)=t.
\]
\subsection{Short English statement}
Does every odd integer greater than \(3\) occur as the number of conjugacy classes of some finite non-abelian group of odd order?
