\section{Research attempt: Binary encoding preserves distributions only with support constraints}
Let a categorical variable have $q$ levels and choose an injective code
$c$ into $k=\lceil\log_2q\rceil$ bits. Pushing probabilities along $c$ gives
a bijection between categorical distributions and bit-vector distributions
supported on the code set: $P(c(a))=P(a)$ and unused codewords have probability
zero. Likelihoods of encoded samples and Shannon entropies are preserved by
reindexing their finite sums. The same holds for several variables when each
entire block of bits is treated as one vector-valued variable.

The attempted shortcut treats the new bits as unrestricted independent binary
variables. For three equally likely levels encoded by $00,01,10$, each bit
has success probability $1/3$, while $P(11)=0$. Independent bits with those
marginals would give $P(11)=1/9$, a contradiction. Thus a one-variable model
can acquire a nontrivial dependence constraint merely from its encoding.
All codeword probabilities being equal is not enough to make individual bits
independent.

With a one-hot code of length $q$, the constraint is instead exactly one
nonzero bit. This avoids unused labels in a different way but couples all
bits in the block. Dropping the constraint admits impossible categorical
observations. Conditional independence of categorical variables transfers to
conditional independence of whole code blocks, by the same event bijection;
it does not imply arbitrary independence assertions between their individual bits.

The distribution-level correspondence is therefore exact but does not by itself
preserve a sparse graphical representation, algorithm runtime, or the research
priority in the source discussion. An algorithm for unrestricted binary models
would need an encoding of structural zeros and block constraints, with its
cost charged, before it solves the categorical task.
