\subsection{Definitions and mathematical statement}
Let \(f:\C\to\C\) be an entire function. Write \(f^n\) for its \(n\)-fold iterate, and define its Fatou set \(F(f)\) to be the set of points having a neighborhood on which \(\{f^n:n\geq 0\}\) is a normal family with respect to the spherical metric. A Fatou component is a nonempty connected component of \(F(f)\). A Fatou component \(D\) is completely invariant if
\[
 f^{-1}(D)=D.
\]
Thus both \(f(D)\subseteq D\) and \(f^{-1}(D)\subseteq D\) hold; surjectivity of \(f:D\to D\) is not required.

For \(a\in\C\) and \(\varepsilon>0\), put
\[
 U(a,\varepsilon)=\{z\in\C:|f(z)-a|<\varepsilon\}.
\]
Following the supplied statement, call \(a\) a \emph{locally omitted value} of \(f\) if there exist \(\varepsilon>0\) and a nonempty connected component \(G\) of \(U(a,\varepsilon)\) such that
\[
 G\cap f^{-1}(\{a\})=\varnothing.
\]
The existential quantifier on \(\varepsilon\) makes explicit the implicit quantifier in the supplied wording. No additional condition involving nested components or smaller radii is imposed here.

\textbf{Question.} For every entire function \(f:\C\to\C\) and every completely invariant Fatou component \(D\) of \(f\), is it true that
\[
 \forall a\in\C,\qquad
 \left[
 \exists\varepsilon>0\ \exists G\text{ a connected component of }U(a,\varepsilon)
 \text{ with }G\cap f^{-1}(\{a\})=\varnothing
 \right]
 \Longrightarrow a\in D?
\]
The source statement says entire, without explicitly requiring transcendentality or finite order; those hypotheses are therefore not added to the question. The supplied dated curation reports a finite-order result and describes the general assertion as a conjecture. This is a statement-only draft, and that literature assessment has not been independently verified.
\subsection{Short English statement}
If an entire function has a completely invariant Fatou component \(D\), must every finite value omitted on some connected component of the inverse image of a sufficiently chosen disk centered at that value belong to \(D\)? The supplied curation labels the problem partially solved and reports the assertion for finite-order entire functions.
