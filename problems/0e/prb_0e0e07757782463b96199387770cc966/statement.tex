For the Diophantine setup, use the max norm and nonzero denominators. A vector $y\in\R^n$ is $v$-approximable if $|y\cdot q-p|<\|q\|_\infty^{-v}$ for infinitely many $q\in\Z^n\setminus\{0\}$, $p\in\Z$. It is very well approximable (VWA) if this holds with $v=n+\eps$ for some $\eps>0$. For $A\in M_{m,n}(\R)$ the source's powered-norm convention is
\[
 \|Aq-p\|_\infty^{m}<\|q\|_\infty^{-n-\eps}
\]
for infinitely many $q\in\Z^n\setminus\{0\}$, $p\in\Z^m$, for some $\eps>0$. The superscript $m$ is a power, not an additional coordinate or dimension parameter hidden in the norm.

The aid proves the following ambient tail estimate for every $m,n\geq1$. For each bounded matrix box $B$ and fixed $\eps>0$, define
\[
 E_{R,\eps}(B)=\{A\in B:\exists q\ne0,\ \|q\|_\infty\geq R,
 \ \exists p\in\Z^m:
 \|Aq-p\|_\infty^m<\|q\|_\infty^{-n-\eps}\}.
\]
There is $C=C(B,m,n,\eps)$ such that for all $R\geq1$,
\[
 \operatorname{Leb}(E_{R,\eps}(B))\leq CR^{-\eps}.
\]
For a fixed $q$ of max norm $Q$, put $\delta_Q=Q^{-(n+\eps)/m}$. Each row constraint cuts a slab of width at most a constant times $\delta_Q/Q$ in the coordinate where $|q_j|=Q$. The $m$ rows give $O((\delta_Q/Q)^m)$ volume, there are $O(Q^m)$ relevant numerators, and $O(Q^{n-1})$ denominator vectors in a max-norm shell. The resulting shell sum is $O(\sum_{Q\geq R}Q^{-1-\eps})=O(R^{-\eps})$. Constants are for the fixed bounded box and fixed positive $\eps$.

Letting $R\to\infty$ shows the infinite-solution set for fixed $\eps$ is null. Taking the countable union over $\eps=1/j$ and bounded boxes gives ambient Lebesgue-nullity of all VWA matrices. The $m=1$ statement includes the vector normalization. No estimate uniform as $\eps\to0$ is asserted.
