\section*{UnsolvedMath ID: 701311}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(G\) be a group with identity \(1_G\). For \(u,v\in G\), define \([u,v]=u^{-1}v^{-1}uv\). For each positive integer \(n\), define the left-normed iterated commutator recursively by
\[
[x,{}_1 a]=[x,a],\qquad [x,{}_{n+1}a]=[[x,{}_n a],a].
\]
An element \(a\in G\) is a \emph{left Engel element} if
\[
\forall x\in G\;\exists n\in\mathbb Z_{\geq 1}\quad [x,{}_n a]=1_G.
\]
The integer \(n\) may depend on \(x\); no uniform bound is required.

Does there exist a group \(G\) and elements \(a,x_0\in G\) such that
\[
\left(\forall x\in G\;\exists n\in\mathbb Z_{\geq 1}\quad [x,{}_n a]=1_G\right)
\quad\text{and}\quad
\left(\forall m\in\mathbb Z_{\geq 1}\quad [x_0,{}_m(a^{-1})]\neq 1_G\right)?
\]
No finiteness or other restriction on \(G\) is imposed in the supplied statement. The supplied registry labels the problem open; that status has not been independently verified.
\subsection{Short English statement}
Does some group contain a left Engel element whose inverse fails to be a left Engel element? The Engel condition allows the number of commutator iterations to depend on the chosen group element.
