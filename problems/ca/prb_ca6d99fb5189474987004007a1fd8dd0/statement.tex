\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(G\) be an arbitrary group, and let \(C,F\leq G\) be cyclic subgroups, with \(F\) finite. No finiteness assumption is imposed on \(C\) or \(G\). Define
\[
CFC=\{c_1fc_2:c_1,c_2\in C,\ f\in F\}.
\]
The index \([G:C]\) is the cardinality of the set of left cosets \(\{gC:g\in G\}\).

Is the following assertion true: for every such \(G,C,F\),
\[
G=CFC\quad\Longrightarrow\quad [G:C]<\infty?
\]
The supplied source also says ``Cf.\ 12.62''; the referenced problem is not included in the record, so its relationship to this assertion remains unspecified.
\subsection{Short English statement}
Must a cyclic subgroup \(C\) have finite index in a group \(G\) whenever every element of \(G\) can be written as \(c_1fc_2\), with \(c_1,c_2\in C\) and \(f\) in a fixed finite cyclic subgroup \(F\)? The supplied registry labels this problem open; that status is not independently verified.
