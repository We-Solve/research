\subsection{Definitions and mathematical statement}
Let \(G\) be a group generated by a finite set \(S\). Use the standard word-length convention
\[
\ell_S(g)=\min\{n\geq 0:g=s_1\cdots s_n,\ s_i\in S\cup S^{-1}\},
\]
where the empty product is the identity. For a finite alphabet \(X\), let \(X^*=\bigcup_{n\geq0}X^n\) be the set of finite words, including the empty word; juxtaposition denotes concatenation.

Following the supplied definition, call \(G\) \emph{contracting} if there exist a faithful action \(G\curvearrowright X^*\) for some finite alphabet \(X\), and real constants \(0<\lambda<1\) and \(C>0\), such that
\[
\forall g\in G\ \forall x\in X\ \exists h\in G\ \exists y\in X:
\quad \ell_S(h)<\lambda\ell_S(g)+C
\quad\text{and}\quad
\forall w\in X^*,\quad g\cdot(xw)=y(h\cdot w).
\]
Here faithfulness means that an element fixing every word is the identity. The choices of \(h\) and \(y\) may depend on \(g\) and \(x\), but must work simultaneously for every \(w\).

A group \(G\) is \emph{amenable} if there exists a finitely additive probability measure \(\mu:\mathcal P(G)\to[0,1]\) satisfying \(\mu(G)=1\), \(\mu(\varnothing)=0\), and
\[
\mu(A\cup B)=\mu(A)+\mu(B)\quad(A\cap B=\varnothing),
\qquad
\mu(gA)=\mu(A)\quad(g\in G,\ A\subseteq G).
\]
It is non-amenable if no such measure exists.

\textbf{Part (b), the remaining question in the supplied record.} Does there exist a finitely generated group \(G\), with a finite generating set \(S\), that satisfies the contracting condition above and is non-amenable?
