\subsection{Definitions and mathematical statement}
For a positive integer \(d\), let \(\lambda_d\) denote Lebesgue measure on \([0,1]^d\). A \(d\)-dimensional copula is a function \(C:[0,1]^d\to[0,1]\) of the form
\[
C(u_1,\ldots,u_d)=\mu_C\!\left(\prod_{j=1}^d[0,u_j]\right),
\]
where \(\mu_C\) is a Borel probability measure on \([0,1]^d\) whose every one-dimensional marginal is uniform on \([0,1]\). In particular, \(C(u)=0\) whenever a coordinate of \(u\) is zero, and \(C(1,\ldots,1,t,1,\ldots,1)=t\) for every coordinate position and \(t\in[0,1]\). Write \(\mathcal C_d\) for the set of these copulas. \[
\mathcal S_d=\{C\in\mathcal C_d:\mu_C\perp\lambda_d\}.
\]
