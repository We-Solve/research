Write \((M,d,\mu)\) for the compact metric probability space in the supplied record. Let \(G\) be a finitely generated group acting on \(M\) by measure-preserving Lipschitz homeomorphisms. Ergodicity means that every measurable set invariant under the action modulo null sets has measure zero or one. Choose a finite symmetric generating set \(S\subseteq G\). Put
\[
L^2_0(M,\mu)=\left\{f\in L^2(M,\mu):\int_M f\,\dd\mu=0\right\},
\qquad U_s f(x)=f(s^{-1}x).
\]
The action has a spectral gap if there is \(\kappa>0\) such that
\[
\sum_{s\in S}\|U_s f-f\|_2^2\geq \kappa\|f\|_2^2
\quad\text{for every }f\in L^2_0(M,\mu).
\]
