\section*{UnsolvedMath ID: 800226}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(n\geq 1\) be an integer. A set \(X\subset\C^n\) is totally disconnected if every connected subset of \(X\) has at most one point. With respect to the Euclidean metric on \(\C^n\), its one-dimensional Hausdorff measure is
\[
\mathcal H^1(X)=\lim_{\delta\downarrow0}\inf\left\{\sum_{j=1}^{\infty}\operatorname{diam}(U_j): X\subseteq\bigcup_{j=1}^{\infty}U_j,\ \operatorname{diam}(U_j)<\delta\text{ for all }j\right\}.
\]
For a nonempty compact set \(X\subset\C^n\), define its polynomial hull by
\[
\widehat X=\left\{z\in\C^n: |p(z)|\leq\max_{x\in X}|p(x)|\text{ for every }p\in\C[z_1,\ldots,z_n]\right\}.
\]
Set \(\widehat\varnothing=\varnothing\). A compact set is polynomially convex if \(\widehat X=X\).

\textbf{Question (H. Alexander).} For every integer \(n\geq1\) and every compact, totally disconnected set \(X\subset\C^n\) satisfying \(\mathcal H^1(X)<\infty\), must \(\widehat X=X\)? The measure hypothesis permits \(\mathcal H^1(X)=0\); no positivity assumption is imposed.
\subsection{Short English statement}
Must every compact, totally disconnected subset of \(\C^n\) with finite one-dimensional Hausdorff measure be polynomially convex? The supplied registry labels this question open; that label is not an independently verified assessment.
