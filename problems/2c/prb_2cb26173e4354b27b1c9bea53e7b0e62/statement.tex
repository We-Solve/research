{\small\sffamily UnsolvedMath ID 20001237 · Computer Science}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


For a statistical model with parameter $\theta$ and observations $D$, the likelihood is $L(\theta;D)=\Pr_\theta(D)$, or the corresponding density. Maximum likelihood seeks a global maximum over the admissible parameter space. For an integer matrix $A$, the fiber at $b$ is $\mathcal F_b=\{x\in\mathbb Z_{\ge0}^d:Ax=b\}$. A Markov basis is a finite set of integer moves $u$ with $Au=0$ such that steps $x\mapsto x\pm u$ staying nonnegative connect every nonempty fiber. In a log-linear model, sufficient statistics are $b=Ax$. A zero-dimensional likelihood solution space has finitely many algebraic points, counted with multiplicity; positive-dimensional fibers contain algebraic families of solutions. The task is to describe exceptional statistic vectors giving nonzero-dimensional likelihood solution sets.
