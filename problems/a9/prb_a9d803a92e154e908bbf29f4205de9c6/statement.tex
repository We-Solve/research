For primes $p_1<\cdots<p_u$ and an integer $k\geq1$, define the guaranteed number of covered integers in an interval by
\[
F_k(p_1,\ldots,p_u)=\min_{m\geq0}\bigl|\{a\in\{m+1,\ldots,m+k\}:p_i\mid a\text{ for some }i\}\bigr|.
\]
Estimate this quantity, especially when $k=\alpha p_u$ for a fixed $\alpha>2$.
