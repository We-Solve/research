\section{Enumeration and Typical Structure of $k$-SAT Functions}\label{statement}

\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


A Boolean function maps $\{0,1\}^n$ to $\{0,1\}$. A $k$-SAT function is represented by a conjunction of clauses of width at most $k$, each clause a disjunction of literals $x_i$ or $\neg x_i$; distinct formulas computing the same function count once. Uniformly choosing a function means choosing from this finite set of distinct functions. A function is unate if complementing an appropriate subset of input coordinates makes it monotone in every coordinate. As $n\to\infty$, $o(1)$ tends to zero.
\paragraph{Statement recorded in the supplied source.}
How many $k$-SAT functions on $n$ Boolean variables are there, and what does a typical such function look like? In particular, for fixed $k\geq 2$, is a $1-o(1)$ fraction of all such functions unate? \href{https://doi.org/10.4171/owr/2022/22}{[S2]}
\paragraph{Scope qualification.}
Here functions, not syntactic formulas, are counted. The asymptotic question fixes the clause width before letting the number of variables grow.
\paragraph{Source status.}
The supplied catalogue labels this record partially solved. Its source-status metadata was checked against the supplied snapshot on 2026-10-11. This import does not independently establish current open status or mathematical correctness. The catalogue literature assessment is dated 2026-08-22.
\subsection{Short English statement}
Count distinct bounded-clause-width Boolean functions and determine whether almost all are monotone after suitable input-coordinate flips.

\section{Research attempt: Collision-free unate lower bound and failure of formula counting}

\paragraph{A formula family that can be counted without collisions.}
Use the source's equivalent DNF formulation. For $1\leq k\leq n$ and a family
$\mathcal H\subseteq\binom{[n]}k$, define
\[
 f_{\mathcal H}(x)=\bigvee_{S\in\mathcal H}\ \bigwedge_{i\in S}x_i.
\]
The empty disjunction is zero. On the input $1_T$ with exactly $k$ ones,
$f_{\mathcal H}(1_T)=1$ if and only if $T\in\mathcal H$, because a $k$-set
$S$ is contained in the $k$-set $T$ only when $S=T$.
Thus these $2^{\binom nk}$ formulas represent distinct functions. Every clause
is indispensable: $1_S$ is a private satisfying input for its own clause.
A variable $i$ is essential exactly when some $S\in\mathcal H$ contains it.
Indeed $1_S$ and $1_{S\setminus\{i\}}$ distinguish its two values; if no clause
contains $i$, independence is immediate.
With each possible clause independently included with probability $1/2$, the
probability that a specified variable is absent is
$2^{-\binom{n-1}{k-1}}$. A union bound shows that at least
\[
 \left(1-n2^{-\binom{n-1}{k-1}}\right)2^{\binom nk}
\]
functions in this family depend on all variables, whenever the displayed lower
bound is positive. Each has $2^n$ different input-coordinate sign orientations,
and the resulting functions over all such families are distinct. To prove this,
a function monotone in both directions in a coordinate must be independent of
that coordinate: with all other inputs fixed, its two values satisfy both
opposite inequalities. An essential coordinate therefore has a unique monotonic
direction. Equality of two oriented functions forces their orientations to agree,
after which the $k$-weight evaluations identify $\mathcal H$.
Consequently the total number $N(n,k)$ of source functions satisfies
\[
 N(n,k)\geq
 \left(1-n2^{-\binom{n-1}{k-1}}\right)2^{\binom nk+n}.
\]
Complementing the output gives the corresponding CNF count if that convention
is preferred. This is a lower bound for a specifically constructed subclass;
it does not count all possible prime implicants of a general unate function.

\paragraph{The missing upper bound cannot be obtained by counting syntax.}
For fixed $k\geq2$, the error $n2^{-\binom{n-1}{k-1}}$ tends to zero, so the
lower bound has the expected $2^{\binom nk+n}$ scale. The naive syntax bound,
however, chooses arbitrary subsets of the $2^k\binom nk$ consistent signed
$k$-clauses and gives only $N(n,k)\leq2^{2^k\binom nk}$.
It is much too large to prove typical unateness.
The obstruction is concrete even for $k=2$:
\[
 (x_1\wedge x_2)\vee(x_1\wedge\neg x_2)=x_1.
\]
Adding any clauses of the form $x_1\wedge x_j$ or $x_1\wedge\neg x_j$ leaves
this function unchanged. Even testing whether syntax is minimal requires logical
implication rather than just absence of repeated clauses: for $k=2$,
\[
 (x_1x_2)\vee(\neg x_1x_3)\vee(x_2x_3)
 =(x_1x_2)\vee(\neg x_1x_3),
\]
where juxtaposition means conjunction. If $x_2x_3=1$, one of the first two
clauses is true according to the value of $x_1$, proving the redundancy.
This identity identifies the first gap in an attempted independent-clause upper
bound: private witnesses, overlaps and logical implication must be controlled,
not merely the number of available clauses. The lower-bound argument does not
provide that control and does not re-prove the known fixed-$k$ theorem.

\section{Verification and adversarial audit}

The injectivity check uses inputs of weight exactly $k$, which is why every
chosen clause must use $k$ distinct variables. Essentiality is checked by an
explicit pair of inputs; orientation multiplicity is asserted only for essential
functions. At $k=1$ the union-bound error does not vanish, and at $k=n$ the essentiality
probability is exactly $1/2$, rather than tending to one, so neither endpoint is used in the fixed
$k\geq2$, $n\to\infty$ conclusion. The two Boolean identities were checked
by splitting on $x_1$ or $x_2$, not by assuming distinct formulas are distinct
functions.
