\subsection{Definitions and mathematical statement}
In the usual finite-dimensional formulation, let \(n\geq 1\) and let \(D\subset\C^n\) be a bounded domain, meaning a nonempty connected open set. Write \(\mathbb B^n=\{z\in\C^n:\|z\|_2<1\}\). For \(p\in D\), define the squeezing function by
\[
s_D(p)=\sup\bigl\{r\in(0,1]:\text{there exists an injective holomorphic map }f:D\to\mathbb B^n,\ f(p)=0,\ r\mathbb B^n\subseteq f(D)\bigr\}.
\]
The domain \(D\) is homogeneous if its group \(\operatorname{Aut}(D)\) of biholomorphic self-maps acts transitively: for every \(p,q\in D\), there exists \(\phi\in\operatorname{Aut}(D)\) with \(\phi(p)=q\). Biholomorphic invariance of the squeezing function then makes \(s_D\) constant; denote its value by \(s(D)\).

\textbf{Problem.} Determine \(s(D)\) for every bounded homogeneous domain \(D\subset\C^n\), with \(n\geq1\) arbitrary.

\subsection{Short English statement}
For each bounded homogeneous complex domain, determine the common value of its squeezing function, which measures how large a centered Euclidean ball can fit inside an injective holomorphic image of the domain in the unit ball. The displayed formulation uses finite-dimensional domains; any intended infinite-dimensional scope requires clarification.
