\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


For a statistical model with parameter $\theta$ and observations $D$, the likelihood is $L(\theta;D)=\Pr_\theta(D)$, or the corresponding density. Maximum likelihood seeks a global maximum over the admissible parameter space. A three-way table is a nonnegative array $x_{ijk}$, with two-way margins obtained by summing over one index. Holes mark entries or margins that have not been observed. Completing these data requires compatibility of the specified counts and margins, followed by estimation within the intended statistical model.
\paragraph{Statement recorded in the supplied source.}
Problem 56 (Fienberg). Consider 3-way table missing data problem. This consists of a 3-way table with holes and 2-way margins which also have holes.. How can you estimate the likelihood and "glue" this information together into a good global picture of the whole table? Can this problem be formulated as an algebraic variety? \sref{statement}{2}
