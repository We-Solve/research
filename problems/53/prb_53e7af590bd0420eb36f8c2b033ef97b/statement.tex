\subsection{Definitions and mathematical statement}
For a positive integer \(n\), a permutation of length \(n\) is a sequence containing each element of \(\{1,\ldots,n\}\) exactly once. A permutation \(\pi\) contains a pattern \(\sigma\) if some subsequence of \(\pi\) has the same relative order as \(\sigma\); otherwise it avoids \(\sigma\). A permutation class is a collection closed under taking patterns. Write \(\operatorname{Av}(B)\) for the class avoiding every pattern in \(B\). The separable permutations form the class
\[
\mathcal S=\operatorname{Av}(2413,3142).
\]
Here a subclass means a permutation class contained in the specified class, with no finite-basis assumption.

For permutations \(\alpha\) and \(\beta\) of lengths \(a\) and \(b\), respectively, define
\[
\alpha\oplus\beta=(\alpha_1,\ldots,\alpha_a,a+\beta_1,\ldots,a+\beta_b),
\qquad
\alpha\ominus\beta=(b+\alpha_1,\ldots,b+\alpha_a,\beta_1,\ldots,\beta_b).
\]
For classes \(A,B\), let \(A\oplus B=\{\alpha\oplus\beta:\alpha\in A,\ \beta\in B\}\), and define \(A\ominus B\) analogously. A class \(D\) is sum closed if \(D\oplus D\subseteq D\), and skew closed if \(D\ominus D\subseteq D\).

For a permutation \(\sigma\) of length \(k\) and nonempty permutations \(\tau_1,\ldots,\tau_k\), the inflation \(\sigma[\tau_1,\ldots,\tau_k]\) replaces each entry \(\sigma_i\) by a consecutive block order-isomorphic to \(\tau_i\), with the blocks ordered in value according to \(\sigma\). For classes \(X,U\), write
\[
X[U]=\{\sigma[\tau_1,\ldots,\tau_k]:k\geq1,\ \sigma\in X\cap S_k,\ \tau_i\in U\text{ for all }i\}.
\]
Set
\[
X=\operatorname{Av}(2413,3142,2143,3412).
\]
