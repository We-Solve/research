\section{Research attempt: When a linear projection preserves closed dynamics}
Let the dynamics be $x_{t+1}=Ax_t$ on $K^n$ and let the observed reduced state be $y_t=Px_t$, where $P:K^n\to K^k$ is surjective. An exact autonomous linear reduced model valid for every initial state exists if and only if
\[
A(\ker P)\subseteq\ker P.
\]
Indeed, if $PA=BP$ for some $k\times k$ matrix $B$, then $Pv=0$ implies $PAv=BPv=0$. Conversely, under the kernel condition define $B(Px)=PAx$. This is well-defined: two choices of $x$ differ by a vector in $\ker P$, whose image under $PA$ is zero. It is linear, and surjectivity of $P$ defines it on all $K^k$. Its defining equation gives $PA=BP$, and iteration yields $Px_t=B^tPx_0$. Uniqueness of $B$ follows from surjectivity.

The need for closure cannot be certified by low snapshot rank alone. Set
\[
A=\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad P=\begin{pmatrix}1&0\end{pmatrix}.
\]
The states $(0,0)$ and $(0,1)$ have the same reduced state zero, but next reduced states zero and one. Thus no deterministic map of the current reduced state, linear or nonlinear, can describe all projected updates. Algebraically, $e_2\in\ker P$ while $Ae_2=e_1\notin\ker P$.

If training initial states all lie on the first coordinate axis, their snapshot matrix has rank at most one and all their first projected updates are zero. A fitted rule $y_{t+1}=0$ interpolates those one-step observations exactly. But from $x_0=(1,0)$ the projected trajectory is $1,0,1,0,\ldots$, so the learned rule fails at the next step. Retaining memory repairs this particular example: eliminating the second coordinate gives $y_{t+2}=y_t$, and the pair $(y_t,y_{t+1})$ evolves by a two-dimensional swap. This repair explicitly gives up the claimed one-dimensional autonomous state.
