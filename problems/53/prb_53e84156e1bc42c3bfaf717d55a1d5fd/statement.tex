\subsection{Definitions and mathematical statement}
In a metric Markov setting, let $(X,d)$ be the state space and $m_x$ the one-step transition probability from $x$. When these probabilities have finite first moment, write $W_1$ for their optimal transport distance with cost $d$ and set
\[
 \kappa(x,y)=1-\frac{W_1(m_x,m_y)}{d(x,y)}\qquad(x\ne y).
\]
The source asks for transportation inequalities or other functional inequalities expressing the concentration consequences of positive coarse Ricci curvature. It seeks a genuinely coarse formulation allowing non-Gaussian tails at small measures or scales, and suggests a quadratic-then-linear transport cost as one possibility.

To describe the suggested type of inequality, if $\mu$ is an appropriate reference probability and $\alpha:[0,\infty)\to[0,\infty)$ is a cost function, define
\[
 \mathcal T_\alpha(\nu,\mu)
 =\inf_{\pi\in\Pi(\nu,\mu)}\int\alpha(d(x,y))\,\mathrm d\pi(x,y),
\]
where $\Pi(\nu,\mu)$ is the set of couplings. Relative entropy is
\[
 H(\nu\mid\mu)=\int\log\!\left(\frac{\mathrm d\nu}{\mathrm d\mu}\right)\,\mathrm d\nu
\]
when $\nu$ is absolutely continuous with respect to $\mu$, and is $+\infty$ otherwise. A representative transport-entropy target would be to determine hypotheses, $\alpha$, and a constant $C$ for which
\[
 \mathcal T_\alpha(\nu,\mu)\le C H(\nu\mid\mu)
\]
for the intended class of $\nu$, with $\alpha$ behaving quadratically below a crossover scale and linearly above it.
