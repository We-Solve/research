The scalar field is also unspecified. Fix \(\mathbb K\in\{\R,\C\}\) for either reading, and put \(H=\ell_2(\N;\mathbb K)\).

A map \(f:M\to N\) between metric spaces is a \emph{coarse embedding} if there exist nondecreasing functions \(\rho_-,\rho_+:[0,\infty)\to[0,\infty)\), with \(\lim_{t\to\infty}\rho_-(t)=\infty\), such that
\[
 \rho_-(d_M(u,v))\le d_N(f(u),f(v))\le\rho_+(d_M(u,v))
 \qquad(u,v\in M).
\]
Banach spaces carry their norm metrics. Saying that \(X\) \emph{coarsely contains} \(H\) means that a coarse embedding \(H\to X\) exists; no linearity is required. A Banach space is \emph{superreflexive} if it admits an equivalent uniformly convex norm. A norm \(|\cdot|\) is uniformly convex if for every \(\varepsilon\in(0,2]\) there is \(\delta>0\) such that
\[
 |x|=|y|=1,\quad |x-y|\ge\varepsilon
 \quad\Longrightarrow\quad
 \left|\frac{x+y}{2}\right|\le 1-\delta.
\]

For a \(k\)-dimensional normed space \(E\) over \(\mathbb K\), write
\[
 d_{\mathrm{BM}}(E,\ell_2^k(\mathbb K))
 =\inf_T\|T\|\,\|T^{-1}\|,
\]
where the infimum ranges over linear isomorphisms \(T:E\to\ell_2^k(\mathbb K)\). Use the following conventional definitions for the second question. A Banach space \(Y\) is \emph{weak Hilbert} if there exist \(\delta\in(0,1]\) and \(C\ge1\) such that every nonzero finite-dimensional subspace \(E\subseteq Y\) contains a subspace \(F\) satisfying
\[
 \dim F\ge\delta\dim E,\qquad
 d_{\mathrm{BM}}(F,\ell_2^{\dim F}(\mathbb K))\le C,
\]
and there is a bounded linear projection \(P:Y\to F\), with \(P|_F=\operatorname{id}_F\) and \(\|P\|\le C\). Use \emph{asymptotically Hilbertian} to mean that there exists \(C\ge1\) such that for every integer \(n\ge1\) there is a closed finite-codimensional subspace \(Z_n\subseteq Y\) for which
\[
 d_{\mathrm{BM}}(E,\ell_2^{\dim E}(\mathbb K))\le C
 \quad\text{whenever }E\subseteq Z_n\text{ and }1\le\dim E\le n.
\]

An \emph{expander sequence}, under the convention used here, is a sequence \((G_n)_{n\ge1}\) of finite connected simple undirected graphs \(G_n=(V_n,E_n)\), with \(|V_n|\ge2\), such that \(|V_n|\to\infty\), the vertex degrees are bounded by a common finite constant, and
\[
 \inf_{n\ge1}h(G_n)>0,\qquad
 h(G_n)=\min_{\substack{A\subseteq V_n\\0<|A|\le |V_n|/2}}
 \frac{|\partial_{E_n}A|}{|A|},
\]
where \(\partial_{E_n}A\) consists of edges with exactly one endpoint in \(A\). Equip \(V_n\) with the unscaled shortest-path metric \(d_{G_n}\). The sequence \emph{equi-coarsely embeds} into \(Y\) if there are maps \(f_n:V_n\to Y\) and a single pair of control functions \(\rho_-,\rho_+\) as above such that
\[
 \rho_-(d_{G_n}(u,v))\le\|f_n(u)-f_n(v)\|_Y
 \le\rho_+(d_{G_n}(u,v))
 \qquad(n\ge1,\ u,v\in V_n).
\]
Thus the controls are independent of \(n\).
