\subsection{Definitions and mathematical statement}
Let \(S^1=\R/\Z\), and let \(m\) be normalized Lebesgue measure on \(S^1\), so that \(m(S^1)=1\). Write \(\operatorname{Diff}^{2}(S^1)\) for the group of circle diffeomorphisms whose maps and inverses are of class \(C^2\). A subgroup \(G\leq\operatorname{Diff}^{2}(S^1)\) is finitely generated if some finite subset generates \(G\) as a group. A nonempty closed set \(\Lambda\subseteq S^1\) is \(G\)-invariant if \(g(\Lambda)=\Lambda\) for every \(g\in G\), and is minimal if it contains no proper nonempty closed \(G\)-invariant subset. Here an \emph{exceptional minimal set} means a minimal invariant set that is a Cantor set: a nonempty compact perfect nowhere dense subset of \(S^1\).

\textbf{Question (catalogue entry).} For every finitely generated subgroup \(G\leq\operatorname{Diff}^{2}(S^1)\) and every exceptional minimal set \(\Lambda\) for its action, must
\[
 m(\Lambda)=0
\]
hold?
