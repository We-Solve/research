\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(n\geq 1\) be an integer. A matroid of rank \(n\) consists of a ground set \(E\) and a collection \(\mathcal I\) of finite subsets of \(E\), called independent sets, satisfying: \(\varnothing\in\mathcal I\); every subset of an independent set is independent; and whenever \(I,J\in\mathcal I\) satisfy \(|I|<|J|\), some \(e\in J\setminus I\) satisfies \(I\cup\{e\}\in\mathcal I\). The maximum cardinality of an independent set is \(n\). A basis is a maximal independent set; every basis therefore has \(n\) elements. Write \(\mathcal B(M)\) for the set of bases of \(M\). No finiteness assumption on \(E\) beyond finite rank is imposed here.

\textbf{Kahn's matroidal Rota basis conjecture, as supplied.} For every integer \(n\geq 1\), every rank-\(n\) matroid \(M\), and every indexed family
\[
(B_{i,j})_{1\leq i,j\leq n},\qquad B_{i,j}\in\mathcal B(M),
\]
there exist elements \(b_{i,j}\in B_{i,j}\) such that
\[
\{b_{i,1},\ldots,b_{i,n}\}\in\mathcal B(M)
\quad\text{for every }i\in\{1,\ldots,n\},
\]
and
\[
\{b_{1,j},\ldots,b_{n,j}\}\in\mathcal B(M)
\quad\text{for every }j\in\{1,\ldots,n\}.
\]
The input bases need not be distinct or disjoint. The basis requirements force distinct representatives within each row and within each column; no global distinctness requirement is stated. If rank zero is allowed, the corresponding empty-array assertion is vacuous.

The supplied record labels this problem partially solved. Its dated assessment says that the full conjecture remains unresolved, that Buci\'{c}, Kwan, Pokrovskiy, and Sudakov establish a roughly half-row partial result, and that later work gives asymptotically many transversal bases in the Rota special case. These are supplied curation claims, not independently verified conclusions. The record does not specify the exact quantitative partial results or their hypotheses.
\subsection{Short English statement}
For any square array of bases of one rank-\(n\) matroid, choose one element from each entry so that every row and every column of chosen elements is a basis. The supplied partially solved status and literature summary require independent verification.
