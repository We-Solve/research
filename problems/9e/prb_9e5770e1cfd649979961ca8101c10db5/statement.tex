\[
\mathcal S(\tau)=\{\text{smooth four-manifolds }M\text{ with }M\simeq\tau\}/\text{diffeomorphism}.
\]
A surgery procedure is intended as a controlled smooth modification, for example replacing a codimension-zero piece $U\subset M$ by a piece $V$ using a specified boundary diffeomorphism, producing $(M\setminus\operatorname{int}U)\cup_\varphi V$. This description is general context, not a restriction to ordinary sphere surgery.

Is there a useful list of such procedures that generates every element of $\mathcal S(\tau)$? Thus the record asks for a surgery-generation program, not a fixed finite move theorem with supplied axioms.
