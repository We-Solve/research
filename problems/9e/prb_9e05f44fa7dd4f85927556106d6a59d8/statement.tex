Write \(C[0,1]=C([0,1];\mathbb K)\) for the Banach space of continuous functions with norm \(\|f\|_\infty=\sup_{t\in[0,1]}|f(t)|\), and write
\[
c_0=\{(a_n)_{n\geq1}\in\mathbb K^{\N}:a_n\longrightarrow0\},\qquad \|(a_n)\|_\infty=\sup_{n\geq1}|a_n|.
\]
A Banach space contains a copy of another Banach space if it has a closed linear subspace isomorphic to that space by a bounded linear map with bounded inverse. A bounded linear operator \(T:C[0,1]\to C[0,1]\) \emph{fixes a copy of} a Banach space \(Y\) if there exist a closed subspace \(E\subseteq C[0,1]\), isomorphic to \(Y\), and a constant \(c>0\) such that
\[
\|Tf\|_\infty\geq c\|f\|_\infty\qquad(f\in E).
\]
Thus \(T|_E\) is an isomorphism onto its image.
