\subsection{Definitions and mathematical statement}
The exact Euclidean shortest vector problem takes a nonsingular integer matrix \(B\in\Z^{n\times n}\), encoded in binary, defining the full rank lattice
\[
 L(B)=\{Bz:z\in\Z^n\}\subset\R^n.
\]
Its output is a vector \(v\in L(B)\setminus\{0\}\) with
\[
 \|v\|_2=\lambda_1(L(B)):=\min\{\|w\|_2:w\in L(B)\setminus\{0\}\}.
\]
The dimension \(n\) is part of the input, and the requested answer is exact, not an approximation within a factor. The source asks whether this search problem is NP-hard.

A corresponding decision task, useful for specifying hardness reductions, takes a nonnegative rational threshold \(t\) and asks whether \(\lambda_1(L(B))^2\leq t\). An exact shortest-vector output determines this answer. The source does not specify the reduction type intended by NP-hardness of its search task.
