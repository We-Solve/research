\section*{UnsolvedMath ID: 701525}
\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
A group is \emph{periodic} if every element has finite order. An \emph{involution} is an element of order exactly \(2\). A group is \emph{locally finite} if every subgroup generated by finitely many elements is finite. For \(t\in G\), its centralizer is
\[
C_G(t)=\{g\in G:gt=tg\}.
\]
Is the following assertion true? For every periodic group \(G\) containing at least one involution, if \(C_G(t)\) is locally finite for every involution \(t\in G\), then there exists a subgroup \(N\) such that
\[
\{1\}\ne N\trianglelefteq G
\quad\text{and}\quad N\text{ is locally finite}.
\]
The subgroup \(N\) is not required to be proper in \(G\).
\subsection{Short English statement}
Must every periodic group containing involutions, all of whose involution centralizers are locally finite, have a nontrivial locally finite normal subgroup? The supplied registry labels this problem open; that label is not independently verified here.
