Write \(\operatorname{PSH}(X,\omega)\) for the upper semicontinuous, locally integrable functions \(\varphi:X\to[-\infty,\infty)\) satisfying \(\omega+dd^c\varphi\geq0\) in the sense of currents. Set
\[
\operatorname{Vol}_{\omega}(X)=\int_X\omega^n.
\]
For bounded \(\omega\)-plurisubharmonic functions, interpret \((\omega+dd^c\varphi)^n\) using the locally bounded complex Monge--Amp\`ere product.

Under the usual bounded-approximation interpretation, define \(DMA(X,\omega)\) to consist of those \(\varphi\in\operatorname{PSH}(X,\omega)\) for which there is a positive Radon measure \(\mu_\varphi\) such that, for every sequence
\[
\varphi_j\in\operatorname{PSH}(X,\omega)\cap L^\infty(X),
\qquad \varphi_j\searrow\varphi,
\]
one has
\[
\lim_{j\to\infty}\int_X f\,(\omega+dd^c\varphi_j)^n
=\int_X f\,d\mu_\varphi
\qquad\text{for every }f\in C(X,\R).
\]
In particular, the limiting measure must be independent of the decreasing approximating sequence. Denote it by \((\omega+dd^c\varphi)^n\).
