\subsection{Definitions and mathematical statement}
Work in the computable language of ordered fields. A real closed field is recursively saturated if every recursive partial type over finitely many of its elements which is finitely satisfiable in the field is realized there. A Scott set is a nonempty family $S\subseteq\mathcal P(\N)$ closed under Turing reducibility and finite Turing joins, such that every infinite binary tree computable from an element of $S$ has a path whose code belongs to $S$.

The source asks which standard systems, in the Macintyre--Marker convention for recursively saturated real closed fields, are possible, suggesting ``all Scott sets.'' To specify the representation convention, call a structure $S$-saturated when each complete type of a finite tuple is computable from a member of $S$, and every partial type over a finite tuple, computable from a member of $S$ and finitely satisfiable in the structure, is realized. The supplied research aid reports that the associated Scott set is unique for the effectively perfect theory of real closed fields, and that every Scott set is represented by an $S$-saturated real closed field. It attributes the full representation theorem to Dolich, Knight, Lange and Marker (2015). Thus, in that standard-system convention, the reported answer is precisely all Scott sets.
