\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \((W,S)\) be a Coxeter system. For \(w\in W\), its length with respect to \(S\) is
\[
\ell(w)=\min\{k\in\Z_{\geq 0}:w=s_1\cdots s_k,\ s_i\in S\},
\]
where the empty product is the identity. The set of reflections is
\[
T=\{wsw^{-1}:w\in W,\ s\in S\}.
\]
For finite \(S\), define the reflection length-enumerating series
\[
R_{W,S}(x)=\sum_{t\in T}x^{\ell(t)}=\sum_{n\geq 0}\bigl|\{t\in T:\ell(t)=n\}\bigr|x^n\in\Z[[x]].
\]
Here \(\ell(t)\) is length in the simple generators \(S\), not length in the reflection generating set \(T\).

\textbf{Problem (attributed to Stembridge in the supplied source).} Is it true that for every Coxeter system \((W,S)\) with \(S\) finite there exist polynomials \(P,Q\in\Q[x]\), with \(Q(0)\ne 0\), such that
\[
Q(x)R_{W,S}(x)=P(x)
\quad\text{in }\Q[[x]]?
\]

\textbf{Unresolved scope qualification.} The supplied wording quantifies over Coxeter systems without explicitly requiring \(S\) to be finite. The formulation above makes that hypothesis explicit so that all coefficients are finite. If \(S\) is infinite, then every element of \(S\) is a reflection of length one, so the displayed sum does not define an ordinary formal power series with integer coefficients. The intended convention on Coxeter systems therefore requires confirmation.

The supplied source presents rationality of the ordinary growth series \(\sum_{u\in W}x^{\ell(u)}\) as known background, citing [Hum, Proposition 5.12] and [BB, Corollary 7.1.4]. This background is distinct from the reflection-enumerating question.
\subsection{Short English statement}
The question asks whether, for every Coxeter system with finitely many simple generators, the generating function counting reflections by their length in those generators is rational. The supplied record labels the problem open and attributes its proposal to Stembridge; these are supplied source claims. Finiteness of the generating set is an explicit scope qualification requiring review.
