\paragraph{A local cusp test compatible with reflection symmetry.}Let a smooth two-dimensional lens map \(F(s,t)=(X,Y)\) obey \(X(s,-t)=X(s,t)\) and \(Y(s,-t)=-Y(s,t)\), as a chosen equatorial-symmetry chart would. The elementary normal-form example
\[F(s,t)=(s,t^3+st)
\]
has Jacobian determinant \(J=3t^2+s\). Its critical set is \(s=-3t^2\), and the caustic image is \((-3t^2,-2t^3)\), which satisfies \(27Y^2+4X^3=0\). At nonzero \(t\), the critical image has nonzero derivative and is a fold arc; at zero both first derivatives vanish and the cubic cusp is visible explicitly.
\paragraph{A symmetry-only failure.}The map \(F_0(s,t)=(s,st)\) has the same reflection parity but critical set \(s=0\), whose entire image is one point. Thus reflection symmetry and a vanishing Jacobian do not force a stable cusp; a nonzero cubic transverse derivative and a suitable mixed derivative are genuine extra conditions. Nor does this local cusp calculation produce a global astroid or count higher-order sheets.
