\subsection{Definitions and mathematical statement}
Let \(G\) be a finitely generated group with identity \(e\). For a finite symmetric generating set \(S\), let \(B_S(n)\) be the set of elements representable by words of length at most \(n\) in \(S\). The group has exponential growth if there exist \(c>1\) and \(n_0\in\N\) such that \(|B_S(n)|\ge c^n\) for every integer \(n\ge n_0\); this property is independent of the finite generating set. The group is amenable if there is a finitely additive function \(m:\mathcal P(G)\to[0,1]\) with \(m(G)=1\) and \(m(gA)=m(A)\) for all \(g\in G\) and \(A\subseteq G\).

The supplied question asks for a characterization of the finitely generated amenable groups \(G\) of exponential growth satisfying
\[
 p^G_{2n}\asymp\exp(-n^{1/3})\qquad(n\to\infty).
\]

\[
 p^{G,\mu}_{2n}:=\mathbb P(X_{2n}=e)=\mu^{*2n}(e).
