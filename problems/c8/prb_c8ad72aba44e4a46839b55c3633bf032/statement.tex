\section{Reusable Garbled RAM under Weaker Assumptions}\label{30002628}
{\small\sffamily UnsolvedMath ID 30002628 · Computer Science}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


Garbled RAM encodes a RAM computation to hide data while enabling evaluation. Reusability allows the encoding to serve repeated computations; persistent memory preserves encoded state across them.

A cryptographic security requirement compares an efficient adversary\textquotesingle s advantage with a negligible function of the security parameter. A negligible function is smaller than every inverse polynomial eventually; computational and information-theoretic security are different requirements.
\paragraph{Statement recorded in the supplied source.}
Can reusable garbled RAM, including schemes with persistent memory, be constructed under assumptions weaker than indistinguishability obfuscation, functional encryption for circuits, or the stronger obfuscation assumptions used by the known constructions? \sref{30002628}{2}
\paragraph{Scope qualification.}
The relevant reuse, memory-access leakage, and security requirements are those of the source.

Construct reusable stateful garbled RAM under weaker assumptions while preserving the required efficiency and security.
