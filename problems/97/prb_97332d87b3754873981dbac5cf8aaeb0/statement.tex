\section{Asymptotic Counts of Growing-Width $k$-SAT Functions}\label{30005109}
{\small\sffamily UnsolvedMath ID 30005109 · Computer Science}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


A Boolean function maps $\{0,1\}^n$ to $\{0,1\}$. A $k$-SAT function is represented by a conjunction of clauses of width at most $k$, each clause a disjunction of literals $x_i$ or $\neg x_i$; distinct formulas computing the same function count once. Uniformly choosing a function means choosing from this finite set of distinct functions. A function is unate if complementing an appropriate subset of input coordinates makes it monotone in every coordinate. As $n\to\infty$, $o(1)$ tends to zero.
\paragraph{Statement recorded in the supplied source.}
If $k=k(n)\leq(1/2-c)n$ for some constant $c>0$, what is the asymptotic number of $k$-SAT functions on $n$ Boolean variables? \sref{30005109}{2}
\paragraph{Scope qualification.}
The constant $c>0$ is fixed, while the integer width $k=k(n)$ may grow subject to the displayed bound. Clause-width and repeated-literal conventions follow the cited enumeration problem.
