The source does not explicitly specify the parameter domain; the interpretation here is that these are full-dimensional lattice simplices in \(\Z^n\), with reflexivity taken about the origin. In this interpretation, the requirement that the origin lie in the interior forces \(q_i>0\) for every \(i\).

A full-dimensional lattice polytope \(P\subset\R^n\) is \emph{reflexive} if \(0\in\operatorname{int}(P)\) and its polar
\[
P^\vee=\{y\in(\R^n)^*: \langle y,x\rangle\leq 1\text{ for every }x\in P\}
\]
is a lattice polytope in the dual lattice. It has the \emph{integer-decomposition property} (IDP) if, for every integer \(k\geq 1\) and every \(z\in kP\cap\Z^n\), there exist \(z_1,\ldots,z_k\in P\cap\Z^n\) such that \(z=z_1+\cdots+z_k\).

Define the Ehrhart \(h^*\)-polynomial by
\[
\sum_{m=0}^{\infty}\#(mP\cap\Z^n)t^m
=\frac{h_P^*(t)}{(1-t)^{n+1}},
\qquad
h_P^*(t)=\sum_{i=0}^{n}h_i^*t^i.
\]
Its coefficient sequence is \emph{unimodal} if there is an index \(r\in\{0,\ldots,n\}\) with
\[
h_0^*\leq\cdots\leq h_r^*\geq\cdots\geq h_n^*.
\]
It is nonunimodal if no such index exists.
