\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


Let $M\in\mathbb{R}^{n\times n}$ satisfy $M=M^{\mathsf T}$. Positive semidefiniteness means
\[
 M\succeq0\quad\Longleftrightarrow\quad x^{\mathsf T}Mx\ge0\quad\text{for every }x\in\mathbb{R}^n.
\]
Write $\operatorname{nnz}(M)$ for its number of nonzero entries. For a nonsingular matrix the spectral condition number is $\kappa_2(M)=\|M\|_2\|M^{-1}\|_2$; the usual condition number is infinite for a singular matrix. Quasi-linear time allows a fixed power of logarithms times the input sparsity and dimension, for example $O((n+\operatorname{nnz}(M))(\log n)^C)$ when other promised parameters are fixed. A certificate is a checkable witness implying $M\succeq0$; a factorization $M=LL^{\mathsf T}$ is an example. The requested procedure may return no certificate, but every certificate it does return must be correct. On promised positive semidefinite inputs its probability of producing a valid certificate must be bounded below by a positive constant independent of $n$.
\paragraph{Statement recorded in the supplied source.}

\section{Attempt and results}
We use exact real arithmetic for the following tests. Their arithmetic counts are
not bit-complexity claims. The input is the entire symmetric matrix, not merely
a matrix-vector oracle. The source does not specify a condition-number threshold;
the failed example below has spectral condition number exactly three.

\paragraph{A sound sparse certificate.}
If $M_{ii}\ge\sum_{j\ne i}|M_{ij}|$ for every $i$, then $M\succeq0$.
Indeed, for every real $x$,
\[
x^TMx\ge\sum_i M_{ii}x_i^2-\sum_{i<j}|M_{ij}|(x_i^2+x_j^2)
=\sum_i\left(M_{ii}-\sum_{j\ne i}|M_{ij}|\right)x_i^2\ge0.
\]
The inequalities follow from $2|x_ix_j|\le x_i^2+x_j^2$.
Computing the row sums requires $O(n+\operatorname{nnz}(M))$ arithmetic
operations. On inputs passing these explicit inequalities the success probability
is one, and there are no false certificates. This is the standard diagonal
dominance test, rederived here, not a new general certifier.

\paragraph{Well-conditioned positive matrices missed by that test.}
Let $n=2^r\ge16$ and recursively define $H_1=(1)$ and
$H_{2m}=\left(\begin{smallmatrix}H_m&H_m\\H_m&-H_m\end{smallmatrix}\right)$.
Induction gives $H_n^T=H_n$ and $H_n^2=nI$. Thus
$M=I+H_n/(2\sqrt n)$ has eigenvalues in $\{1/2,3/2\}$.
Both signs occur for $n\ge2$: the recursion gives trace zero, so a symmetric
matrix with square $nI$ cannot have all eigenvalues of one sign. Consequently
$M\succ0$ and $\kappa_2(M)=3$.
Every off-diagonal absolute row sum is $(n-1)/(2\sqrt n)$, whereas
$M_{ii}\le1+1/(2\sqrt n)$. Since $n-2>2\sqrt n$ for $n\ge16$,
every row fails the certificate. Small condition number therefore does not supply
the missing success guarantee for this particular test.

\paragraph{Why finitely many quadratic-form probes do not certify a matrix.}
Consider a deterministic adaptive algorithm that only queries $v^TMv$ and makes
$q<n$ queries. Run it on $I$, and let $V$ be the span of the queried vectors.
Choose a unit $u\perp V$ and set $B=I-2uu^T$. Every query answer on $B$ is
the same as on $I$. Induction on the query index gives the same adaptive
transcript and output. But $Bu=-u$ and $Bw=w$ for $w\perp u$, so $B$ is
indefinite for $n\ge2$ and has singular-value condition number one.
Any algorithm accepting this transcript is unsound. The conclusion concerns
this restricted deterministic oracle model; the input-dependent choice of $u$
does not prove a lower bound for randomized algorithms on a fixed matrix, and
does not prevent an algorithm from reading all entries.
