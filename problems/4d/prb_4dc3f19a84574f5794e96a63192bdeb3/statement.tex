\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
For a finite undirected graph $G=(V,E)$ let $n=|V|$, $m=|E|$, and let $d_G(X)$ count edges with one end in $X$ and the other in $V\setminus X$. A subgraph is viewed as $H=(V,E_H)$ with $E_H\subseteq E$, retaining isolated vertices. The source does not allow reweighting, so these are ordinary edge counts, not weighted cut values. Graph simplicity and parallel-edge conventions are not stated.

\textbf{First algorithmic problem.} Devise a combinatorial polynomial-time algorithm and universal constants $c_1,C_1>0$ which, for every graph in the intended input class with $m>0$, find $H\subseteq G$ satisfying
\[
 |E_H|\leq C_1n,\qquad
 d_H(X)\geq c_1\frac nm\,d_G(X)\quad\text{for every }X\subseteq V.
\]
\textbf{Second algorithmic problem.} Devise a combinatorial polynomial-time algorithm and universal constants $c_2,C_2>0$ which find $H\subseteq G$ satisfying
\[
 |E_H|\geq c_2n,\qquad
 d_H(X)\leq C_2\frac nm\,d_G(X)\quad\text{for every }X\subseteq V.
\]
These are the explicit uniform-constant readings of the source's $O(n)$, $\Omega(n)$, $\Omega(n/m)$, and $O(n/m)$ notation. The two algorithms may return different subgraphs.

The literal input class ``given a graph'' needs qualification: $n/m$ is undefined at $m=0$, and if graphs with $m/n\to0$ are allowed, no subgraph can have $\Omega(n)$ edges in the second problem. Such sparsity also conflicts with the first scaled lower bound on nonzero cuts for universal constants. Connectedness or an appropriate density restriction might be intended, but neither is supplied and none is imposed silently.

The registry status and classification are partial progress, whereas the research summary says both problems are solved by polynomial-time constant-factor cut sparsification and names Fung--Hariharan--Harvey--Panigrahi and Nagamochi--Ibaraki. The record gives no exact result matching all of the unweighted-subgraph, global $n/m$ scaling, linear-edge, and combinatorial-algorithm requirements. Weighted or differently normalized sparsification is not identified with the stated tasks without review. The archived Egres index is explicitly not a current resolution authority.
\subsection{Short English statement}
Construct, by combinatorial polynomial-time algorithms, unweighted subgraphs with linear edge counts and cut values bounded below or above by a constant times $n/m$ of every original cut.
