\section{Research attempt}
The source has no fixed hardware, noise model, or computational task. This attempt tests a specific control proposal: an entangling two-qubit interaction plus arbitrarily shaped collective controls should allow individual gates. The proposal fails by an exact symmetry obstruction. We then quantify the control time needed if a weak symmetry-breaking term is added. These are illustrative control calculations, not a completion of the source program and not claimed novel.

Let $I$ be the $2\times2$ identity, $X=\left(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\right)$, $Z=\operatorname{diag}(1,-1)$, and let $W(v\otimes w)=w\otimes v$ be the swap operator. In units with $\hbar=1$, consider
\[
 H_0(t)=J(t)Z\otimes Z+u(t)(X\otimes I+I\otimes X)
             +v(t)(Z\otimes I+I\otimes Z),
\]
with real piecewise continuous functions on $[0,T]$. Its unitary propagator solves $\dot U_0=-iH_0U_0$, $U_0(0)=I_4$. Norms below are operator norms induced by Euclidean norm.

\begin{proposition}
Every such propagator commutes with $W$. For the target $V=X\otimes I$ and every real global phase $\theta$,
\[
 \|U_0(T)-e^{i\theta}V\|\ge\sqrt2.
\]
If $H(t)=H_0(t)+E(t)$ is Hermitian with $\|E(t)\|\le\varepsilon$, its propagator satisfies
\[
 \|U(T)-e^{i\theta}V\|\ge\sqrt2-\varepsilon T.
\]
Thus operator-norm error at most $\eta<\sqrt2$ requires $T\ge(\sqrt2-\eta)/\varepsilon$ when $\varepsilon>0$.
\end{proposition}
\begin{proof}
Swapping exchanges the summands in each collective term and leaves $Z\otimes Z$ unchanged. Therefore $[H_0(t),W]=0$. The matrix $WU_0(t)W$ obeys the same linear initial-value equation as $U_0(t)$, proving equality by uniqueness. Unitarity follows from $\frac d{dt}(U_0^*U_0)=0$; these arguments apply on each continuous piece and then concatenate.

The antisymmetric subspace is one-dimensional, spanned by the unit vector
\[
 s=(|01\rangle-|10\rangle)/\sqrt2.
\]
Consequently $U_0(T)s=e^{i\alpha}s$ for some phase. But $Vs=(|11\rangle-|00\rangle)/\sqrt2$ lies in the symmetric subspace and is orthogonal to $s$. Hence $\|(U_0-e^{i\theta}V)s\|^2=2$ for every $\theta$, proving the first norm bound.

To compare propagators, differentiate $R(t)=U_0(t)^*U(t)$, obtaining $\dot R=-iU_0^*EU$. Integration and unitary invariance give $\|R(T)-I\|\le\int_0^T\|E(t)\|dt\le\varepsilon T$. Since $\|U-U_0\|=\|R-I\|$, the triangle inequality gives the second bound. Rearrangement proves the time constraint.
\end{proof}

This obstruction persists with arbitrarily rapid collective pulses so long as the same swap symmetry is preserved. It concerns the full unitary task; controllability on a smaller invariant subspace is a different question. An entangling drift by itself does not remove all conserved symmetries. Conversely, the lower time bound alone does not prove that a chosen asymmetric perturbation enables the target at any finite time.
