For fixed $k<\ell$, let $F_k(N,\ell)$ be the least integer threshold
such that every $N$-element set of positive integers with at least that
many $k$-term arithmetic progressions contains an $\ell$-term progression.
We count nonconstant progressions once, in increasing order. The main
questions are whether $F_3(N,4)=o(N^2)$ and whether
$\log F_3(N,\ell)/\log N\to2$ for each fixed $\ell>3$.
Both answers are affirmative. This note deduces them from the precise
Fox--Pohoata comparison theorem and standard progression bounds.
