\section{Online Model Selection for Nonparametric Classes}\label{30005866}
{\small\sffamily UnsolvedMath ID 30005866 · Computer Science}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


In an online decision problem, an algorithm selects an action at each of $T$ rounds and receives the feedback allowed by the source model. Regret compares its cumulative expected loss with the appropriate best comparator's cumulative loss. Model selection chooses adaptively among $M$ candidate function classes, seeking performance close to that of the best appropriate class without knowing its index. A nonparametric class is not restricted to a fixed-dimensional linear parameterization; its complexity still influences learning difficulty.
\paragraph{Statement recorded in the supplied source.}
For which nonparametric model classes is online model selection possible with regret of order $\log M$? \sref{30005866}{2}
\paragraph{Scope qualification.}
In the primary report pp. 1352--1353, logarithmic dependence concerns the number of models M, while regret also depends on the time horizon and class difficulty. The supplied phrase regret of order $\log M$ is retained as source shorthand, not a claim of horizon-independent total regret. Feedback and comparator are those of the bandit model discussed there.
