\section{Research attempt: Surrogate indistinguishability, finite orbit invariants, and exact certificates}

\paragraph{A surrogate has an information limit even before learning.}
Consider real $n\times n$ matrices with Frobenius norm one, $n\geq1$, and
try to estimate their Euclidean operator norm from that single surrogate.
The inequality
\[
 n^{-1/2}\leq\|A\|_{\rm op}\leq1
\]
follows as follows. Each column has norm at most $\|A\|_{\rm op}$, so
$1=\sum_j\|Ae_j\|^2\leq n\|A\|_{\rm op}^2$.
Conversely for unit $x$, applying Cauchy--Schwarz to every row gives
$\|Ax\|^2\leq\sum_{ij}a_{ij}^2=1$.
The endpoints are attained by $A=I/\sqrt n$ and $A=e_1e_1^T$.
A rule observing only this surrogate must output the same positive value $c$
on both matrices. Its worst multiplicative error is at least
$\max\{c\sqrt n,1/c\}$, minimized at $c=n^{-1/4}$ with value $n^{1/4}$.
That constant output also attains this worst factor for the entire displayed
interval. Thus the best possible approximation factor using only this feature
is exactly $n^{1/4}$; more samples of the same feature cannot improve it.
This is a deliberately elementary quantity, not a claim that spectral norm of
an explicit matrix is computationally hard.

Trace features can also miss nonnormal size altogether: for
$A_t=t e_1e_2^T$ in dimension at least two, $A_t^2=0$, so every positive-power
trace is zero, exactly as for the zero matrix, whereas $\|A_t\|_{\rm op}=|t|$.
Any bound inferred solely from those traces needs additional assumptions such
as a restricted matrix class; this example is not Hermitian and is not a
counterexample for Hermitian matrices.

\paragraph{What invariants mean for a finite encoded conjecture space.}
Suppose a finite set $\mathcal C$ of $M$ candidate statements is supplied with
explicit permutations $s_1,\ldots,s_k$ and their inverses. These define an
action of the free group on $k$ generators (the action itself need not be free).
Build the graph joining $c$ to $s_jc$ and $s_j^{-1}c$.
Breadth-first exploration gives its components using at most $2kM$ directed
edge examinations. These components are exactly the group orbits: a graph path
is a generator word, and every generator word gives a graph path.
A function on $\mathcal C$ is invariant exactly when it is constant on those
components. Assigning each component its least encoded element therefore gives
a complete orbit invariant for this finite model. The proof gives no finite
search bound for an infinite syntactic or geometric conjecture space, where
an orbit can be infinite and equality of represented statements adds another
problem.

\paragraph{A concrete certificate separates testing from proving.}
For a row vector $a\in\mathbb R^d$ and $x\in\mathbb R^d$,
\[
 \left(\sum_i a_i^2\right)\left(\sum_i x_i^2\right)
 -(\sum_i a_ix_i)^2
 =\sum_{i<j}(a_ix_j-a_jx_i)^2.
\]
Expand the right side: each $a_i^2x_j^2$ for $i\ne j$ occurs once and
each cross term is $-2a_ia_jx_ix_j$, exactly the difference on the left.
Summing over matrix rows is an exact sum-of-squares certificate for
$\|Ax\|^2\leq\|A\|_F^2\|x\|^2$.
A polynomial-identity checker can verify this by comparing coefficients; its
input includes the proposed squares and all quantified variable assumptions.
This is an explicit certificate interface, not an implemented proof-assistant
integration or a proof that a learned generator will find useful identities.

Finite testing by itself cannot substitute for that certificate. Given finitely
many real test points $t_1,\ldots,t_N$ and a different point $t_0$, the polynomial
\[
 p(t)=1-M\prod_{i=1}^N(t-t_i)^2
\]
equals one at every test point, but is negative at $t_0$ when
$M>\prod_i(t_0-t_i)^{-2}$. Repeated test points cause no difficulty.
The example permits a degree growing with the number of tests; no contradiction
to interpolation with an a priori bounded-degree model is intended.
