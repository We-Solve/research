\subsection{Definitions and mathematical statement}
The surrounding local records place $d(\varphi)$ in the Heegaard-splitting setting: item 11000158 uses a handlebody double coset, and item 11000161 identifies distance at most one with weak reducibility. Thus the relevant distance is a disk-set distance, not merely the distance between one prescribed pair of curves.

In the usual closed genus-$g\ge2$ convention, fix a handlebody $V_g$ with boundary $S_g$ and let $\mathcal D\subset\mathcal C(S_g)^{(0)}$ be the set of vertices represented by essential curves bounding disks in $V_g$. The curve graph has essential-curve vertices, edges joining disjoint representatives, and unit-edge path metric $d_{\mathcal C}$. For $\varphi\in\mathcal M=\operatorname{Mod}(S_g)$, the standard Heegaard distance is
\[
 d(\varphi)=d_{\mathcal C}(\mathcal D,\varphi\mathcal D)
 =\min_{a,b\in\mathcal D}d_{\mathcal C}(a,\varphi b).
\]
The handlebody and gluing conventions must agree with the source; low-genus curve-graph conventions are not specified by the excerpt.

\textbf{Problem 2.3.} Find an algorithm that, on input an arbitrary mapping class $\varphi\in\mathcal M$ in a finite effective encoding, terminates and outputs the exact integer $d(\varphi)$. \subsection{Short English statement}
Compute the exact Heegaard distance between a handlebody disk set and its image under any given mapping class. An algorithm for a fixed pair of curve vertices does not by itself minimize over the two disk sets.
