\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
Let \(d\geq 1\), let \(F_d\) be the free group on \(x_1,\ldots,x_d\), and let \(w\in F_d\) be a group word. For a group \(G\), define
\[
V_w(G)=\{w(g_1,\ldots,g_d):g_1,\ldots,g_d\in G\},
\qquad w(G)=\langle V_w(G)\rangle.
\]
Using the symmetric convention for word width, define \(\operatorname{wd}_w(G)\) to be the least nonnegative integer \(m\) such that every element of \(w(G)\) is a product of at most \(m\) elements of \(V_w(G)\cup V_w(G)^{-1}\); set the width to \(\infty\) if no such integer exists. The empty product is the identity. The supplied source does not explicitly specify its convention concerning inverses.

For a finite group \(G\), its Pr\"ufer rank is
\[
\operatorname{rk}(G)=\max_{H\leq G}d(H),
\]
where \(d(H)\) is the minimum size of a generating set of \(H\), with \(d(\{1\})=0\). A finite \(p\)-group is a finite group whose order is a power of the prime \(p\). For indexing below, take \(\mathbb N=\{0,1,2,\ldots\}\); the source does not specify whether zero belongs to \(\mathbb N\), and the trivial group has width zero.

\begin{enumerate}
\item[(a)] Is it true that for every group word \(w\) there exists a function
\[
h_w:\mathbb N\times\mathbb N\longrightarrow\mathbb N
\]
such that, for every prime \(p\), every \(r\in\mathbb N\), and every finite \(p\)-group \(G\) of Pr\"ufer rank exactly \(r\),
\[
\operatorname{wd}_w(G)\leq h_w(p,r)?
\]
The function may depend on \(w\), but must be uniform over all such groups \(G\).
\item[(b)] If (a) holds, can the bounds be chosen independently of \(p\)? Equivalently, is it true that for every group word \(w\) there exists a function \(H_w:\mathbb N\to\mathbb N\) such that, for every prime \(p\) and every finite \(p\)-group \(G\),
\[
\operatorname{wd}_w(G)\leq H_w\bigl(\operatorname{rk}(G)\bigr)?
\]
\end{enumerate}

The supplied source adds that an affirmative answer to (a) would imply a result attributed to A. Jaikin-Zapirain: every word has finite width in each \(p\)-adic analytic pro-\(p\) group. Here a pro-\(p\) group is an inverse limit of finite \(p\)-groups, and \(p\)-adic analytic means a finite-dimensional analytic group over \(\mathbb Q_p\). The source supports its implication by stating that a pro-\(p\) group is \(p\)-adic analytic if and only if the Pr\"ufer ranks of all its finite continuous quotients are uniformly bounded. These are preserved as supplied background assertions, not independently verified results. The reference for Jaikin-Zapirain's result is only ``ibid.'' and cannot be resolved from this record; the source also does not explicitly distinguish an abstract verbal subgroup from its closure in the pro-\(p\) setting.
\subsection{Short English statement}
For each group word, ask whether its width in every finite \(p\)-group can be bounded using only \(p\) and the group's Pr\"ufer rank, and then whether the dependence on \(p\) can be removed. The bounds may depend on the word. This is D. Segal's problem, recorded as open in the supplied registry; that status has not been independently verified.
