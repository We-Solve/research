\textbf{Source problem code:} catalogue entry
\subsection{Definitions and mathematical statement}
For a set \(X\subseteq\R\), give \(X\) its subspace topology. Under the standard real-valued interpretation, let
\[
C_p(X)=\{f:X\to\R:f\text{ is continuous}\}
\]
with the topology of pointwise convergence, inherited from \(\R^X\).

For a topological space \(Y\) and \(y\in Y\), use the conventions
\[
\Omega_y=\{A\subseteq Y:y\in\overline A\setminus A\},\qquad
O(\Omega_y)=\{U\in\Omega_y:U\text{ is open in }Y\},
\]
and
\[
\Gamma_y=\{B\subseteq Y:B\text{ is infinite},\ y\notin B,\ B\setminus V\text{ is finite for every neighborhood }V\text{ of }y\}.
\]
The property \(\binom{O(\Omega_y)}{\Gamma_y}\) means that every \(U\in O(\Omega_y)\) contains some \(B\in\Gamma_y\). A space is \(\kappa\)-Fr\'echet when this property holds at every point \(y\in Y\); here \(\kappa\) is part of the property name, not a cardinal parameter to be determined.

Determine the least cardinality
\[
\min\bigl\{|X|:X\subseteq\R\text{ and }C_p(X)\text{ is not }\kappa\text{-Fr\'echet}\bigr\}.
\]
Thus the requested failure means that there exist \(f\in C_p(X)\) and an open set \(U\subseteq C_p(X)\) with \(f\in\overline U\setminus U\), such that no infinite subset \(B\subseteq U\) has all but finitely many of its elements in every neighborhood of \(f\).

The supplied excerpt defines \(O(\Omega_y)\) but does not expand \(C_p(X)\), \(\Omega_y\), \(\Gamma_y\), or the binomial selection notation. The formulation above explicitly adopts their standard interpretations; these conventions require confirmation against the cited source.
\subsection{Short English statement}
Find the smallest size of a set of reals \(X\) for which the space of continuous real-valued functions on \(X\), with pointwise convergence, fails to be \(\kappa\)-Fr\'echet. Under the stated conventions, failure occurs when an open set accumulates at a function but contains no infinite subset converging to that function.
