\section{Question 3.27 — Mahler}\label{statement}

\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


A Liouville number is a real irrational $x$ such that for every integer $N\ge1$ there are integers $p$ and $q\ge2$ with $0<|x-p/q|<q^{-N}$. An entire transcendental function is a holomorphic function on all of $\mathbb C$ which is not a polynomial.
\paragraph{Statement recorded in the supplied source.}
Does there exist an entire transcendental function $f$ such that $f(x)$ is a real Liouville number for every real Liouville number $x$? \sref{statement}{2}
\subsection{Short English statement}
Can an entire function which is not a polynomial send every Liouville number to another Liouville number?
