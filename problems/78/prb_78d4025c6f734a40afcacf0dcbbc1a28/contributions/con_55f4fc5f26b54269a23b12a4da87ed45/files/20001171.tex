\section{From an approximate HJB value to implemented control}\label{20001171}

\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.


A control policy chooses actions from available state or observation information. A value function records the optimal expected cost, while an approximate value function can be used to select a candidate policy. Its suboptimality is the difference between that policy's cost and the optimal cost under the same initial condition and model. Numerical solution of a Bellman equation and faithful implementation of a feedback policy are separate tasks.

I have been interested in numerical methods in stochastic (and deterministic) control for several decades, and have developed the current methods of choice for the stochastic problem (which is often the best method for determinstic problems as well, as seen in applications to complex variational problems in out book). These cover virtually all of the cost functions and systems of current interest. But, in applications, there is a serious dimensioanlity problem, beyond 4 dimensions. Various approximation schemes (say, Q-learning or neural nets) have been hyped, but with llittle to show, outside of some very special cases. Additionally, solving the Bellman or HJ-Bellman equation is not enough. One wants the control, and to investigate the effects of implemetation of reasonable approximations. The visualization problem, even in 3 dimensions, is formidable. \href{https://aimath.org/WWN/optimalcontrol/optimalcontrol.pdf}{[S2]}

\section{Research attempt: Uniform value error alone does not control sampled feedback}
Choose finite-horizon deterministic dynamics $\dot x=f(t,x,u)$ and cost
$J=\int_0^T c(t,x,u)\,dt+g(x(T))$. For any smooth candidate $W$, integration
along a trajectory gives the exact identity
\[
 J-W(0,x_0)=g(x(T))-W(T,x(T))+
 \int_0^T[c+W_t+\nabla W\cdot f](t,x(t),u(t))\,dt.
\]
Assume trajectories exist on the horizon, terminal error is at most $\delta$,
the minimum over actions of the integrand lies in $[-\epsilon,\epsilon]$,
and the implemented action has integrand at most $\epsilon+\zeta$.
Every admissible cost is at least $W(0,x_0)-\delta-T\epsilon$; the implemented
cost is at most $W(0,x_0)+\delta+T(\epsilon+\zeta)$. Taking the infimum
proves loss at most $2\delta+2T\epsilon+T\zeta$. This elementary verification
argument shows precisely which residual and implementation quantities are needed.

The attempted shortcut bounds only $\|W-V^*\|_\infty$. Consider
$\dot x=u\in[-1,1]$, $T=1$, $c=u^2$, $g=0$, $x_0=0$.
The optimal value is zero, achieved by $u=0$. Set
$W_n(t,x)=n^{-1}\sin(n^2x)$. Its uniform value error and terminal error are
at most $1/n$, but $\partial_xW_n(0,0)=n$. Minimizing the instantaneous
Hamiltonian $u^2+nu$ at the observed state yields $u=-1$ for $n\ge2$.
If an implementation samples the state only at time zero and holds this
action until time one, its cost is exactly one for every $n$. Thus vanishing
uniform value error does not ensure vanishing implemented-control loss.

This does not assert the same loss for continuously recomputed feedback:
its state sees a changing oscillatory derivative. The fixed sample interval
is part of the exhibited implementation and the source explicitly asks about
implementation effects. The residual-based identity explains the failure:
the derivatives and held-action Hamiltonian error are not controlled by the
uniform approximation error.
