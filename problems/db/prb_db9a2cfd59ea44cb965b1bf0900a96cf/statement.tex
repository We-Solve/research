\subsection{Definitions and mathematical statement}
An $m$-strand string link is a proper embedding of $m$ oriented intervals in $D^2\times[0,1]$ joining fixed corresponding endpoints on the bottom and top disks, considered up to ambient isotopy fixing the boundary. Let $d\geq1$. Standard $C_d$-equivalence is generated by isotopy and degree-$d$ tree-clasper surgeries; in the usual tree convention a degree-$d$ tree has $d+1$ leaves and $d-1$ trivalent nodes.

For an abelian group $A$, an invariant $v$ is extended to singular string links by the crossing-difference rule $v(L_\times)=v(L_+)-v(L_-)$. It has degree $<d$ if the iterated extension vanishes on string links with $d$ transverse double points.

The conjecture is that, for every $m,d\geq1$ and every pair of $m$-strand string links $L,L'$,
\[
L\sim_{C_d}L'
\quad\Longleftrightarrow\quad
\forall\text{ abelian groups }A\ \forall A\text{-valued finite-type }v
\text{ of degree }<d,\quad v(L)=v(L').
\]
The coefficient quantifier is genuinely over all abelian groups; it is not restricted to rational-valued invariants. The source does not separately state a framing convention, which should be matched to its string-link and clasper definitions.
