\section{Find the value of the De Bruijn–Newman constant}\label{9400062}
{\small\sffamily UnsolvedMath ID 9400062 · Number Theory}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


For $u\ge0$ put
\[
\Phi(u)=\sum_{n=1}^{\infty}(2\pi^2n^4e^{9u}-3\pi n^2e^{5u})\exp(-\pi n^2e^{4u}).
\]
For $t\in\mathbb R$ define the entire function
\[
H_t(z)=\int_0^{\infty}e^{tu^2}\Phi(u)\cos(zu)\,du\qquad(z\in\mathbb C).
\]
There exists a real constant $\Lambda$ for which every zero of $H_t$ is real exactly when $t\ge\Lambda$. This fixes the normalization of the de Bruijn--Newman constant. The nonnegativity $\Lambda\ge0$ is proved in the cited paper; it does not determine the exact value.
\paragraph{Statement recorded in the supplied source.}
Determine the exact value of $\Lambda$. \sref{9400062}{2}
\subsection{Short English statement}
Find the precise transition parameter at which the zeros of this deformed Riemann xi function all become real.
