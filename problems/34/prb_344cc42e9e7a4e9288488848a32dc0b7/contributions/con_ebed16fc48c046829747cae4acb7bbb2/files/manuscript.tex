\subsection{When an oracle hybrid is actually valid}
The source's grey-box steganographic models distinguish what the channel chooser, sender and warden know. Its phrase about replacing pseudorandom functions does not itself specify a security game for a replacement family. We test the familiar oracle-hybrid route with all its simulation assumptions exposed.
Let $E^O$ be a probabilistic polynomial-time oracle experiment, including every participant and all information supplied to them, making polynomially many oracle queries. Suppose the probability that its output bit is 1 differs by at most $\eta$ from a reference cover experiment when $O$ is a uniformly random function. Suppose further that the function family $F_K$ is secure against every such oracle distinguisher with advantage at most $\epsilon$.
\begin{proposition}
Replacing the random-function oracle in this entire simulatable experiment by $F_K$ changes its distance from the reference acceptance probability to at most $\eta+\epsilon$.
\end{proposition}
\begin{proof}
A distinguisher given oracle $O$ can run the specified experiment $E^O$ with its own independent coins and output the resulting bit. Its running time and query count are polynomial by hypothesis. The two oracle worlds exactly reproduce the random-function and keyed-function acceptance probabilities, so their difference is at most $\epsilon$. Applying the triangle inequality with the reference cover probability gives $\eta+\epsilon$.
\end{proof}
The important failed step is treating unavailable auxiliary information as though the reduction could generate it from oracle access. For example, if the experiment also receives the secret key $K$, it can query a fixed input $x$ and test whether the answer equals its locally computed $F_K(x)$. In the keyed-function world this test always accepts. In a random-function world independent of $K$, with $\ell$-bit outputs, it accepts with probability $2^{-\ell}$. The advantage is therefore $1-2^{-\ell}$. This is not a break of standard secret-key pseudorandom-function security: that security never gives the distinguisher $K$. It shows why the reduction must account for the source model's information distribution, including coalitions.
