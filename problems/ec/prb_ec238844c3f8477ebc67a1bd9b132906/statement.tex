A homeomorphism $F:(X,d)\to(Y,d_Y)$ is quasisymmetric if some homeomorphism $\eta:[0,\infty)\to[0,\infty)$ satisfies
\[
 \frac{d_Y(F(x),F(a))}{d_Y(F(x),F(b))}
 \le\eta\!\left(\frac{d(x,a)}{d(x,b)}\right)
