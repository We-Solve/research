\section{Research attempt: An exact streaming compression route and its inconsistency trap}
For $N$ sampled states, let $E\in K^{N\times r}$ contain feature evaluations and $Y\in K^{N\times d}$ the observed next states. Exact coefficient fitting asks for $C\in K^{r\times d}$ with $EC=Y$. A tempting acceleration keeps only a basis of rows of $E$. This loses contradictory responses unless the same dependencies are checked in $Y$. The smallest counterexample has
\[
E=\begin{pmatrix}1\\1\end{pmatrix},\qquad
Y=\begin{pmatrix}0\\1\end{pmatrix}.
\]
Either single row gives a solvable fitted system, while both rows require $C=0$ and $C=1$.

The corrected streaming algorithm stores an echelon basis of feature rows, together with the corresponding transformed response rows. Reduce each incoming pair $(e,y)$ by the stored pivot rows using identical row operations on its feature and response parts. If the reduced feature row is nonzero, normalize its new pivot and retain the pair. If it is zero and the response row is also zero, discard the pair. If it is zero and the response row is nonzero, report inconsistency.

Here is a correctness proof. Subtracting a stored equation from a new equation leaves their joint solution set unchanged, because the operation is reversible when the stored equation is retained. Scaling a row by a nonzero field element is similarly reversible. A zero feature and zero response row is the tautology $0=0$. A zero feature with a nonzero response row requires $0=y\ne0$ in at least one output coordinate, so no solution exists. Inductively the stored system has exactly the same coefficient solutions as all processed rows, unless a verified inconsistency was found. There can be at most $r$ stored rows because each retained row has a new feature pivot. After successful processing, back substitution and arbitrary choices of free coefficients describe every exact fit.

With dense row storage, an incoming row uses at most $r$ eliminations, each touching at most $r+d$ entries. Thus streaming reduction costs $O(Nr(r+d))$ field operations and stores $O(r(r+d))$ field elements. Feature evaluation and final coefficient reconstruction incur their own costs. For rational arithmetic this is not a bit-complexity bound: numerator and denominator lengths may grow. For noisy real measurements exact inconsistency is not evidence against every statistical model; it rejects only the exact deterministic fitting formulation.
