\subsection{Definitions and mathematical statement}
A set \(A\subseteq\N\) is computably enumerable if an algorithm enumerates its elements. For sets \(A,B\subseteq\N\), write \(A\leq_T B\) if membership in \(A\) is computable using \(B\) as an oracle, and write \(A\equiv_T B\) if both \(A\leq_T B\) and \(B\leq_T A\). Let \(\mathcal D_{\mathrm{ce}}\) be the set of Turing degrees containing a computably enumerable set, ordered by the order induced by \(\leq_T\). For \(\mathbf a=\deg_T(A)\) and \(\mathbf b=\deg_T(B)\), their join is \(\mathbf a\vee\mathbf b=\deg_T(A\oplus B)\), where
\[
A\oplus B=\{2n:n\in A\}\cup\{2n+1:n\in B\}.
\]
A finite lattice is a nonempty finite partially ordered set \(L\) in which each pair \(x,y\) has a least upper bound \(x\vee_L y\) and a greatest lower bound \(x\wedge_L y\).

\textbf{Problem.} Characterize all finite lattices \(L\) for which there exists an injective map \(f:L\longrightarrow\mathcal D_{\mathrm{ce}}\) such that, for every \(x,y\in L\),
\[
f(x\vee_L y)=f(x)\vee f(y),
\]
and \(f(x\wedge_L y)\) is the greatest lower bound of \(f(x)\) and \(f(y)\) in \(\mathcal D_{\mathrm{ce}}\). Explicitly, the latter condition means
\[
f(x\wedge_L y)\leq_T f(x),\qquad f(x\wedge_L y)\leq_T f(y),
\]
\[
\forall\mathbf d\in\mathcal D_{\mathrm{ce}},\quad
\bigl(\mathbf d\leq_T f(x)\ \land\ \mathbf d\leq_T f(y)\bigr)
\Longrightarrow \mathbf d\leq_T f(x\wedge_L y).
\]
The meet condition requires an ambient greatest lower bound for each image pair; it is stronger than merely being a greatest lower bound within \(f(L)\). It does not assume that every pair of computably enumerable degrees has a meet. The displayed formulation preserves binary joins and meets. The supplied wording does not specify an additional requirement that the least or greatest element of \(L\) map to the least or greatest element of \(\mathcal D_{\mathrm{ce}}\); whether such a requirement was intended remains unresolved.
\subsection{Short English statement}
Determine exactly which finite lattices admit an injective representation by computably enumerable Turing degrees that preserves every binary join and meet. Meets are taken in the ordered set of computably enumerable degrees. The source does not specify whether the embedding must also preserve the ambient least and greatest degrees.
