\subsection{Definitions and mathematical statement}
Let \(A\subset\Z\) be a finite nonempty alphabet. An infinite word over \(A\) is a sequence \(w=(a_n)_{n\geq 0}\) with \(a_n\in A\). A factor is a finite contiguous block of this sequence. For a finite word \(x=b_1\cdots b_m\), let \(|x|=m\) and \(S(x)=\sum_{j=1}^{m}b_j\). An additive square is a factor \(xx'\) with \(|x|=|x'|\geq 1\) and \(S(x)=S(x')\).

Does there exist a finite nonempty set \(A\subset\Z\) and an infinite word \(w=(a_n)_{n\geq0}\) over \(A\) containing no additive square? Explicitly, is it true that
\[
\exists A\subset\Z,\quad 0<|A|<\infty,\quad
\exists (a_n)_{n\geq0}\in A^{\{0,1,2,\ldots\}},\quad
\forall i\geq0\ \forall m\geq1,\qquad
\sum_{j=0}^{m-1}a_{i+j}\ne\sum_{j=0}^{m-1}a_{i+m+j},
\]
where \(i\) and \(m\) are integers?

The formulation uses the standard convention that the repeated blocks have positive length; the supplied wording does not explicitly impose this condition. If empty blocks were allowed as forbidden factors, every word would contain the empty additive square, so this convention requires confirmation in mathematical review.
\subsection{Short English statement}
Does some finite set of integers support an infinite sequence in which every two consecutive nonempty blocks of the same length have different sums? The supplied record calls this the PVHH sum-square avoidance problem and labels it open; that status is supplied dated curation, not an independently verified conclusion.
