\subsection{Definitions and mathematical statement}
For a finite connected undirected graph \(G=(V,E)\), let \(d_G(u,v)\) be the minimum number of edges in a path from \(u\) to \(v\), and define the interval
\[
I_G(u,v)=\{x\in V:d_G(u,v)=d_G(u,x)+d_G(x,v)\}.
\]
The graph is a median graph if, for every \(u,v,w\in V\), the intersection
\[
I_G(u,v)\cap I_G(v,w)\cap I_G(w,u)
\]
contains exactly one vertex. Let \(Q_k\) be the graph on \(\{0,1\}^k\) whose adjacent vertices differ in exactly one coordinate. The cube dimension of a median graph is the largest integer \(k\geq 0\) for which it contains an isometric copy of \(Q_k\). Bounded cube dimension means that this dimension is at most a fixed constant \(D\), independent of the number of vertices.
