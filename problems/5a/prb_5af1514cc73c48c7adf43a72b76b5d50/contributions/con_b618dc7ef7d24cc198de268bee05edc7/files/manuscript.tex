\subsection{Locally positive blocks need not assemble into a positive matrix}
The record overlaps the more specific random-graph question under ID 30003869. Here we test a different route: enforce the semidefinite constraint only in each small neighborhood and assemble those entries globally. Take the six-cycle with adjacency matrix $A$ and put $X=I-(3/5)A$.
\begin{proposition}
The matrix $X$ has unit diagonal and every principal block on a radius-one ball is positive definite, but $X$ itself is not positive semidefinite.
\end{proposition}
\begin{proof}
Each radius-one ball induces a three-vertex path. Its block, in path order, is
\[
\begin{pmatrix}1&-3/5&0\\-3/5&1&-3/5\\0&-3/5&1\end{pmatrix}.
\]
The path adjacency matrix has characteristic polynomial $t(t^2-2)$, so the displayed block has eigenvalues $1,1\pm3\sqrt2/5$. They are positive because $18/25<1$. However, every cycle vertex has degree two, so $X\mathbf1=(1-6/5)\mathbf1=-\mathbf1/5$. Its quadratic form on $\mathbf1$ is $-6/5<0$, disproving global positive semidefiniteness.
\end{proof}
This obstruction concerns checking and assembling overlapping local principal blocks. A local algorithm may instead construct genuine vectors and use their Gram matrix, which is globally positive semidefinite by construction. Thus the example does not prove that all local SDP algorithms fail; it pinpoints an invalid feasibility inference. The primary Fan--Montanari work indeed supplies successful local constructions for specified random graph models, and those results are not contradicted here.
