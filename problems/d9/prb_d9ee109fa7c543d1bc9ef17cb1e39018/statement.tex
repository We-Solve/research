\subsection{Definitions and mathematical statement}
A semigroup is a nonempty set \(S\) equipped with an associative binary operation. An element \(e\in S\) is idempotent if \(e^2=e\). Thus \(S\) has no idempotents if \(s^2\ne s\) for every \(s\in S\). The semigroup \(S\) is finitely generated if there is a finite subset \(A\subseteq S\) such that every element of \(S\) is a nonempty finite product of elements of \(A\). It is finitely presented if it is isomorphic to \(A^+/\rho\), where \(A\) is a finite alphabet, \(A^+\) is the free semigroup of nonempty words, and \(\rho\) is the congruence generated by a finite set of pairs of words.
