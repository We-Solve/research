\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


A $k$-submodular function has domain $\{0,1,\ldots,k\}^V$ and satisfies $f(x)+f(y)\geq f(x\sqcap y)+f(x\sqcup y)$. Coordinatewise meet keeps equal labels and otherwise gives zero; join keeps an agreed label or a lone nonzero label, and gives zero for conflicting nonzero labels.

Polynomial time means a number of elementary steps bounded by a polynomial in the encoded input length. A decision problem is in $\mathrm{NP}$ if yes-instances have polynomial-length certificates verifiable in polynomial time; NP-hardness is under polynomial-time reductions.

A set function $f:2^V\to\mathbb R$ is submodular if $f(A)+f(B)\geq f(A\cup B)+f(A\cap B)$ for all $A,B\subseteq V$. It is monotone if inclusion never decreases its value and normalized if $f(\varnothing)=0$.

\section{Source model and attempted reduction}
Kiraly's report, printed pages 2896--2897, introduces the evaluation-oracle
model before asking the final $k$-submodular question. The catalogue sentence
alone does not specify the representation. We analyze oracle access with
$n=|V|$ and fixed $k\ge2$; a complete value table instead already has
$(k+1)^n$ entries and can simply be scanned in time linear in that table.
No hardness claim about every possible succinct representation follows.

Choose a nonzero label vector $\ell\in\{1,\ldots,k\}^n$ and define
$g_\ell(S)=f(x)$ where $x_i=\ell_i$ for $i\in S$, and $x_i=0$ otherwise.
For two such vectors, meet and join correspond exactly to intersection and
union. Thus $g_\ell$ is an ordinary submodular set function, by substitution
in the defining inequality. Every vector belongs to at least one such orthant,
so
\[
\min_x f(x)=\min_{\ell\in\{1,\ldots,k\}^n}\min_{S\subseteq V}g_\ell(S).
\]
Even granting ordinary submodular minimization as an external polynomial-time
subroutine, this enumerates $k^n$ orthants. Its unproved step would be a
polynomial procedure selecting sufficiently many of them. Choosing an arbitrary
one fails already for $n=1$, $f(0)=0,f(1)=2,f(2)=-1$, with all other nonzero
labels assigned value $2$: the only nontrivial unary inequalities are
$f(a)+f(b)\ge2f(0)$ for distinct nonzero labels, and they all hold. The
label-one orthant misses the minimum.

\section{A complete obstruction to coordinate descent}
One might try to choose labels incrementally, accepting any improving
single-coordinate move. For every $k\ge2$, put
\[
u(0)=0,\qquad u(1)=1,\qquad u(a)=2\ (a\ge2),\qquad
F(x_1,x_2)=u(x_1)+u(x_2)-3\mathbf1_{\{x_1=x_2=1\}}.
\]
Here $\mathbf1$ denotes the indicator of the stated event. This is
$k$-submodular. We give a direct proof for all labels and pairs.
For a coordinate without a conflict of distinct nonzero labels, the unary
slack $u(a)+u(b)-u(a\sqcap b)-u(a\sqcup b)$ is zero.
At a conflict it is $u(a)+u(b)\ge3$.
For the interaction term, if both input vectors are $(1,1)$ the slack is zero.
If exactly one input is $(1,1)$ and there is no coordinate conflict, their join
is $(1,1)$ and their meet is not, again giving zero interaction slack.
If exactly one input is $(1,1)$ and a conflict occurs, neither output is
$(1,1)$; the interaction slack is $-3$, paid by that coordinate's unary
slack. If neither input is $(1,1)$, their meet cannot be $(1,1)$; the
interaction slack is either zero or $+3$, according to their join.
These cases exhaust all pairs and prove the inequality.

Nevertheless $F(0,0)=0$, while every vector obtained by changing exactly
one coordinate has value $1$ or $2$. Thus $(0,0)$ is a strict local minimum
for the proposed neighborhood. The global minimum is $F(1,1)=-1$:
all other vectors have nonnegative unary sum and no subtracted term.
The obstruction even occurs for $k=2$, whose known minimization algorithms
therefore cannot be replaced by this coordinate-descent argument.
Adding independent nonnegative unary terms supplies the same obstruction in
higher dimensions. This is a failed-route example, not an oracle lower bound.
