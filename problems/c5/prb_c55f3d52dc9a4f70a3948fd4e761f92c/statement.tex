\subsection{Definitions and mathematical statement}
A Steiner triple system on a finite vertex set \(V\) is a family \(\mathcal{T}\subseteq\binom{V}{3}\) such that every two-element subset of \(V\) belongs to exactly one member of \(\mathcal{T}\). A set \(I\subseteq V\) is independent if no member of \(\mathcal{T}\) is contained in \(I\). Define
\[
\alpha(V,\mathcal{T})=\max\{|I|:I\subseteq V,\ \text{no }T\in\mathcal{T}\text{ satisfies }T\subseteq I\}.
\]
Here \(\log\) is interpreted as the natural logarithm.

The proposed statement is: for every \(\varepsilon\in(0,1)\), there exists an integer \(N\) such that, for every integer \(n\geq N\) with \(n\equiv1\) or \(3\pmod 6\), every Steiner triple system \((V,\mathcal{T})\) with \(|V|=n\) satisfies
\[
\alpha(V,\mathcal{T})\geq(1-\varepsilon)\sqrt{3n\log n}.

\subsection{Short English statement}
Does every sufficiently large Steiner triple system have a vertex subset containing no triple whose size is at least \((1-\varepsilon)\sqrt{3n\log n}\), for every fixed \(\varepsilon>0\)? The threshold must work for all systems of the same order. The supplied record labels this conjecture open; this draft does not independently verify that status.
