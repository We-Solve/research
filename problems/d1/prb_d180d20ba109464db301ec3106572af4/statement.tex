For the grid \([n]^2\), let \(t(n)\) be the least number of
selected grid points whose pairwise determined lines cover
the whole grid. We reconstruct Alon's bounds
\[
 c n^{2/3}\leq t(n)\leq C n^{2/3}\log n
 \quad(n\geq2),
\]
so in particular \(t(n)=o(n)\).
Source: N. Alon, \emph{Economical coverings of sets of lattice
points}, \url{https://web.math.princeton.edu/~nalon/PDFS/lattice.pdf}.
See \url{https://www.erdosproblems.com/798}.
The planar argument below includes the approximation and
probabilistic steps explicitly.
