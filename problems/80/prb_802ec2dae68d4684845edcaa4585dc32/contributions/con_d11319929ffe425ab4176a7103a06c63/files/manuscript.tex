Every edge lies on exactly $k$ paths and has objective coefficient $k$.
\begin{proposition}
The integer optimum is $k$, and the standard relaxation $0\le y_e\le1$ has optimum $k(k+1)/2$. Its gap on this family is $(k+1)/2$.
\end{proposition}
\begin{proof}
Every pair of distinct edges is constrained by $y_e+y_f\le1$, so an integer solution selects at most one edge and selecting one attains value $k$. Assigning $y_e=1/2$ to every edge is fractionally feasible. Summing all pair constraints counts each variable exactly $k$ times, giving $k\sum_e y_e\le\binom{k+1}{2}$. Since the objective is $k\sum_e y_e$, the half-vector attains the resulting upper bound $k(k+1)/2$.
\end{proof}
