\textbf{Erd\H{o}s \#207; partial reconstruction, 2026-09-23.}
For every fixed $g\geq2$, do all sufficiently large $n\equiv1,3\pmod6$ admit a Steiner triple system in which the union of any $j$ distinct edges has at least $j+3$ vertices, for every $2\leq j\leq g$? A Steiner triple system is a collection of three-element subsets in which each pair of distinct vertices occurs exactly once.
