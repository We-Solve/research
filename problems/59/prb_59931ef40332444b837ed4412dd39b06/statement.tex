\section{Approximating Maximum Nonsymmetric Principal Subdeterminants}\label{statement}

\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.


For an index set $S$, $L_{S,S}$ is the principal submatrix with both rows and columns in $S$. Positive semidefiniteness of $L+L^{\mathsf T}$ means $x^{\mathsf T}(L+L^{\mathsf T})x\geq0$ for every real $x$. In this setting the principal determinants are nonnegative. A $2^{O(k)}$ approximation returns a set $S$ of size $k$ whose determinant is at least the maximum divided by $2^{Ck}$ for an absolute constant $C$.
\paragraph{Statement recorded in the supplied source.}
Let $L$ be a matrix such that $L+L^\mathsf T$ is positive semidefinite. Is there a $2^{O(k)}$-approximation algorithm for maximizing $\det L_{S,S}$ over all index sets $S$ of size $k$? \sref{statement}{2}
\paragraph{Scope qualification.}
The approximation is multiplicative, with the usual zero-optimum convention. A computational answer must specify finite input precision and the polynomial dependence on matrix size.

Approximate the largest size-$k$ principal determinant when the matrix has positive-semidefinite symmetric part.
