\section{Research attempt: A conversion diagram whose paths overstate compatibility}
Model each converter as a partial function with a declared input domain. A drawn arrow $A\to B$ says only that some converter exists; paths do not automatically establish conversion for every object of $A$. For example take $A=B=C=\mathbb Z$, let $f:A\to B$ be defined on nonnegative integers with $f(x)=x+1$, and let $g:B\to C$ be defined only on even integers with $g(y)=y/2$. Both arrows are valid, yet the path fails on input zero since $f(0)=1$ is outside $g$'s domain. Its exact domain is the odd nonnegative integers.

For arbitrary partial $f,g$, the composite domain is
\[
\operatorname{dom}(g\circ f)=\{x\in\operatorname{dom}f:f(x)\in\operatorname{dom}g\}.
\]
This follows directly from the two operations needed to evaluate the composition. For a longer path, propagate an input through each stage and retain it only while the next domain predicate holds; induction proves that the retained input set is exactly the composite domain. If candidate input sets are finite and converter outputs and predicates are explicitly supplied, this is an executable finite test. A graph of format names alone omits the information needed for it.

Reversibility is another independent annotation. The total map $f:\mathbb Z\to\mathbb N$, $f(x)=|x|$, has the right inverse $g(n)=n$ on $\mathbb N$, since $f(g(n))=n$. But $g(f(-1))=1\ne-1$. A pair of arrows in both directions therefore does not prove source roundtrip. A truthful atlas must distinguish each direction's supported domain and loss behavior. The proof does not prescribe a visual design or inventory real converters.
