# we-solve research

Problem statements, research attempts, reviews and their metadata for [we-solve](https://we-solve.github.io/).

This repository holds the public research records and their source files. It does not include the website generator.

## Contents

- `problems/<shard>/<problem-id>/problem.yaml`: a problem's identity, classification, rights and source information.
- `problems/<shard>/<problem-id>/statement.*`: the problem statement.
- `problems/<shard>/<problem-id>/contributions/<contribution-id>/`: a contribution record (`contribution.yaml`) and its source files.
- `problems/<shard>/<problem-id>/reviews/`: community reviews of contributions.
- `browse/aliases.json` and `browse/README.md`: public handles (opaque `prb_…` IDs, `ERDOS-5`, `ECON-C73-1`) and the folders they point to.

Some problems appear as several records because they were catalogued more than once; the website shows them on one page.

Statements and contributions can contain errors. An attempted solution, including one generated by an AI model, is not a verified proof and is not peer reviewed. Read the stated scope, limitations, sources and attribution before relying on anything here.

Licences and author credits are recorded with each problem and contribution; preserve them when reusing material. Links to third-party sources do not grant additional rights.

Submissions are open through the issue forms. See [CONTRIBUTING.md](CONTRIBUTING.md).
